## Design (PCP-SILAC compartment profiling)
There are 3 cell lines (A549, Calu-1, NCI-H1299), 2 biological replicates each and 4 compartments (cytosol, mitochondrion, nucleus, vesicle). That gives 24 triple-SILAC mixtures, each cut into 10 SDS-PAGE slices, so 240 runs. Each run has 3 rows, one per channel: 720 rows × 55 columns.

| channel | sample | source |
|---|---|---|
| SILAC heavy (Arg10/Lys8) | IAV-infected compartment (X:31 A/Aichi/68, MOI 2, 24 h) | paper Fig. 2A legend + text; deposit readme |
| SILAC medium (Arg6/Lys4) | uninfected control compartment | paper Fig. 2A; readme ("IVA (heavy) versus control (medium heavy)") |
| SILAC light (Arg0/Lys0) | internal standard: the pool of all 4 light (untreated) compartments of that experiment, spiked into each mixture | paper ("all light-labeled cell fractions of one experiment were combined and served as an internal standard"); readme |

**Data check.** In all 24 MaxQuant experiments every influenza protein group is heavy-dominant: median log2 normalized H/M is 2.7–4.7 per experiment. IFIT1, IFIT2 and OASL have H/M 2–15 in every A549 compartment, which matches the paper's statement that IFITs were up "exclusively in A549".

**Groups.** Each (cell line × compartment × infection) group has 2 sources, biological replicates 1 and 2. The light reference has 8 aliquots per cell line, carrying replicate 1 or 2 by experiment.
- A549: MaxQuant experiments C_3/C_4, M_3/M_4, N_3/N_4, V_3/V_4. These are files `_1_` and `_2_` and are numbered 1 and 2 here.
- Calu-1: C_C_1 … C_V_2.
- NCI-H1299: H_C_1 … H_V_2.

**Source names.** Each source name denotes one physical sample:
- `<cell line>_exp<n>_IAV_infected_<compartment>`
- `<cell line>_exp<n>_uninfected_<compartment>`
- `<cell line>_exp<n>_light_uninfected_fraction_pool_spiked_into_<compartment>_mix`, one per light aliquot, following the PXD002388 reference-aliquot precedent.

## Open items / limitations
- `comment[precursor mass tolerance]` is `not available`: no mqpar.xml was deposited and MaxQuant 1.4.1.2 does not record it. Because of this, convert-openms exits 1, as in the precedents.
- **Fraction numbering.** For the 80 Calu-1 files, MaxQuant numbers fractions as 11 − (file slice index), and the SDRF follows the search.
  - The deposited data confirm this. Median protein MW of the PSMs (`mwcheck.txt`) falls with slice index in A549 (149 → 19 kDa) and NCI-H1299 (191 → 24 kDa) but rises in Calu-1 (27 → 238 kDa).
  - So fraction k is the same gel region in all three cell lines.
- **Virus taxon.** The PRIDE organism NEWT:553341 (A/Aichi/68/2007) disagrees with the strain in the paper. The paper's strain was used.
- **Companion PXD007809.**
  - It shares no RAW file with this deposit.
  - The 132 runs in this deposit's MaxQuant design that are missing here are in PXD007809, according to the independent review's FTP listing.
  - It holds the third A549 replicate.
  - Here, A549 replicates 1/2 correspond to MaxQuant C_3/C_4 etc. Coordinate the numbering if PXD007809 is annotated.
- **Not encoded.** MOI 2 is stated in the paper but has no template column; it is recorded in the manifest only.
- **Record source.** The PRIDE v3 API and the MCP PRIDE tools timed out. The record came from the v2 API and the FTP README/listing.
