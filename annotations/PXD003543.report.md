# PXD003543 — SDRF annotation report

**Status: REVIEW_PENDING_EXTERNAL.** The independent review has not run yet. Nothing was committed or approved.

Dataset: *Proteomic profile of oxaliplatin treated cell line reveals DNA damage induced nucleolar stress as main response*. The cell line is CCRF-CEM. Paper: Ozdian et al., J Proteomics 2017, doi:10.1016/j.jprot.2017.05.005, closed access, so only the abstract was read.

## Scope and screening
- **Full scope.** All 60 deposited .raw files are annotated. SEARCH.zip is MaxQuant output and is used as evidence only. No runs were excluded and nothing was blocked, so there is no BLOCKED.md entry.
- **SILAC is confirmed.** In the MaxQuant 1.4.1.2 summary.txt, all 60 runs have Multiplicity 2, Labels0 empty and Labels1 Arg6;Lys6.
- **No duplicate or re-deposit.** A PRIDE search on "oxaliplatin CCRF-CEM", "oxaliplatin SILAC" and "Ozdian" returns only PXD003543. There is no SDRF for it in sdrf-annotated-datasets.
- **Caller vs prompt file.** The batch11 prompt file listed other accessions (PXD013543 and PXD035431/33/34). Those already have annotations, and PXD013543 is a label-free rat study. The caller named PXD003543, so that is what was annotated.

## Design (120 rows × 50 columns)
- **Two-plex SILAC, three biological replicates.** Each replicate is one light+heavy mixture, tagged 080408, 110408 and 180408. Each mixture was run as 20 SDS-PAGE gel slices, giving 60 raw files with 2 channels each.
- **Channel map:**
  - SILAC light = oxaliplatin, 29.3 uM for 240 min.
  - SILAC heavy = untreated.
- **Source of the map:** the PRIDE sampleProcessingProtocol says "Light cell lines ... treated with L-OHP 29.3 μM for 240 minutes".
- **Check against the data** (proteinGroups, Ratio H/L normalized):
  - Replicate correlations are 0.76–0.81, so all three replicates have the same orientation.
  - The proteins with the highest H/L (more in heavy) are nucleolar/processome and centrosomal proteins: UTP11L, WDR46, NSA2, GLTSCR2, RPL7L1, DDX56, CEP41, ASPM and MAD1L1. RPL/RPS and UTP/NOP family medians are also above 0.
  - These are the classes the abstract says oxaliplatin **down**-regulates. Lower levels in the treated channel means treated = light, which agrees with the protocol.
- **Sources (6 total):** `CCRF-CEM_<oxaliplatin|untreated>_<rep>`.
- **Biological replicate:** numbered 1–3 within each treatment group.
- **Factor value:** `factor value[treatment]` = oxaliplatin / untreated.
- **Templates:**
  - ms-proteomics v1.2.0
  - human v1.1.0
  - cell-lines v1.1.0
- **Sample metadata** (from Cellosaurus CVCL_0207): blood; T cell; T-cell childhood acute lymphocytic leukemia (MONDO:0000871); 3Y11M; female; European ancestry; child stage (1-4 yo) (HsapDv:0000265). The culture medium is RPMI 1640.
- **Custom columns:** `characteristics[dose]` and `characteristics[sampling time]`. For untreated rows both are "not applicable".
- **Technical values:**
  - Orbitrap Elite (MS:1001910).
  - DDA top20, CID at 35 NCE, MS2 in the linear ion trap.
  - MS1 range 300–1700 m/z, taken from the raw method.
  - Trypsin; SDS PAGE fractionation; TCEP reduction; IAA alkylation.
  - Tolerances 4.5 ppm and 0.5 Da, from the Andromeda .apar files.
- **Modifications:**
  - Carbamidomethyl C, fixed.
  - Oxidation M, variable.
  - Acetyl at protein N-term, variable.
  - Label:13C(6) (UNIMOD:188) on R and K, variable.
  - There is no Multi modifications column in this summary.txt.

## Open items / limitations
- **Paper not read.** The full text is closed access. All methods come from the PRIDE protocol, the raw headers and the MaxQuant output.
- **MS1 range conflict.** The protocol says 300–1950 m/z, but the raw method says 300–1700 in the 3 files sampled, one per replicate. The raw value is used.
- **MaxQuant version and fasta mismatch.** The protocol says v1.3.0.5 with SwissProt 4.4.2013. The deposited output says 1.4.1.2 with uniprot_Human_20130904. No SDRF column depends on this.
- **Precursor tolerance.** The protocol's 20 ppm is the first-search value. The annotated 4.5 ppm is the main search.
- **Untreated cells.** The protocol does not say whether they were mock-treated or what their timing was.
- **Passage number** is "not available".
