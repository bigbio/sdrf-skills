## Study
Zuccato JA *et al.* "Prediction of brain metastasis development with DNA methylation signatures." *Nat Med* 2025;31(1):116-125. PMID 39379704, PMC11750707, doi:10.1038/s41591-024-03286-y. The full text came from NCBI efetch (numeric id, title checked); Europe PMC fullTextXML returned HTTP 500. The only ESM is the reporting summary (an image-only PDF). There is no supplementary table.

The proteomics is a side arm of a methylation study:
1. **49 primary LUAD tumours (UHN "IMPACT" cohort).** Tissue lysate was mixed 1:1 with a super-SILAC standard and run on an Orbitrap Elite (240-min gradient, top-10 CID in the ion trap) in 2015. The data were searched with MaxQuant 2.4.7.0.
2. **50 brain-metastasis (BM) tumours from LUAD patients.** The lysis buffer contained TCEP and chloroacetamide, and digestion used Promega Trypsin/Lys-C. The samples were run as diaPASEF on a timsTOF Pro (2023) and searched with DIA-NN 1.8.1 against a project library.
3. **The project library.** A pool of 2 µL of each BM sample was separated into 60 high-pH RP fractions and run as DDA-PASEF (Dec 2022). It was searched with FragPipe (MSFragger 3.6) and converted with EasyPQP.

## Key decisions and evidence

### SILAC check (campaign rules 14 and 18)
The SILAC is real. The deposited `proteinGroups.txt` has `Ratio H/L` and `Intensity L/H` for all 49 experiments, so the multiplicity is 2.

**Channel map:**
- Light = patient tissue.
- Heavy = the super-SILAC reference.
- The heavy reference is HCC827 + NCI-H520 + NCI-H460 mixed 1:1:1, labelled with Lys-8 (13C6 15N2) and Arg-10 (13C6 15N4).

**Sources for the map:**
- The paper says "mixed with equal amounts of super-SILAC standard … as done previously (45, 46)".
- Ref. 45 (Mirhadi 2023, PMC9808373; same lab, same Orbitrap Elite method) describes how the standard was made.

**Check against the data:**
- Proteins found only in tissue are strongly light: HBB H/L 0.069, IGHG1 0.030, SFTPB 0.0019, SFTPA2 0.0012, AGER 0.019 and PTPRC 0.090.
- EGFR is heavy-dominant (H/L 4.25). This fits HCC827, which is EGFR-amplified.

**How the rows are encoded (rule 18, following the precedents PXD000690 and PXD001963):**
- Heavy rows have sample type `reference`, material type `cell line` and `pooled sample` = `SN=HCC827;SN=NCI-H520;SN=NCI-H460`.
- Heavy rows have age, sex, individual and biological replicate set to `pooled`, and disease and histologic subtype set to `not applicable`.
- Heavy rows have organism part `lung`, because Cellosaurus gives Lung for all three lines.
- `cell-lines` is **not** declared.

### Instruments
These come from the raw files, not from PRIDE:
- All 49 `.raw` headers read **Orbitrap Elite**. I got them by LZMA2-decompressing the first ~1 MB of each member through range reads.
- analysis.tdf gives **timsTOF Pro** for a DIA run and a library run (same serial number).
- The PRIDE `instruments` field lists "Orbitrap Fusion Lumos" and a generic Bruker term. Lumos is wrong for every arm.

### Modifications, read from the deposited search outputs
**BM library (pepXML `search_summary`):**
- Fixed: Carbamidomethyl C.
- Variable: Oxidation M, protein N-term Acetyl, Phospho STY, and n-term Q/C −17.03 and E −18.01 (UNIMOD:28, 26 and 27).
- Precursor window ±50 ppm, fragment 20 ppm.

**BM DIA (DIA-NN log):**
- Variable: UniMod:35 M, UniMod:1 `*n` (protein N-term) and UniMod:21 STY.
- Tolerance 20/20 ppm.
- No `--unimod4` flag. C carbamidomethylation comes from the library: UniMod:4 is on the library peptides, and DIA-NN searched that library.
- I annotated the same seven mods on the DIA rows as on the library rows, because the library's pyro-forms were part of the DIA search space.

**LUAD (MaxQuant):** no mqpar or parameters file was deposited.
- Oxidation (M) is evidenced: proteinGroups has the column `Oxidation (M) site IDs`.
- Lys8 and Arg10 come from ref. 45 together with the H/L ratios.
- Carbamidomethyl C is **inferred**. Supporting evidence: the IAA alkylation is documented, PRIDE's PTM list contains "iodoacetamide derivatized residue", and it is the MaxQuant default.
- Acetyl (Protein N-term) is **not annotated**, because no deposited evidence supports it.

## Conflicts found
- **PRIDE vs raw files:** PRIDE instruments (Orbitrap Fusion Lumos) conflict with the raw files (Elite and timsTOF Pro). The raw files win.
- **PRIDE SILAC tag:** it is project-wide. It applies to the LUAD arm only; the BM arm is label-free (reconcile refuted).
- **Library fragment tolerance:** the paper says 0.1 Da, the deposited pepXML says 20 ppm. pepXML wins.
- **FragPipe version:** the paper says v22.0, PRIDE says 19.0, and the pepXML says MSFragger 3.6, which matches FragPipe 19. This is not an SDRF column.
- **Patient numbers:** PRIDE says 364 samples / 309 patients, the paper says 402 / 346. These are cohort-level numbers and do not affect the SDRF.
