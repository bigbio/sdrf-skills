# PXD064518 — SDRF annotation report

**Status:** BLOCKED (per project policy — the study's biological factor is not recoverable per channel).
**Decision:** Although every single-cell channel is identifiable as a single mouse cardiomyocyte and a
729-row SDRF is technically constructible (`ms-proteomics + vertebrates + single-cell`, validates clean
per template), the study's core experimental variable — **control vs Myc-overexpressing genotype** — is
**not deposited per channel** for the 81 analytical `..._CNIC-KI_TMT{n}` files. A motivated hunt across
six sources (PRIDE files, the OPEN paper Methods + supplementary PMC13292336, and Zenodo records
19439667 / 18379944 / 19484833, plus Europe PMC supplementary) found a per-channel genotype map only for
the **pilot** PXD064499 (files `20220323_SST_cnic_SCP_*`), never for this dataset. Extrapolating the
pilot's alternating design to these files is forbidden (layouts flip; the brief bars assuming a fixed
layout). Per the project policy "block when the biological factor is missing rather than deposit an SDRF
whose only distinguishing axis is not available," this dataset is BLOCKED and no SDRF is shipped. The
structural facts below are recorded so a future run can annotate it if the per-channel genotype is later
supplied (e.g. by the authors). See `annotations/BLOCKED.md`.

## 5. THE key limitation — per-channel genotype (control vs Myc) is NOT assignable, and I did not fabricate it

The single experimental variable is **control vs Myc-overexpressing**. Each batch holds 4 + 4 of these,
and the paper states two labelling **designs were alternated** ("each type ... was differentially
labelled with alternative tags", Fig 1c) specifically so the genotype→channel assignment **flips
between runs**. To assign genotype per channel I need the per-file design.

**Sources hunted for the per-file (per-channel) genotype map — all exhausted:**
1. **PRIDE files/all** — only raw/mzML/mzid; no design/sample sheet. ✗
2. **Paper Methods / Data-availability** — give the *general* layout (130N empty, 131 carrier, 4+4 cells,
   two designs) but **no per-file design assignment** for the 81 analytical files. ✗
3. **Zenodo `19439667` (iSanXoT workflow, ref [99])** — has a true channel→cell→genotype map
   (`level_creator.tsv`), but only for the **pilot's 12 files** `20220323_SST_cnic_SCP_1..12`
   (= PXD064499). Its `ID-q.tsv` Batch↔`Spectrum File` map confirms these are pilot files, **not**
   this dataset's `..._CNIC-KI_TMT{n}` files. ✗ for the analytical set
4. **Zenodo `18379944` (Complementary data, ref [40])** — protein-level volcano/marker/PERMANOVA
   outputs; no per-cell channel map. ✗
5. **Zenodo `19484833` (Raw_data_1, Figs 1–3)** — Metaboanalyst per-cell inputs. Fig 2's cell→TMT→
   genotype table covers **12 TMTs / 96 cells = the pilot** (cells CTRL_1..48/MYC_1..48). Fig 3 uses
   TMT84+ = the **FACS** dataset (PXD064501). Neither indexes this dataset's TMT1–83 raw files, and
   none carries the channel dimension for them. ✗
6. **Europe PMC supplementary** (`PMC13292336`, one .docx: Figs S1–S17 + Tables S1–S5) — QC/PLS-DA/
   chromatin/chi-square tables; no per-cell channel→genotype design. ✗

The pilot's design is a **strict batch-parity alternation**, but extrapolating that ordering onto the
81 heterogeneous analytical files (acquired over time, aggregating sub-experiments; the paper notes
"TMT samples 5–9 and 12–20 within the Analytical Dataset correspond to dataset 3") would be a
**guess**. Per the annotator brief ("Layouts can flip between runs — never assume one fixed layout";
"Do not fabricate channel identities"), I annotated every single-cell channel as a **single
cardiomyocyte with genotype left unrecorded** rather than invent control/Myc labels.

Consequence: the SDRF has **no `factor value[...]` column** and no `characteristics[genotype]` — the
factor (Myc overexpression) cannot be bound to individual channels from any deposited artifact. Cell
*identity* (single mouse cardiomyocyte, adult male heart) is fully and correctly annotated; only the
control-vs-Myc *label* is missing. This is a legitimate partial annotation, not a block: none of the
three templates' **required** columns depend on genotype.

## 7. Technical metadata — evidence and decisions

Precedence: deposited PD 2.5 search (the mzid) > Methods. All acquisition/search values are from the
**single-cell** arm (not the bulk arm, which uses a different Q Exactive HF workflow — excluded here;
bulk is a separate deposition, PXD064994/PXD073496).

- **Instrument:** Orbitrap Eclipse (MS:1003029), tribrid + FAIMS Pro (CV −50/−70 V; no SDRF column for
  FAIMS CV — noted only here). PRIDE `instruments` agrees.
- **Acquisition:** Data-dependent acquisition (PRIDE:0000627). RETICLE = real-time-search-assisted DDA.
- **Dissociation:** `beam-type collision-induced dissociation` (MS:1000422 = **HCD**) — the Orbitrap
  MS2 that yields the reporter-quant/identified spectra (38 NCE). The RETICLE trigger scans use ion-trap
  **CID** (30 NCE); only HCD is annotated (single-cardinality column). `ms2 mass analyzer = orbitrap`.
- **Enzyme:** Trypsin (MS:1001251), 75 ng/cell.
- **Label:** TMT 10-plex → `comment[label]` = TMT126…TMT131 per channel; TMT reagent = **UNIMOD:737
  (TMT6plex)**, matching PRIDE's "TMT6plex-126 reporter+balance…".
- **Modifications (deposited PD 2.5 workflow):** static TMT6plex on **K** and on **peptide N-term**;
  variable **Oxidation (M)** UNIMOD:35; variable **Acetyl (protein N-term)** UNIMOD:1.
  **No Carbamidomethyl** — the scope-MS single-cell prep performs **no reduction/alkylation** (only the
  *bulk* arm used DTT/IAA). `comment[reduction reagent]` and `comment[alkylation reagent]` are set to
  `not applicable` to make this explicit (the reflexive Carbamidomethyl annotation would be wrong here).
- **Precursor tolerance:** `15 ppm` — the enforced post-search filter for accepted PSMs. (PD Sequest HT
  was run with an 800 ppm *search window* then filtered to 15 ppm; RTS used 10 ppm. 15 ppm reflects the
  real precursor accuracy of the deposited identifications.) **Fragment tolerance not stated** →
  `not available`. `collision energy = 38 NCE` (HCD quant).
- **Batch:** `comment[sample preparation batch]` = the TMT batch token (TMT1…TMT83); `carrier channel`
  = TMT131; `reference channel` = not applicable (there is no reference channel; 130N is empty).
- Fraction identifier 1 (unfractionated single cells); technical replicate 1.

- **Stated (paper/PRIDE/deposited files):** mouse; heart cardiomyocytes; manual single-cell picking;
