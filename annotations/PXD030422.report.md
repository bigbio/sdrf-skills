## Study
Nicolas AM, …, Oellerich T, Rödel C, Fokas E, Greten FR. "Inflammatory fibroblasts mediate resistance to neoadjuvant therapy in rectal cancer." *Cancer Cell* 2022;40(2):168-184.e13. PMID 35120600, doi:10.1016/j.ccell.2022.01.004.

**The full text was not accessible.** It is not in PMC, and Europe PMC lists it as "Subscription required". The publisher HTML/PDF and the Unpaywall link (hybrid, CC-BY) returned HTTP 403, and further attempts there were stopped. The Elsevier API returned metadata only. Only the abstract was read.

- **Samples:** FFPE rectal cancer tissue from 61 patients treated with neoadjuvant chemoradiotherapy (CRT). The tumour cell population was isolated by laser-capture microdissection (MMI CellCut).
- **Quantification:** super-SILAC. Each tissue lysate was mixed 1:1 (protein) with a heavy (Arg10/Lys8) standard made of five CRC cell lines: LS411N, HT29, SW480, SW837 and SW1463. The mix was digested by FASP with trypsin.
- **MS:** single-shot 178-min DDA runs.
- **Search:** one MaxQuant 1.5.2.8 search, multiplicity 2.

## Key decisions (evidence)
1. **Multiplexing verified (rule 14).** `summary.txt` shows Multiplicity 2 and Labels1 = `Arg10;Lys8` for every run. The protocol says the same. Heavy = the reference standard; FFPE patient tissue cannot be metabolically labelled. Light = the patient sample.
2. **Super-SILAC encoding (rule 18; precedents PXD001370/PXD000332).** Heavy rows have:
   - `sample type` = reference, `material type` = cell line;
   - `pooled sample` = `SN=LS411N;SN=HT-29;SN=SW480;SN=SW837;SN=SW1463` (Cellosaurus names; HT29 → HT-29 CVCL_0320);
   - `disease` = colorectal adenocarcinoma (all five lines per Cellosaurus);
   - `age`/`sex`/`individual`/`biological replicate` = `pooled` (TERMS allow_pooled);
   - clinical columns `not applicable`.

   There is one heavy source per patient mix, "super-SILAC reference standard (mixed with <Sample Name>)". The protocol states each tissue lysate was mixed with the standard before digestion.
3. **Clinical values come only from `Cohort_file_IDs.txt`, joined on the Raw file ID (rule 18).**
   - `individual` = Internal ID; `age`; `sex`;
   - `tumor grading` (Grade 2/3, NCIT);
   - `tumor stage` = pre-CRT clinical TNM (`cT3N1M0` …);
   - `treatment response` / factor value;
   - `clinical data` = a verbatim free-text rendering of pre-CRT TNM, regimen (5-FU + RT or 5-FU + Oxaliplatin + RT), post-CRT pTNM, DFS event and DFS time (months).

   No cohort-level summary was copied onto rows. Nothing was added beyond what the deposit publishes.
4. **Instrument: raw beats PRIDE.** PRIDE and the protocol name only the Orbitrap Fusion, but the 12 T_Oellerich runs are Q Exactive HF (headers: "Q Exactive HF - Orbitrap MS", TOP30 method). Per-run values:
   - MS2 analyser: Fusion ion trap (header "Detector Type = IonTrap", protocol); QE HF orbitrap.
   - Fragment tolerance (MaxQuant parameters.txt): ITMS 0.5 Da for Fusion; FTMS 20 ppm for QE HF.
   - NCE (headers): 35% for Fusion; 28% for QE HF. The Fusion method also contains a second dependent MS2 event at 40% with AGC 500. The protocol states 35, so 35 is used.
5. **Modifications come from the search (brief rule).** They are Carbamidomethyl C (fixed), Acetyl Protein N-term, Oxidation M, **Deamidated N** and Arg10/Lys8 (variable, rule 11). Deamidation (N) is missing from the PRIDE prose, but it is in summary.txt for every run and has its own sites table. Cleavage agent = Trypsin (MS:1001251). The search rule was Trypsin/P (rule 2).
6. **The file name beats the MaxQuant experiment name.** For 7 runs the MaxQuant "Experiment" disagrees with the file-name number. Examples: TO_…_KRK_R1_49 → `KRK_R1_48`, and R1_50/52/53/54 are each shifted down; H_…_KRK_R1_62 → `KRK_R1_61`. The shifted names collide: two files each map to KRK_R1_48, KRK_R1_51, KRK_R1_61 and KRK_R1_22. The file names agree 1:1 with the cohort Raw file IDs and the Sample Name suffixes, so the file names were used.

- **PRIDE prose vs search:** the prose omits Deamidation (N). Resolved to the search.
- **MaxQuant experiment names vs file names:** 7 runs disagree. Resolved to the file names (decision 6).
- **reconcile organism BLOCKER:** a false positive ("murine" in the project description). Refuted in validation.txt.

## Stated vs inferred
- **Stated** (deposit): all clinical values, labels, cell lines, reagents, mods, tolerances, instrument per run, MS2 analyser and NCE.
- **Inferred:**
  - `treatment status` = pre-treatment. Pathological complete responders (ypT0pN0, 32 patients) have no tumour cells left after CRT, yet they yielded microdissected tumour-cell runs.
  - `Residual Disease` as the NCIT encoding of non-pCR.
  - Repeated runs treated as technical replicates.
  - `rectal cancer` rather than a histological subtype.
  - `malignant cell` taken from the protocol's "tumor cell population" (PRIDE's dropdown says epithelial cell).

## Open items / limitations (also in the manifest)
- Paper full text unavailable. Methods and supplementary files were not checked, so per-sample details such as biopsy vs resection and the replicate design are unconfirmed.
- Pre-treatment status is inferred (see above).
- R1/R2/wdh runs: re-injection vs re-preparation is unknown. Patient 22's 2016 Fusion run has a different prefix date (070316) from its 2015 QE HF runs (171215), so it may be a separate preparation. It is encoded as technical replicate 3.
- Precursor tolerance 6 ppm is from prose only; mqpar.xml was not deposited.
- FFPE/LCM have no licensed column; they are described here only.
- techsdrf is not installed; raw headers were read by HTTP range reads.

## Judgement calls a reviewer should attack hardest
1. **`treatment status = pre-treatment`** rests on a logical inference (pCR patients cannot yield post-CRT tumour cells), not on a sentence in an accessible source. The alternative is to drop the column.
2. **File-name number over MaxQuant "Experiment" for the patient key** (7 runs). The 1:1 match with the cohort's Raw file IDs and Sample Name suffixes supports it. If the MaxQuant names were right, 7 runs would carry another patient's clinical data.
3. **Super-SILAC heavy encoding and treatment-response terms.** The heavy rows use a per-patient heavy source, `pooled` for biological replicate/age/sex/individual, `SN=` in `pooled sample` (validator warning), and `colorectal adenocarcinoma` as the pool's disease. Non-pCR is mapped to NCIT "Residual Disease" because no non-pCR term exists. The 12 Q Exactive HF runs carry 20 ppm (FTMS) fragment tolerance taken from parameters.txt, not from the prose.

No BLOCKED.md entry: the whole deposit is annotated.
