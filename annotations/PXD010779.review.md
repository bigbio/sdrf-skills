- **Is the block justified? Yes.** I re-checked it:

  - In the TMT `mqpar.xml`, the `<experiments>` list is empty, and the isobaric labels carry no sample names.

  - Leaving the 8 unassigned channels unannotated, instead of guessing them, is correct.

## Key independent verifications
- **Which tumor is in which super-SILAC experiment.** I recomputed this from `super-SILAC_proteins_proteinGroups.txt`, using normalized H/L with reverse hits and contaminants removed:
  - Share of proteins with L/H < 0.5: #1_LN 18.7%, #2_Lung 8.5%, #3_LN 9.3%. This matches Fig. 2C (LN1 19%, Lung and LN2 8–9%).
  - Correlation of log-ratios (R²): #1–#2 = 0.28, #1–#3 = 0.45, #2–#3 = 0.46. This matches the paper's finding that LN1 vs Lung correlates least.
  - So #1 = LN1, #2 = Lung, #3 = LN2.
- **Label orientation.** ERBB2 has H/L = 0.022 in #2_Lung, so ERBB2 is high in the light channel. That makes light = tumor and heavy = the spiked-in 12-cell-line reference. The heavy rows are typed `reference` (PRIDE:0000899) and carry no patient attributes, which is correct.
- **Clinical values.** There is only one patient, the index patient. Every value comes from individual-level statements about him:
  - "A 50-year old African American never smoker…" and "his … course" support ancestry, smoking status and sex.
  - Table I gives the excision sites, dates and preceding regimens. I checked each clinical-history string against Table I.
  - Age is left `not available` instead of being derived from the age at diagnosis.
- **Search and acquisition values.**
  - From mqpar/parameters: Arg6;Lys6 (UNIMOD:188 on R and K), Trypsin/P, Carbamidomethyl (C) fixed, Oxidation (M) / Acetyl (Protein N-term) / Phospho (STY) variable, main search tolerance 4.5 ppm, MS/MS tolerance 20 ppm.
  - Deamidation is in the paper but not in the deposited search, so leaving it out is correct.
  - From raw headers (range reads of `3_LN_super-SILAC_F4_R1` and `_R2`): Orbitrap Elite, HCD, NCE 32.0, EASY-nLC. The R1 method is `top15HCD_360min` (360 min); the R2 method is `top15HCD_80min` (80 min). This matches 21600 s and 4800 s in `comment[chromatography duration]`.
- **Files.** The PRIDE `files/all` list has 122 entries, all with projectAccessions = PXD010779. The SDRF data files are exactly the 72 super-SILAC RAW files, each with one light and one heavy row. Fraction and technical replicate match the `_F<n>_R<n>` tokens and `experimentalDesignTemplate.txt`. I found 0 inconsistent rows and 0 duplicates.
- **Templates.** ms-proteomics 1.2.0, human 1.1.0, clinical-metadata 1.0.0 and oncology-metadata 1.0.0 are the latest versions at sdrf-templates 7da1747. The YAMLs bundled in sdrf-pipelines are byte-identical to that revision.
