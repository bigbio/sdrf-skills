## Key decisions and evidence

**`cell-lines` template NOT used (biggest judgment call).** The screen tagged this as a cell-line
study, but:
1. The iPSC line is **hi12** (paper: "hi12 (ref 32) iPSCs"). hi12 has **no Cellosaurus entry** and no
   CLO entry (verified: Cellosaurus API `numFound: 0`; OLS `clo` `numFound: 0`). So the cell-lines
   template's payload — `cellosaurus accession` / `cellosaurus name` — cannot be filled.
2. `characteristics[cell line]` under `cell-lines/1.1.0` is `required` with **both** reserved words
   forbidden, so declaring the template would force asserting an unverifiable line on every row.
3. **Embryoid-body cells are not a cell line.** They are heterogeneous differentiated aggregates
   (three germ layers) derived *from* hi12 — a cell *type*, not an immortalized line. 96 of 111 rows
   are EB, so cell-lines would misrepresent the majority.

Instead, identity is captured by `characteristics[cell type]` (BTO, which the column licenses):
- iPSC rows → `NT=hiPSC cell;AC=BTO:0006081` (CL has no iPSC term; EFO:0004905 exists but EFO is *not*
  in the cell-type column's allowed ontologies CL/BTO/CLO, so BTO was used).
- EB rows → `NT=embryoid body;AC=BTO:0001718`.

`characteristics[individual] = hi12` records the shared donor/line across all 111 rows (iPSCs and
their EB derivatives come from the same reprogrammed donor).

**Acquisition is pure narrow-window DIA** → `dia-acquisition` (forces the literal
`Data-independent acquisition`). No DDA arm in this accession, so the template covers every file.

**Modifications.** `Oxidation` (UNIMOD:35, TA=M, Variable) and `Acetyl` (UNIMOD:1, `PP=Protein
N-term`, Variable) — both variable. **No Carbamidomethyl**: paper Methods explicitly state "cysteine
carbamidomethylation was not included," and the Chip-Tip protocol has no reduction/alkylation step.
PRIDE's `modifications` field lists only "monohydroxylated residue / acetylated residue," consistent.
A separate exploratory **phospho (S/T/Y)** search was run on the same raw files (paper Data analysis);
it is an add-on search variant, not the primary directDIA search, so phospho is **not** encoded in
`comment[modification parameters]` — noted here for the reviewer.

**Cleavage agents.** Trypsin (MS:1001251) + Lys-C (MS:1001309) — master mix contains both (paper:
"20 ng/µl trypsin and 10 ng/µl lys-C").

**Dissociation method** = `beam-type collision-induced dissociation` (MS:1000422) = HCD, NCE 27%.
(This SDRF column is the MS fragmentation method; the cell-dissociation reagent TrypLE Express is a
different concept not modeled by this column.)

## Values deliberately left `not available` / `not applicable`

| column | value | why |
|---|---|---|
| `comment[isolation window width]` | `not available` | The 40SPD single cells were split across **four** nDIA schemes — 2Th3ms, 4Th6ms, 8Th12ms, 16Th24ms (isolation widths 2/4/8/16 m/z). The `.raw` filenames do **not** encode which scheme each file used, and the paper gives no per-file map for the iPSC/EB arm (its 12/12/24/12 split describes a different 60-cell set). The column pattern `^\d+(\.\d+)?$` admits only one scalar, so no single verifiable value exists. Matches the accepted precedent for variable-window DIA (PXD052416). Recovery would require parsing each `.raw` acquisition method or the Spectronaut `.sne` run→method mapping. |
| `comment[dia method]` | `not available` | Method is narrow-window DIA (nDIA) on Astral; no PRIDE-ontology CV term exists for it (searched `pride`, `numFound: 0`). Column requires a PRIDE term. |
| `characteristics[age]`, `[sex]` | `not available` | hi12 donor demographics are not stated in the paper (age forbids `not applicable`, so `not available`). |
| `characteristics[organism part]` | `not applicable` | iPSCs and embryoid bodies are in-vitro cultured cells with no source tissue/organ. |

`comment[scan window lower/upper limit]` = `380` / `980` from the paper's stated full-MS and MS/MS
m/z range (380–980).

## Judgement calls a reviewer should attack hardest

1. **Dropping `cell-lines`.** A reviewer could argue the iPSC rows *are* a cell line (hi12) and should
   carry `characteristics[cell line]=hi12` even without a Cellosaurus accession. Counter: the template
   forbids reserved words on `cell line`, hi12 has no CV entry, and it can't apply to the 96 EB rows —
   so a single file-wide declaration would be wrong for the majority.
2. **`disease = normal` on all rows.** Positive assertion of health; donor status not stated. `not
   available` would be more conservative. Chose `normal` because the study is explicitly a
   normal-development differentiation model, not a disease study.
3. **`comment[isolation window width] = not available` for all rows.** A reviewer may contend the
   per-file nDIA scheme is recoverable from the `.raw` methods or the `.sne` files. Left `not
   available` as honest and precedent-aligned; recovery path documented above.
4. **iPSC cell type via BTO not CL/EFO.** `hiPSC cell` (BTO:0006081) chosen because CL lacks an iPSC
   term and EFO is outside the column's allowed ontologies. `embryoid body` (BTO:0001718) for EB rows
   is a structure term used as cell type — defensible but not a precise CL cell class.
5. **Phospho search excluded from modification parameters** (treated as a secondary search variant).
