## Conflicts resolved

- **PRIDE `SILAC` vs label-free arm.** The paper and the .msf win. `reconcile` raises
  `labelled_annotated_as_label_free` on the LFQ file as a BLOCKER; this is rebutted, see Screening.
- **Trypsin.** `reconcile` raises `cleavage_agent_unsupported` because the PRIDE protocol text only
  says "protease digestion". The paper says "digestion ... using trypsin" and the .msf enzyme is
  Trypsin (Full).
- **Fragment tolerance.** The paper prose says 20 ppm. The .msf Sequest node says 0.02 Da, which is
  used. 15 ppm / 0.1 Da belong to the Spectrum Files RC recalibration node.

## Open items / limitations

- `characteristics[sex]` = not available. Male and female mice were used and sex-matched within a
  replicate, but no per-replicate sex is given.
- Age has no licensed characteristics column for vertebrates (`characteristics[age]` is human-only in
  the pinned templates, so it is not added even though parse_sdrf would accept it). It is carried as
  `factor value[age]` in the LFQ file only. `developmental stage` = adult is inferred from 2 and 10
  months.
- Heavy reference: strain not available. Whether one or several animals supplied it is unstated,
  so it is modelled as one heavy source per IP.
- `comment[fractionation method]` = not available. The reused protocol (PXD025510) says "fractionated
  over SDB-RPS StageTips", but no PRIDE:0000550 descendant names SDB-RPS (mixed-mode sulfonated
  reversed phase). Mapping it to RP or SCX would be a guess.
- FLAG and IgG IPs of one replicate share a lysate. Only the source names (same
  age/genotype/replicate) link them.
- Search parameters were read from one .msf per arm, plus a template and label check on all four
  SILAC .msf. The 24 LFQ .msf were read for raw paths only.
