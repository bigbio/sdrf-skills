## Criterion-by-criterion
1. SILAC - PASS. Neuro2a cells grown 12 passages in SILAC-LYS6 (Lys 13C6) or unlabelled medium; heavy
   cells treated with tunicamycin (1 ug/ml overnight), both treated with TPE-MI, mixed 1:1, n=5.
   PD 2.1 precursor-ion quantifier, heavy/light ratios.
2. Neurodegenerative disease - FAIL. The deposited SILAC experiment is tunicamycin-induced ER stress vs
   untreated control in untransfected Neuro2a cells: general proteostasis/unfolded-protein biology.
   Huntington disease work in the paper (Httex1 25Q/97Q-mCherry transfection in Neuro2a; HD patient iPSC
   pNSC lines ND36999 180Q, ND36997 33Q, CRISPR-corrected 18Q) is flow cytometry/imaging only and is not
   part of the proteomics or the deposit. Manuscript: "For deeper insight we next performed a quantitative
   proteomics analysis using a matched pair design ... SILAC" in the tunicamycin section; HD is a separate
   fluorescence experiment. PRIDE record: diseases = [], keywords Neuro2a/Mouse/TPE-MI/SILAC; file names
   TPEMI_stressN_TPEMI_controlN. Neuro2a is a neuroblastoma line, not a neurodegeneration model.
3. No existing SDRF - PASS (per caller; PRIDE lists no submitter SDRF).
4. Vendor raw deposited - FAIL. PRIDE v3 files/all lists 25 files: 5 mzML (categorised RAW), 5 mgf,
   5 pride.mgf.gz, 5 mzid.gz, 5 pride.mztab.gz. No .raw (Orbitrap Fusion Lumos) files.
5. Mapping recoverable - would PASS (one mzML per replicate pair, heavy = tunicamycin, light = control),
   moot given 2 and 4.

## Decision
exclude - general proteostasis (tunicamycin ER stress) in Neuro2a; HD named only in non-deposited
fluorescence experiments; additionally no vendor raw files.
