## Rule-by-rule
1. **SILAC — pass.** Medium (Lys 2H4 / Arg 13C6) and heavy (Lys 13C6 15N2 / Arg 13C6 15N4) Neurobasal
   SILAC media combined with AHA BONCAT pulse; H/M ratios are the quantification (Proteome Discoverer 1.4).
2. **Neurological disease — FAIL.** Rule 2 crux: no disease model is part of the deposited runs.
   - Animals listed in Methods: C57Bl/6J, MNK-WT, MNK1-KO, MNK2-KO, MNK-DKO. No Fmr1-KO, no CYFIP1+/-,
     no patient material. The proteomics arm uses only MNK1 WT vs KO neurons, both BDNF-stimulated.
   - FMRP/Fragile X enters only via (a) a Venn-diagram comparison of the identified proteins against
     published FMRP-binding mRNA lists (external data, no FMRP perturbation in the runs) and
     (b) the Discussion's speculation about FXS/autism relevance. That is "disease named only as
     background motivation", which the criteria explicitly do not count.
   - MNK1 is not a neurological-disease gene studied in a disease context; the paper is a
     translational-signalling study. The PRIDE `diseases: Fragile x syndrome (DOID:14261)` and keyword
     `Fmrp` are submitter tags; manuscript > deposit metadata.
3. **No existing SDRF — pass** (per caller; not re-checked).
4. **Raw files — pass.** 3 Thermo .raw (samplepairA/B/C) plus .msf/.pep.xml/.prot.xml and an analysed xlsx (13 files, v3 files/all).
5. **Mapping — would pass.** Heavy = MNK1-WT, medium = MNK1-KO (Fig. 7 legend), one run per replicate pair A/B/C.
   Not needed given rule 2.
