# PXD006792 — screening report (SILAC x neurodegenerative disease campaign)

**Decision: EXCLUDE** — fails criterion 1 (no SILAC-type metabolic labelling in the deposited runs).
No SDRF written.

## Study
- PRIDE: "Tadpole-like conformations of polyglutamine-expanded soluble huntingtin exon 1 engenders novel interactions"
- Publication: Newcombe EA et al., J Mol Biol 2018;430(10):1442-1458, PMID 29627459, PMC5963539, doi 10.1016/j.jmb.2018.03.031
  (full text read via NCBI efetch db=pmc id=5963539; title verified; Europe PMC fullTextXML returned HTTP 500).
- Proteomics arm: GFP-Trap IP of soluble Httex1-25Q-Emerald, Httex1-46Q-Emerald and GFP control from transfected
  Neuro2a cells (mouse), n=3 each, FASP digest, Q Exactive, MaxQuant + Perseus.

## Criteria
1. **SILAC in deposited runs — FAIL.**
   - Paper Methods: "Perseus ... to determine significantly enriched species in **label free quantification**
     measurements"; Results: "Using a **label-free quantification** strategy"; Fig. 9 legend: "Data were acquired
     using **label free** MS/MS methods from n=3 replicates." No SILAC, heavy Lys/Arg or SILAC media anywhere.
   - Deposited MaxQuant output (MaxQuant_Output.zip, parameters.txt): `Label-free protein quantification True`,
     `iBAQ True`, `Match between runs True`; only fixed Carbamidomethyl (C); proteinGroups.txt has
     `LFQ intensity <exp>` columns for the 9 experiments and **zero** `Ratio H/L` columns;
     experimentalDesignTemplate.txt lists 9 single-label raw files (46Q1-3, 25Q1-3, GFP1-3).
   - The "stable isotope labelling" in the description/paper is 15N/13C labelling of recombinant Httex1 for NMR and
     hydrogen-deuterium exchange MS (HDX), neither of which is in this PRIDE deposit and neither is SILAC.
2. Neurodegenerative disease — pass (Huntington's disease; polyQ-expanded Httex1 interactome).
3. No existing SDRF — pass per caller (not re-checked).
4. Vendor raw deposited — pass (9 Thermo .raw + 1 MaxQuant zip; files/all, all entries asserted to PXD006792).
5. Run -> sample map — pass (file names = MaxQuant experiment names); there are no SILAC channels to map.
