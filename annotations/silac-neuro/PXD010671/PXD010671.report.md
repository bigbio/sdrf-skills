In the deposited P113 searches each of them is assigned to **two different samples**: `350-GDN-det` fractions 3-16 (txt_K6_4, txt_LFQ_4) and `352-tri-sol` fractions 3-16 (txt_K6_3, txt_LFQ_3). ## Key decisions and evidence

- **Run -> mouse / fraction map**: from MaxQuant `summary.txt` (Raw file, Experiment, Fraction) of all 45 txt_* folders, read by HTTP range from the 5 search zips (0 deposited files unmapped; 14 conflicting, above). Fraction identifiers are the MaxQuant fractions (contiguous 1..n for every source).
- **Genotype**: explicit in experiment names for P285 (wt/tg), P186 (WT/KI; numbered TXmem/GDNdet experiments mapped through the mouse id in the file name, `_44_` = WT-744 ... `_69_` = KI-069), P548 (Wt/Tg; ids 635/636/637 vs 021/297/371 in file names), P120 (WT/Tg indices, Tg ids 42/43/44 in file names) and all plasma searches. **P113 experiment names carry no genotype** (mouse ids 299-301, 350-352): resolved by exact matching of per-mouse LFQ intensities in `txt_LFQ_1/proteinGroups.txt` to Supplemental Table S3a — 299/300/301 = WT_LFQ_1/2/3, 350/351/352 = TG_LFQ_1/2/3 (33-42 exact matches each, zero cross-genotype matches); App LFQ is about 3x higher in 350-352, as in the explicitly labelled P285 tg mice (`p113_genotype_crosscheck.txt`).
- **Instrument**: Q Exactive Plus (MS:1002634) from the raw-file headers of 5 runs across batches and the paper; PRIDE says Q Exactive — overridden.
- **Modifications** (deposited search): Carbamidomethyl C fixed; Acetyl protein N-term and Oxidation M variable; Lys6 label = Label:13C(6) on K (UNIMOD:188), written Variable. Tolerances: precursor 20 ppm (paper), fragment 20 ppm (parameters.txt FTMS; the paper's 0.5 Da is the ITMS setting).
- **Cleavage agent**: trypsin only (MS:1001251); the Methods name no other protease (in-gel digestion with trypsin, Promega), so the campaign's combined-digest rule does not apply.
- **Disease**: model rows = modelled disease (Alzheimer disease MONDO:0004975; amyotrophic lateral sclerosis MONDO:0004976); WT rows = normal. Never broadcast to controls.
- **SILAC channels and source names**: the brief asks for one row per (source, channel) per run. Both channels are the same mouse, but `sdrf-tools structure` / the review gate require (source, biological replicate, technical replicate, fraction) to be unique, which ignores the label. The light and heavy rows therefore carry source names suffixed `_K0-light` / `_K6-heavy`, with identical characteristics.
- **Biological replicate** (revised after review-1): one integer per animal, unique across the file (1-42). It is shared by all of a mouse's detergent fractions and both SILAC channels. Plasma reuses the brain number where the deposit links them: P113 (same experiment ids), P186 (plasma file names carry the mouse ids) and P120 (index naming plus Tg ids 42/43/44 in the file names). P285 and P548 plasma get their own numbers. No (genotype, replicate) pair covers more than one mouse.
