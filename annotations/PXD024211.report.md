# PXD024211 — USP32 regulates non-proteolytic LAMTOR1 ubiquitination and Ragulator function

**PARTIAL SCOPE: 36 of 72 raw files annotated.** The 36 "Mila" files (MaxQuant experiments M1–M3 / m1–m3) are left out. No source says which samples they contain; see `annotations/BLOCKED.md` (section PXD024211) and the manifest limitations.

Status: **REVIEW_PENDING_EXTERNAL**. The SDRF has not had an independent review yet, so it is a draft.

## Dataset

- Paper: Hertel A et al., Cell Rep 2022;41(10):111653 (PMID 36476874, doi:10.1016/j.celrep.2022.111653). The full text could not be retrieved: no PMC copy, the cell.com PDF returned 403, and the Elsevier API returned metadata only.
- Sample-level evidence comes from the first author's doctoral thesis (Hertel A, née Kalb; Goethe University Frankfurt, doi:10.21248/gups.62688). It describes the same experiment with the same MS protocol text as PRIDE.
- Is this really multiplexed SILAC? Yes: MaxQuant `summary.txt` gives Multiplicity 2 and Labels1 = Lys8 for both searches.

## Design (annotated part)

The cells are hTERT-RPE1 (CVCL_4388). A non-human-targeting (NHT) control and a polyclonal CRISPR/Cas9 USP32 knockout were SILAC-labelled. The lysates were mixed 1:1. One SILAC sample set was measured as three technical replicates.

## SDRF

`annotations/PXD024211.sdrf.tsv`: 72 rows × 47 columns.

Templates:
- ms-proteomics v1.2.0, because the data are MS proteomics;
- human v1.1.0, because the cells are human;
- cell-lines v1.1.0, because the samples come from a cell line.

How the file was built:
- `sdrf-tools build` was run twice, once per sub-experiment. The two searches differ: GG(K) is only in the diGly search, and the second enzyme is only in the diGly digest.
- `postbuild.py` then concatenated the two parts, which have identical headers. It also inserted a second `comment[cleavage agent details]`: Lys-C on the diGly rows, `not applicable` on the total-proteome rows.

Values:
- Modifications:
  - Carbamidomethyl C (Fixed);
  - Oxidation M, Acetyl Protein N-term, GG K (diGly rows only), Label:13C(6)15N(2) K (UNIMOD:259) (all Variable).
- Search settings: fragment tolerance 20 ppm; precursor tolerance `not available`.
- Instrument and method: Q Exactive HF, DDA, HCD, Orbitrap MS2.
- Reagents: DTT, chloroacetamide.
- Fractionation: SCX for the diGly rows, SDS PAGE for the total-proteome rows.
- Cell line: female, 1Y, infant, pigmented layer of retina, retinal pigment epithelial cell, normal, DMEM.

## Validation

See `PXD024211.validation.txt`.
- `parse_sdrf validate-sdrf`, `structure`, `check`, `schema-check` and `manifest-coverage` all pass.
- `reconcile` exits 1 on one finding, which I refuted in the validation file. It reads the reserved word `not applicable` in the second cleavage column as an enzyme. It also applies the project-level "LysC and trypsin" sentence to the in-gel, trypsin-only total-proteome rows. The diGly rows alone reconcile cleanly (exit 0).
- `convert-openms` fails as expected, because the precursor tolerance is `not available`.

## Open items

- **36 Mila files blocked.** "Mila" is Mila Basic, who works on USP11 in the same lab. The total-proteome USP11 H/L ratios (0.61 and 0.42) hint at USP11 depletion in the heavy channel, but nothing documents it.
- **Precursor tolerance** is `not available`: no mqpar.xml was deposited.
- **MaxQuant version conflict:** PRIDE and the thesis say 1.5.1, while `parameters.txt` says 1.6.1.0.
- **R10 not in the SDRF:** heavy arginine was used in culture but was not a search label, so it is not listed as a modification.
- **USP32 total-protein H/L is about 1 in a1–a3.** The knockout is a polyclonal pool. The channel orientation therefore rests on the thesis statement and the diGly-site ratios.
- **Replicate pairing:** total-proteome a1–a3 are assumed to pair with diGly A1–A3 by number.
- **Left as `not available`:** passage number, ancestry category and individual.
- **Undeposited runs:** 10 "GG_sens" runs appear in `summary.txt` but were not deposited.
