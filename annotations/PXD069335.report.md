### Why 10 blanks excluded (`cell line` reserved-word trap, #35 B1)
The `0cell` runs are negative-control wells into which **zero cells were sorted** (file tokens `0cell_H1..H5`, `0cell_G1..G5`; a matching `SP006_0cell` Spectronaut result confirms they were processed as a distinct no-cell set). Under the `cell-lines` template, `characteristics[cell line]` is **required and forbids both reserved words** (`allow_not_available=false`, `allow_not_applicable=false` in the resolved template). A well containing no cell has no valid cell-line identity, and annotating it as `NCI-H460` would fabricate a cell that is not present. This is exactly the documented exclusion criterion, so the blanks are left out of the SDRF rather than mis-annotated.

### Why 27 static-spray CV-scan runs excluded
`SP008_staticspray_*_CVscan_Tout{80,100}` are **direct-infusion (static nano-spray, no LC gradient) compensation-voltage scan** runs used to characterize FAIMS transmission windows (the paper's Fig. 1 CV curves; a PDF report accompanies each run). They are not proteome LC–MS acquisitions: there is no DIA/DDA proteomics acquisition that fits `comment[proteomics data acquisition method]` (required; forbids both reserved words), and forcing a DIA label onto an infusion CV-scan would be false. They share the SP008 prep code with the HeLa dilution series, so the sprayed material is the HeLa Pierce standard, but the run type is instrument characterization, not a sample measurement. **This is the judgement call I most want a reviewer to attack** — the alternative reading of the brief ("annotate every deposited run") would include them, but only at the cost of inventing an acquisition-method term they don't have.

## Key per-arm decisions (evidence)

### NCI-H460 single cells (28 rows)
- **Cell line identity — verified live, not a derivative.** Cellosaurus `CVCL_0459` ID = *NCI-H460* (H460/NCI-H460 are the same line; "H460" is a listed synonym, not a distinct derivative). Male; large cell lung carcinoma; derived from a metastatic pleural effusion. Paper states H460 from ATCC via IMBA Vienna. `cell line = NT=NCI-H460;AC=CLO:0008089` (OLS-verified), `cellosaurus accession = CVCL_0459`.
- `organism part = lung` (UBERON:0002048) — organ of origin of the carcinoma. The physical derivation site (metastatic pleural effusion, UBERON:0000175) is noted here but not forced into `organism part`, which expects a tissue/organ; it is left out rather than mis-mapped.
- `disease = lung large cell carcinoma` (MONDO:0003050), matching Cellosaurus NCIt C4450.
- `sample type = single cell` (PRIDE:0000897); `single cell isolation protocol = cellenONE` (fixed-list value; paper: cellenONE robot, image-based sorting, 20–35 µm diameter gate); `cells per well = 1`; unique `cell identifier`/`source name` per cell (`H460_out{100,80}_{well}`); each cell is its own `biological replicate`.
- **No carbamidomethyl.** Paper: *"carbamidomethylation of cysteines … removed for single cell searches as no alkylation step was performed."* One-Pot prep has no reduction/alkylation. The Carbamidomethyl `modification parameters` column is therefore `not applicable` for every single-cell row; only `Oxidation (M, Variable)` is declared.

### HeLa Pierce digest dilution series (60 rows)
- **Identity = HeLa S3, not parental HeLa.** Pierce HeLa Protein Digest Standard (Thermo 88328) is the **HeLa S3** clone — `CVCL_0058` / `EFO:0002791` (`cell line = NT=HeLa-S3;AC=EFO:0002791`), a validator-clean-but-important distinction. Cellosaurus `CVCL_0058`: female, 30Y6M donor, HPV-related endocervical adenocarcinoma. `organism part = uterine cervix` (UBERON:0000002); `disease = endocervical adenocarcinoma` (MONDO:0000554).
- **Dilution standards, not cells.** Loads span 250 pg (the "single-cell equivalent") to 16 ng of a commercial digest. Per the mass-not-count rule: `sample type = standard` (PRIDE:0000908), `cells per well = not applicable`, `cell identifier = not applicable`, `single cell isolation protocol = not applicable`. All 60 share one biological source → `biological replicate = 1`; the `_01/_02/_03` suffix → `technical replicate` 1–3.
- **Carbamidomethyl present.** The commercial Pierce digest is iodoacetamide-alkylated (PRIDE `modifications` lists "iodoacetamide derivatized residue"), and the paper searched bulk data with static Carbamidomethyl. `Carbamidomethyl (C, Fixed)` + `Oxidation (M, Variable)` declared.
- **Isolation window width is per-file.** The filenames encode the DIA method (`mz{N}` = isolation width in Th, `{K}ms` = maxIT). `comment[isolation window width]` was set from the `mz` token per run (4/5/8/10/20 Th). Single cells: 20 Th (paper: "DIA window size of 20 Th and maxIT 40 ms").

## Values deliberately left `not available` / `not applicable` (and why)
- `age` (H460 rows) = `not available` — Cellosaurus records H460 donor age as unspecified.
- `age` (HeLa rows) = `30Y6M` — Cellosaurus donor age for CVCL_0058 (accepted by `parse_sdrf`; note the repo's `tools score` wrongly rejects compound ages, but that is a known tool defect, not a validity issue).

- Carbamidomethyl column = `not applicable` for single cells (see above).

## Conflicts / cross-source reconciliation
- PRIDE `modifications` = {monohydroxylated residue (Oxidation), iodoacetamide derivatized residue (Carbamidomethyl)}. These map to the two mods declared, but PRIDE gives no per-arm resolution; the **paper Methods** (raw-data-precedence tier) is what establishes that Carbamidomethyl applies to the HeLa/bulk arm only and is absent from single cells. Precedence honored: paper Methods > PRIDE field.
- PRIDE instrument (`Orbitrap Astral`) agrees with the paper and file naming (`Astral1`); no conflict.
