## 1. Study and publication

- **Title:** "A zwitterionic detergent and catalyst-based single-cell proteomics using a loss-free
  microhole-collection disc" (microHOLD).
- **Publication:** Yeo S, Jang J, Jung HJ, Lee H, Lee S, Choe Y. *Anal Chem* 2024;96(29):11690-11698.
  PMID 38991018, DOI 10.1021/acs.analchem.4c00158. **Closed access** — no PMCID, not in Europe PMC OA,
  Unpaywall + Europe PMC returned no PDF, ACS/ResearchGate pages are paywalled (HTTP 403). **Only the
  abstract was available.** The abstract gives no per-channel design.
- **Method:** single-cell TMT proteomics performed in a "micro-HOLe Disc": one-pot lysis + trypsin +
  TMT labeling using a Quadrol catalyst + SB3-14 zwitterionic detergent, **no heat, no reduction, no
  alkylation step**. Application: proteome reprogramming of hormone-sensitive prostate cells toward a
  castration-resistant state.

## 2. Templates chosen and why

`ms-proteomics` (v1.1.0) + `cell-lines` (v1.1.0) + `single-cell` (v1.0.0).

- **ms-proteomics** — LC-MS/MS bottom-up proteomics (base usable-alone MS template).
- **cell-lines** — samples are immortalized prostate cancer cell lines → licenses
  `characteristics[cell line]`, `[cellosaurus accession]`, `[cellosaurus name]`.
- **single-cell** — TMT single-cell proteomics → licenses `[single cell isolation protocol]`,
  `[cell identifier]`, `[cells per well]`, `[sample type]`, `comment[reference channel]`,
  `comment[carrier channel]`.
- **`human` was deliberately NOT declared.** It would force `characteristics[age]` and
  `[sex]` as *required* on every row, which the U118 rows (unidentified donor) cannot satisfy without
  reserved words. `characteristics[organism]=Homo sapiens` is already licensed by the base layer, so
  `human` adds nothing needed here. Cell-line donor demographics were therefore omitted.

## 4. How the channel→sample map was recovered (key evidence for the annotated arm)

PRIDE metadata gives **no** per-channel design. The map was reconstructed **from the deposited
Proteome Discoverer `.msf`** (`230207_39_Thermo_230120_TMT.msf`) by reading its SQLite pages over
HTTP byte-range requests (the file is 10.5 GB; never downloaded whole):

- `WorkflowInputFiles` table → 39 raw files `D:\YSE\230120_YSE_TMT_PCaANDu118\230120_{1..39}.raw`,
  all "Q Exactive Plus Orbitrap".
- `StudyInformation` table → a real, submitter-defined study with **four sample groups**
  (`1_LNC3000`, `2_LNCaP`, `3_C4`, `4_U118`), TMT quan expressed as `TMT10plex`, and per-file
  per-channel labels of the form `230120_N - [126]`. Pairing every channel label with its sample group
  gave a **uniform** assignment across all 39 files (39/39 agreement per channel):

| TMT channel | Sample group | Interpretation | cells/well | sample type |
|---|---|---|---|---|
| 126 | 2_LNCaP | LNCaP single cell | 1 | single cell |
| **127N** | **1_LNC3000** | **LNCaP 3000-cell reference pool** | **3000** | **reference** |
| 127C | 3_C4 | LNCaP-C4 single cell | 1 | single cell |
| 128N | 2_LNCaP | LNCaP single cell | 1 | single cell |
| 128C | 3_C4 | LNCaP-C4 single cell | 1 | single cell |
| 129N | 2_LNCaP | LNCaP single cell | 1 | single cell |
| 129C | 3_C4 | LNCaP-C4 single cell | 1 | single cell |

| 130C | 4_U118 | "U118" single cell | 1 | single cell |
| 131 | 4_U118 | "U118" single cell | 1 | single cell |

So each of the 39 TMT10plex sets = 1 LNCaP 3000-cell reference + 3 LNCaP + 3 C4 + 3 "U118" single

`(4_U118)/(2_LNCaP)` — consistent with this reading. This is deposited submitter metadata, not a
Proteome-Discoverer "Sample, n/a" default, so it is a genuine map, not a fabrication.

## 5. Cell-line identity decisions (verified live via Cellosaurus + OLS)

- **LNCaP** (`2_LNCaP`, and the `1_LNC3000` reference pool) → `characteristics[cellosaurus accession]`
  **CVCL_0395**, name "LNCaP", disease prostate carcinoma (MONDO:0005159), organism part prostate gland
  (UBERON:0002367), cell type epithelial cell (CL:0000066). NB: the submitter wrote plain "LNCaP";
  Cellosaurus `CVCL_0395` is the exact-name parent. The widely-used ATCC LNCaP is the sub-clone
  "LNCaP clone FGC" (CVCL_1379 / EFO:0005726) — a hierarchical child. I used the parent `CVCL_0395` to
  match the submitter's literal label; a reviewer may prefer CVCL_1379.
- **LNCaP C4** (`3_C4`) → **CVCL_4783** (Cellosaurus synonym "C4"), same prostate-carcinoma block. An
  androgen-independent LNCaP derivative — fits the paper's "hormone-sensitive → castration-resistant"
  framing. No EFO/CLO term exists (hence the validator warning); the CVCL is authoritative.
- **"U118"** (`4_U118`) → **UNRESOLVED.** The only Cellosaurus match for the token "U118" is
  **U-118MG (CVCL_0633), a glioblastoma/astrocytoma line** — which does not fit a prostate study.
  Because the paper is inaccessible I cannot confirm whether "U118" is a prostate subline under an
  internal code or literally U-118MG (some single-cell method papers deliberately spike in a very
  different cell type to demonstrate single-cell resolution). I therefore did **not** assert a
  Cellosaurus accession: the U118 rows carry `cell line = U118` (the deposited label, real metadata)
  with `cellosaurus accession / cellosaurus name / disease / organism part / cell type = not
  available`. **This is the #1 item for a reviewer to attack.**

## 6. Conflicts found (PRIDE vs raw data / deposited search) and how resolved

Resolved by precedence **raw data > deposited search > PRIDE fields**:

1. **Instrument.** PRIDE `instruments = "Q Exactive HF"` (and the screening hint said HF). **WRONG.**
   Every `.raw` header (byte-range, utf-16) and every `.msf` `WorkflowInputFiles` row say **"Q Exactive
   Plus Orbitrap"**. The sample-processing protocol text also says "Q-Exactive Plus". → annotated
   **Q Exactive Plus, MS:1002634**.
2. **TMT plex.** PRIDE `modifications = "TMT6plex-126 reporter…"` implies 6-plex. **WRONG.** The
   `.msf` `StudyInformation` says `TMT10plex` and carries all ten channels 126/127N/127C/128N/128C/
   129N/129C/130N/130C/131. → annotated as **TMT10plex** (label channels + `UNIMOD:737` "TMT6plex",
   which is the correct UNIMOD id for the 6/10/11-plex reporter+balance tag; **not** TMTpro
   UNIMOD:2016 — verified there is no 132/133/134 channel and no TMTpro string).
3. **Screening hint cell lines (PC3/LNCaP/DU145).** The deposited study shows **LNCaP, LNCaP-C4,
   "U118"** — not PC3/DU145. Hint correctly flagged as "verify, do not trust".

## 8. `not available` / `not applicable` inventory and why

- **U118 rows** — `cellosaurus accession`, `cellosaurus name`, `disease`, `organism part`, `cell type`
  = `not available`: submitter label "U118" cannot be resolved to a prostate Cellosaurus entry and the
  paper is closed (see §5). `cell line` is kept as the literal "U118" (that column forbids reserved

- **Reference channel (127N, LNCaP 3000-cell pool)** — `single cell isolation protocol` and
  `cell identifier` = `not applicable` (a 3000-cell pool is not an isolated single cell);
  `pooled sample = pooled`, `biological replicate = pooled`, `cells per well = 3000`,
  `sample type = reference`.
- **`comment[carrier channel] = not applicable`** on all rows: the design has a *reference*
  (normalization) channel, not a separate high-abundance carrier/boost channel. `reference channel =
  TMT127N` on every row.
- **reduction/alkylation reagent = not available** (CORRECTED — see Correction below). The first pass
  assumed microHOLD omits reduction/alkylation and set these `not applicable` with no Carbamidomethyl.
  That assumption is unsupported (the paper is closed) and is contradicted by the deposited search.

## Correction (post-review)
An independent reviewer read the deposited PD `.msf` SequestHT search node directly (SQLite over
HTTP byte-range) and found **static Carbamidomethyl (C, +57.021)** and **dynamic Oxidation (M,
+15.995)** — the primary technical evidence, which outranks the "microHOLD omits alkylation"
assumption (the paper is closed and states nothing accessible on this). Fixes applied to all 390 rows:
added `comment[modification parameters] = NT=Carbamidomethyl;AC=UNIMOD:4;TA=C;MT=Fixed` and
`NT=Oxidation;AC=UNIMOD:35;TA=M;MT=Variable` (alongside the two TMT6plex/UNIMOD:737 entries), and
changed `comment[reduction reagent]` / `comment[alkylation reagent]` from `not applicable` to
`not available` (alkylation occurred per the search, but the specific reagent is not stated in any
accessible source). Re-validated per template (parse_sdrf exit 0 for ms-proteomics/cell-lines/single-cell).

## 10. Judgment calls a reviewer should attack hardest

1. **U118 identity (highest priority).** Left `not available` rather than assert U-118MG glioblastoma.
   If the closed paper says "U118" is a specific prostate line (or genuinely U-118MG), those 117 rows
   need real disease/organ/CVCL. Getting the paper Methods/SI is the single unblock.
2. **`single cell isolation protocol = manual picking`.** The fixed enum
   (FACS/cellenONE/microfluidics/LCM/manual picking/nanoPOTS/droplet/acoustic) has **no exact match**
   for microHOLD's limiting-dilution dispensing into disc wells. "manual picking" is the least-wrong
   fixed value (microHOLD explicitly avoids specialized equipment); it is an approximation.
3. **LNCaP = CVCL_0395 vs CVCL_1379 (FGC clone).** Chose the literal-name parent; the ATCC standard is
   the FGC clone.
4. **`cells per well = 1`** for single cells despite limiting-dilution (Poisson) dispensing.
5. **Reference vs carrier semantics** for the 3000-cell LNCaP channel (annotated as `reference`).
6. **Scope:** only 39/326 files annotated; the `230323/230324` arm is very likely the same layout but
   was left out because the file↔channel binding could not be recovered cleanly from the 18 GB `.msf`.
