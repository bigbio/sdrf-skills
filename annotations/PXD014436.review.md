## Findings

### 1. [minor] downstream-usability — comment[precursor mass tolerance] rows 35-331 (7 of 11 searches, 297 rows)

**Issue / fix:** 'not available' makes parse_sdrf convert-openms (quantms) fail. It is spec-permitted (recommended column, reserved word allowed) and honest: only 4 mqpar.xml files were deposited and they disagree (0.006 Da vs 10 ppm). Fix only if new evidence appears (e.g. author-supplied mqpar.xml); otherwise keep and keep the limitation in the report.

**Evidence:** Reviewer-extracted parameters.txt of all 11 searches lacks peptide tolerance; mqpar.xml present only for lepA_2plex1/rsgA_3plex2-4; convert-openms exit 1 'Cannot read precursor mass tolerance: not available'.

### 2. [minor] ontology-convention — comment[dissociation method] rows 1-448

**Issue / fix:** MS:1000422 beam-type CID is defensible for the Impact II collision cell, but curated Bruker Q-TOF precedents use NT=collision-induced dissociation;AC=MS:1000133, and spec README equates MS:1000422 with HCD for downstream tools. Consider MS:1000133 for consistency with curated datasets.

**Evidence:** sdrf-annotated-datasets: JPST001281 (impact II), PXD001073/PXD003354 (maXis), PXD001521-3 (maxis 4g), JPST000958 (maXis impact) all use MS:1000133; paper states only 'collision energy ranged from 23 to 65 eV'.

### 3. [minor] file-mapping — comment[data file] rows 1-448

**Issue / fix:** Values are .d folders inside 11 multi-run ZIP bundles; the deposited filename (e.g. lepA_2plex-1.zip) appears nowhere in the SDRF, only implicitly via comment[sample preparation batch] (lepA_2plex1). Acceptable per spec (.d referenced directly) and curated PXD004817 (inner RAW names of zipped deposits), but consider stating the container mapping in the report so consumers can fetch runs.

**Evidence:** PRIDE files/all: 11 RAW-category ZIPs (56-124 GB) containing 13-19 .d each; base template: 'comment[data file] must exactly match the filename deposited'.

### 4. [minor] experimental-design — characteristics[genotype]/factor value[genotype] = 'wild type' rows with MRG06 (rsgA series, 91 rows)

**Issue / fix:** MRG03 (lepA series control) and MRG06 (rsgA series control) are distinct strains (MRG06 has the lysA kan marker excised) pooled into one 'wild type' level, and 'wild type' is relative (both are Lys-/Arg- auxotrophs carrying empty pWSK29). Paper itself calls both WT and comparisons are within-run SILAC ratios, so not blocking; optionally note the vector/auxotroph background in the report.

**Evidence:** Paper SI Methods: MRG03 = MRG01 (dlysA::kan argE::Tn10) + pWSK29; MRG06 from MRG01 with kan removed + pWSK29.

### 5. [minor] optional-metadata — file (no comment[collision energy] / comment[ms1 scan range])

**Issue / fix:** Paper states collision energy 23-65 eV and full scan m/z 200-2,000; optional columns could carry the scan range (200m/z-2000m/z). Not required.

**Evidence:** PMC5293072 SI Methods, Mass Spectrometry paragraph.

### 6. [minor] provenance — comment[sdrf annotation tool] rows 1-448

**Issue / fix:** NT=sdrf-skills;VV=v0.1.0 matches pyproject.toml but the plugin manifest (.claude-plugin/plugin.json) says 0.2.0; align on the shipped plugin version.

**Evidence:** pyproject.toml version 0.1.0; .claude-plugin/plugin.json version 0.2.0.

### 7. [minor] naming — source name rows 1-448

**Issue / fix:** audit-existing flags source names not following <ACCESSION>-Sample-<n>; the descriptive search_strain_fraction names follow curated PXD004650 and are informative. No change required.

**Evidence:** sdrf-tools audit-existing --json finding source_name_convention (minor).
