# PXD006395: SDRF annotation report

**Status: BLOCKED. No SDRF was built.** The dataset is genuine duplex SILAC (Arg10/Lys8, MaxQuant 1.5.2.8, Q Exactive HF), in three MaxQuant searches: 35 insulin phosphoproteome raws, 21 palmitate phosphoproteome raws and 9 proteome raws (65 RAW in total). No accessible source says which SILAC channel holds which condition (vehicle / insulin; untreated / palmitate), or what the run codes A–H × 1–3 and `<n>_<m>` mean. Campaign rules 6–7 therefore block all 65 runs. The details are in `annotations/BLOCKED.md`, section "PXD006395".

## Study
Li Z, Lai ZW, Christiano R, Gazos-Lopes F, Walther TC, Farese RV. "Global Analyses of Selective Insulin Resistance in Hepatocytes Caused by Palmitate Lipotoxicity." *Mol Cell Proteomics* 2018;17(5):836-849, doi:10.1074/mcp.RA117.000560, PMID 29414761, PMC5930403.

The cells are **HepG2, a human hepatoblastoma cell line**, not primary hepatocytes. The PRIDE protocol says "HepG2 cells were SILAC … labeled"; the raw file names contain `HepG2`; Cellosaurus CVCL_0027 gives Hep-G2, male, 15Y, hepatoblastoma. PRIDE's organism part "hepatocyte" is a submitter dropdown value. The templates would be ms-proteomics + human + cell-lines.

## Evidence examined
- **PRIDE v3 project record** and the paginated file list (68 files: 65 `.raw` + 3 MaxQuant zips; every entry's `projectAccessions` contains PXD006395).
  - The sample protocol names four conditions (palmitate-treated or untreated cells, each stimulated with vehicle or 100 nM insulin for 20 min) and a 1:1 light:heavy mix.
  - It assigns no condition to either label.
- **Paper: not reachable without a bot-check bypass**, which I did not attempt.
  - It is not in the Europe PMC OA subset: `fullTextXML` returns HTTP 500 and `supplementaryFiles` says "not open access".
  - There is no PMC OA S3 copy, and NCBI efetch returns only the abstract.
  - The Unpaywall PDF route (Europe PMC render) and mcponline.org both return a Cloudflare 403. PMC returns a reCAPTCHA page, and ScienceDirect returns 403.
  - No Data-in-Brief, dataset descriptor or preprint exists in Europe PMC.
- **MaxQuant zips.** I listed each zip's central directory over HTTP ranges, then read `mqpar.xml`, `summary.txt` and `parameters.txt` from all three searches.
  - All three: Multiplicity 2, Labels1 `Arg10;Lys8`.
  - Search settings: Trypsin/P; fixed Carbamidomethyl (C); variable Acetyl (Protein N-term) and Oxidation (M), plus Phospho (STY) in the two phospho searches; no multi modifications; tolerances 4.5 / 20 ppm.
  - The experiments are A1–H3 (insulin phospho), A1–F3 (palmitate phospho) and 1A–3C (proteome).
  - One anomaly in the insulin search: raw `…_D2` is mapped to experiment D1, and raw `…_D3` to D2.
- **Raw headers.** I range-read one raw per search. They show the instrument (Q Exactive HF) and the method `2014_08_14_265min.meth`, but no sample description.
- **Orientation check from the data.** The files are `scratchpad/b11-PXD006395/orientation.txt` and `orientation_proteome.txt`; the downloaded tables were deleted afterwards, and their hashes are in `bigtables.sha256`.
  - **Insulin search:** canonical insulin sites (AKT1S1 T246, GSK3B S9, TSC2 T1462, FOXO3 S253) are 2–4× higher in H in all 24 experiments. This suggests heavy = insulin.
  - **Palmitate search:** the same sites are mildly lower in H. This fits heavy = palmitate + insulin, but the design is not stated.
  - **Proteome:** the ratios are flat.
  - Rule 6 forbids a map built from data alone.
- **Duplicate and existing-annotation check:** the dataset is in neither `annotations/` nor `sdrf-annotated-datasets/datasets/`.

## What would unblock it
The paper's Experimental Procedures / Fig. 1 / supplementary tables, or an author statement, giving for each search:
- the light and heavy conditions;
- the meaning of A–H, 1–3 and `<n>_<m>`. A–H might be the eight sequential TiO2 rounds and 1–3 the biological replicates, but this is unconfirmed.

The paper is CC-BY, so a human can fetch it from mcponline.org or PMC.

The planned SDRF would have 130 rows (65 runs × 2 channels) and these settings:
- **Templates and cell line:** ms-proteomics v1.2.0 + human + cell-lines; cell line Hep-G2.
- **Factors:** treatment, with `untreated` controls.
- **Modifications:** set per search.
- **Labels:** Arg10 = UNIMOD:267 and Lys8 = UNIMOD:259, `MT=Variable`.
- **Cleavage agents:** Lys-C + trypsin for the phospho arms; trypsin for the proteome arm.

## Validation
No validation was run, because no SDRF exists. No `.sdrf.tsv`, `.evidence.json` or `.validation.txt` was written, following the fully blocked precedents (PXD002454, PXD008100, PXD000958).
