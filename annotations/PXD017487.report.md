## Design and scope

- **Long-term proteome (annotated).** A375 cells, 2-plex SILAC: light (Lys0/Arg0) and heavy (Lys8/Arg10).
  Three MaxQuant experiments `PROlong_01..03`. Each is one light + one heavy culture mixed 1:1, run on
  SDS-PAGE and cut into 8 gel slices, giving 8 RAW files per experiment (24 RAW in total, × 2 channels = 48 rows).
  - Light = DMSO vehicle (`untreated`, rule 4), biological replicates 1–3: 24 rows, sources `A375_DMSO_rep1..3`.
  - Heavy = A922500 (DGAT1 inhibitor) for 72 h, biological replicates 1–3: 24 rows, sources `A375_A922500_72h_rep1..3`.
- **Phosphoproteome (not annotated, 6 RAW).** Triple SILAC (L Arg0/Lys0, M Arg6;Lys4, H Arg10;Lys8), TiO2-enriched,
  2 RAW each for STY_01..03. Left out: see "Partial scope" below.
- **Searched but never deposited:** the 24 `0_30_120_PRO` runs (the short-term proteome) appear in
  `experimentalDesignTemplate_phosphoproteome.txt` and the authors' `summary_ST.txt`, but they are not in PRIDE.
- Deposited vs annotated: 30 RAW deposited. 24 are annotated, 6 are blocked. The 7 search-output files are not data files.

## Key decisions and evidence

1. **Channel → condition map (proteome).** The bioRxiv preprint (doi:10.1101/2020.06.23.166603) states the map
   outright: Fig. 6A shows A375 Light = DMSO, Heavy = A922500, 72h, in-gel digestion, QE-HF, MaxQuant.
   Four further sources agree: (a) the authors' analysis code
   (`github.com/JoWatson2011/DGAT_2019@1f9fafa`, `src/Proteomics/4_proteinGroupsLT_DJWQC.R:89`) names the H/L ratio `PRO_72h`;
   (b) the file names read `0_72`; (c) the PRIDE keywords name A922500 (spelled "a229500") and A375; (d) the Fig 5A legend
   describes a whole-proteome of SILAC A375 cells with DMSO n = 3 vs A922500 n = 3.
   **I checked the map against the deposited ratios** (`proteinGroups.txt`, H/L normalized, all 3 replicates; output in
   `labeldir_check.txt`). These are the changes the paper reports for A922500:
   - HMOX1 is up 4.7–5.8×. NQO1 (1.4×), SQSTM1 (1.7–1.9×) and SOD2 (1.2–1.3×) are also up (NRF2 targets).
   - CPT1A, ACADVL and ACSL1 are up 1.2–1.5× (fatty-acid oxidation).
   - PLIN2 is down to 0.51–0.54× (lipid-droplet loss).
   - 111 proteins have a mean ratio above 1.5, against 114 up-regulated proteins in the paper.

   So heavy = A922500. Not every marker agrees: SESN2 (0.84–1.04) and SOD1 (1.02–1.16) are not clearly up, although
   the paper reports both by western blot in another experiment (Fig S6B).
2. **Search parameters come from the deposited MaxQuant output, not the prose.** `summary_LT.txt` gives the
   modifications: Carbamidomethyl (C) fixed; Oxidation (M), Acetyl (Protein N-term) and Deamidation (NQ) variable;
   label Arg10;Lys8. The SILAC labels are encoded `MT=Variable` (rule 11) as UNIMOD:267 (R) and UNIMOD:259 (K).
   The fragment tolerance of 20 ppm comes from `parameters.txt`. The precursor tolerance of 7 ppm comes from the
   paper only, because no `mqpar.xml` was deposited.
3. **Cleavage agent.** Trypsin (MS:1001251) is the in-gel digestion enzyme. The search rule was Trypsin/P (rule 2).
   The `reconcile` MINOR finding (cleavage agent unsupported) is a false positive. It is refuted in `validation.txt`.
4. **Instrument.** Q Exactive HF (MS:1002523), read from 3 range-read RAW headers. The paper and PRIDE agree.
5. **Cell line.** A375 is ATCC CRL-1619 (Key resources), Cellosaurus CVCL_0132 / A-375. The donor values come from
   Cellosaurus:
   - 54Y, female, so developmental stage is `adult`.
   - Population "Caucasian" → `European ancestry`.
   - Site "Leg, skin" → `skin of leg` (UBERON:0001511).
   - Disease `amelanotic melanoma` (NCIt C3802 → MONDO:0002971).
6. **Culture medium.** The Methods state SILAC DMEM for A375, so the value is `Dulbecco's Modified Eagle Medium`
   (NCIT:C185409). The Key resources table also lists "RPMI 1640 Medium for SILAC". I preferred the A375-specific
   Methods text.
7. **Treatment terms.** `untreated` follows the template example and rule 4; the actual control was the DMSO vehicle.
   `A922500` has no NCIT/EFO term (OLS returns 0 hits), so it is free text. parse_sdrf gives 2 warnings for these values.
8. Reduction/alkylation: DTT / chloroacetamide (Methods). Fractionation: SDS PAGE. HCD, 28 NCE, Orbitrap MS2, DDA top 12.

## Stated vs inferred

- **Stated:**
  - From the paper: SILAC labels, fractionation, digest, reagents, instrument, DDA, collision energy, precursor tolerance and the DMSO/A922500 design.
  - From the deposit: files, fractions, experiments, mods and fragment tolerance.
  - From Cellosaurus: donor facts.
- **Stated in a figure:** light = DMSO and heavy = A922500 72 h (preprint Fig. 6A). The code, the file names and the data direction agree.
- **Inferred, with the evidence above:**
  - The 72 h duration applies to the heavy channel only.
  - The collision energy "28" is NCE.

## Partial scope (open item)

The 6 STY runs are omitted under rule 7.

**What is stated.** The bioRxiv preprint was read in full (53-page PDF; the external reviewer retrieved it with
`get_pdf_by_unpaywall`, and I verified its title and DOI myself). Lines 229–231 say "phosphorylated peptides from
SILAC-labelled DGAT1high A375 melanoma cells following 4h treatment with A922500". Fig. 3A (p.49) shows
A375 Light = DMSO, Heavy = A922500, 4h → QE-HF → MaxQuant. The agent is therefore known.

**The real blockers:**

1. **The medium channel is undocumented.** The deposit is triple SILAC (`summary_ST.txt` Multiplicity 3,
   M = Arg6;Lys4; reagents CLM-2265 and DLM-2640 are in the Key resources table). No text or figure describes a
   medium channel; the only trace is the code name `STY_30m`.
2. **The time points conflict.** The file names say `0_30_120` (heavy = 120 min). The preprint text, Fig. 3A and the
   authors' code (`STY_4h`) say 4 h.
3. **The stated map fails the rule-6 data check.** In `Phospho (STY)Sites.txt`, RPS6 heavy/light (normalized) is up
   in all 3 experiments, while the preprint reports a loss of pS6 within 2–4 h of A922500 (lines 235–238, Fig. 3B):
   - S235: 1.42 / 1.55 / 1.49
   - S236: 2.17 / 2.29 / 2.02
   - Medium/light is 0.88–1.18. Output: `rps6_check.txt`.

**Unblocked by:** author confirmation of the medium-channel condition and of the light/heavy orientation and time
points. For the record, their technical values would differ from the
proteome rows: variable Phospho (STY) and Gln->pyro-Glu, no Deamidation, plus Label:13C(6) R (UNIMOD:188) and
Label:2H(4) K (UNIMOD:481). Rule 5 would require separate builds for the two arms.

## Limitations (also in the manifest)

- techsdrf is not installed. RAW headers were range-read instead.
- parse_sdrf exit 0 shows the file is well-formed, not that its values are true.
- The paper gives MaxQuant 1.5.6.5, but the deposit says 1.6.2.6. The deposit was preferred; the version is not in the SDRF.
- The dose (30 µM) is not encoded.
- The GitHub analysis repo was read via an anonymous public clone.

## Judgement calls for the reviewer to attack

1. **Leaving out the phospho arm (6 RAW).** The agent (A922500) and a two-channel map are stated. I left the arm out
   because three things contradict that map: the medium (Arg6/Lys4) channel appears in no text or figure, the
   file names say 120 min while the sources say 4 h, and RPS6 pS235/236 heavy/light runs up although the preprint
   reports pS6 loss.
2. **Light = DMSO / heavy = A922500 72 h.** This is stated in preprint Fig. 6A and agrees with the code names, file names and data.
   The NRF2/FAO/PLIN2 signature is strong, but SESN2 and SOD1 do not follow the paper's claim.
3. **The values I chose:**
   - `untreated` for a DMSO vehicle control.
   - `sampling time` = 72 hour on the heavy rows only.
   - A 7 ppm precursor tolerance taken from the prose, with no deposited mqpar.
   - DMEM over the RPMI-for-SILAC entry in the Key resources table.
