- **Publication:** Cell 2025, PMID **40168994**, DOI 10.1016/j.cell.2025.03.002. bioRxiv preprint DOI **10.1101/2024.05.30.596745** (green OA; read in full for the Methods). PRIDE `publications` list was **empty**; the paper was located by title search and confirmed.

## Key decisions and evidence
- **SILAC labels (verified from Methods + `data_processing_protocol`, not guessed):** heavy medium = **L‑lysine‑¹³C₆¹⁵N₂ (Lys8)** and **L‑arginine‑¹³C₆¹⁵N₄ (Arg10)**. Encoded as variable `comment[modification parameters]`: `NT=Label:13C(6)15N(2);AC=UNIMOD:259;TA=K;MT=Variable` and `NT=Label:13C(6)15N(4);AC=UNIMOD:267;TA=R;MT=Variable` (UNIMOD:259/267 verified live via OLS). `comment[label] = SILAC` (PRIDE:0000315), one value per run — the light/heavy channels are the pulse readout **within** each single sample, not separate samples.
- **No Carbamidomethyl / no alkylation:** the paper states *"carbamidomethylation was not included in the fixed modifications"* and the digestion buffer (0.2 % DDM, TEAB, LysC+trypsin) has **no reduction/alkylation step**. The reflex Carbamidomethyl annotation was deliberately omitted (would be wrong on every row).
- **Other search modifications:** Spectronaut default variable mods Oxidation (M, UNIMOD:35) and Acetyl (Protein N‑term, UNIMOD:1); both confirmed by PRIDE `modifications` (*monohydroxylated / acetylated residue*). UNIMOD:1/21/35 verified (Acetyl≠Phospho).
- **Enzymes:** dual LysC + Trypsin → two `comment[cleavage agent details]` columns (MS:1001309, MS:1001251).
- **Cell‑line identity (ATCC, per Methods):** HeLa→CVCL_0030 (parental HeLa, not S3), HEK293T→CVCL_0063, both from `tools cellline` + Cellosaurus. **Bortezomib smart‑OLS trap avoided:** default hit was *"Bortezomib/Rituximab Regimen"* (NCIT:C188467) — corrected to plain **Bortezomib NCIT:C1851**.
- **iPSC line = hi1240** (Methods: *"Human iPSCs hi1240"*, "hi12"). **Not in Cellosaurus** (confirmed) → `cellosaurus accession/name = not available`; `cell line = hi1240` (free text). EBs are embryoid bodies differentiated from hi1240 → same `cell line`, `cell type = not available` (heterogeneous 3‑germ‑layer population), `organism part = not applicable`.
- **hFF:** stated only as *"hFF cells (ATCC)"* / *"homogeneous human foreskin (hFF) cell line"* with no catalog number → specific Cellosaurus line **not determinable**; `cellosaurus accession/name = not available`, `cell line = hFF`. `organism part = prepuce of penis` (UBERON:0001332), `sex = male` (foreskin), cell type = fibroblast.
- **Isolation / cell counts:** cellenONE‑sorted 1/10/20/40‑cell runs → `single cell isolation protocol = cellenONE`; bulk runs (1 µl suspension) → `not applicable`. `cells per well` = 1/10/20/40, or `not applicable` for bulk. `sample type`: 1‑cell → *single cell* (PRIDE:0000897); all multi‑cell + bulk → *bulk control* (PRIDE:0000907; exact count preserved in `cells per well`). The SDRF stores the plain-text value `bulk control`.

- `organism part` / `cell type` → **not applicable / not available** for iPSC & EBs (in‑vitro pluripotent / heterogeneous differentiated aggregate).
- `disease` → **not applicable** for HEK293T, hFF, iPSC, EBs (non‑cancer); HeLa = cervical adenocarcinoma (MONDO:0005153).
- `sex` → **not available** for hi1240/EBs (donor sex not reported).
- Drug **concentrations** (1/10 µM bortezomib; 2/20 µM cycloheximide) and the **differentiation timepoint ordinal** are preserved in `source name`/`cell identifier` (there is no clean SDRF ontology column for either; exact per‑timepoint sampling days are not fully stated — only weekly intervals with T6 at +10 days).
