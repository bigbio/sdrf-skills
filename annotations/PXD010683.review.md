## Channel maps (the request's central question)

- **Nes-KO/S/R triplex (rows 181-240):** The paper's Experimental Design is explicit: "SILAC labeled Nes-KO, A375 S and A375 R cells were used ("light," "medium," "heavy")". The file token `33SR_LMH` has the same positional order. The PRIDE protocol says Lys4/Arg6 = medium and Lys8/Arg10 = heavy. **Documented.**
- **Screen-2 duplex (rows 1-180):** The paper states a label swap ("light, medium, and vice versa"). The author-written raw-file tokens are `A375SR_ML_proteome` (BR1), `A375SR_ML_proteome_2` (BR2) and `A375SR_LM_proteome` (BR3). They are read positionally (S = M, R = L for ML), which is the convention the triplex statement calibrates. The map was then **checked against** the deposited data, not derived from it. The reviewer's recomputed nestin mean log2 M/L is +1.14 (ML), +0.98 (ML_2) and -2.02 (LM). Nestin is high in S (paper: median log2 R/S -2.71), so these values match the annotation. **Documented by a deposited explicit token and data-checked.**
- **ML_proteome_2_01:** The MaxQuant design file assigns this run to `A375SR_LM_BR3_proteome`. That would give BR3 31 runs with two fraction-01 files. Annotating it by its file token as BR2 fraction 1 is the consistent reading, and the report and manifest disclose it.

## Partial scope: stated and justified

- **Stated:** The scope appears in the report header ("PARTIAL ... 110 of 145"), the manifest limitations and the `BLOCKED.md` PXD010683 section. The 35 excluded files the reviewer found are exactly the 33 screen-1 and 2 FFPE files listed there.
- **Screen 1 (33 runs):** The raw names carry no label token. The paper gives only "vice versa". The MaxQuant experiments are all `A375SR_ML_*`, but the reviewer's nestin ratios contradict that token for Phospho_BR1 (about -2.1), Proteome_BR2 (-1.95) and Proteome_BR3 (-1.14). Proteome and phospho runs of the same nominal BR disagree. No explicit source exists, so annotating would mean deriving the map from data patterns. **Exclusion justified.**
- **FFPE (2 runs):** The reviewer downloaded the whole FFPE zip. Its only searched run is `20181211_MaS_prepostBRAfi_dimethyl_LH_1ug` (multiplicity 2), which is not deposited. The label state of the two deposited single-condition runs is undocumented, and per-patient data (Suppl. S3) are not retrievable. **Exclusion justified.**

- **Location:** evidence.json claim "comment[label] + factor value ... rows 1-180 (screen 2)".
- **Evidence:** In this deposit the `A375SR_ML` experiment-name token is wrong for half of screen 1, and it puts ML_proteome_2_01 in an LM experiment.
- **Fix:** Cite only the raw-file tokens. Add the calibration sentence: the paper's triplex order (Nes-KO, S, R = L, M, H) equals `33SR_LMH`.

### M2 (provenance): the cell-type claim says "not stated in ... PRIDE"
- **Evidence:** The PRIDE organismParts list CL:0000148 Melanocyte (and BTO Skin).
- **Fix:** Either annotate `melanocyte` (CL:0000148) citing PRIDE, or keep `not available` and correct the claim with the reason the project-level tag was not used.

### M3 (source wording): A375 R was selected with PLX4720
- **Evidence:** The paper calls it "vemurafenib" only "for simplicity", and the manifest already notes this.
- **Fix:** Optional. Write `PLX4720 (vemurafenib analogue) resistant`, or keep the current term.

### M4 (design): TiO2 enrichment rounds are encoded as fraction identifiers 1-9
- **Evidence:** `comment[fractionation method]` is `not applicable` on these rows. The encoding is defensible because the rounds are sub-samples of one mixture searched as one MaxQuant experiment.
- **Fix:** None required.
