   - Evidence: PRIDE protocol describes one standard; joint MaxQuant searches (mqB: H+Corr, mqC: WT+Corr) and the NS-corr vs NS comparison imply a common reference; manifest records it as an assumption.
   - Fix: Keep, but if the Circulation Methods become readable confirm; otherwise fine as documented limitation.
2. **minor** [completeness] `missing column characteristics[developmental stage]` — Recommended column absent (sdrf-tools score).
   - Evidence: score: Missing recommended column characteristics[developmental stage].
   - Fix: Add with not available (patient lines' ages cannot be mapped to clones reliably).
3. **minor** [source_evidence] `comment[fractionation method] rows 1-912` — Left not available although the protocol (samples mixed with LDS buffer + reducing agent) and 12/15 fractions per sample point to SDS-PAGE (GeLC) fractionation.
   - Evidence: PRIDE sampleProcessingProtocol 'mixed 1:1 ... with the appropriate amount of LDS buffer and redox substance'.
   - Fix: Optional: set SDS-PAGE fractionation only if a source states gel fractionation; otherwise keep not available and note the hint in the manifest.
4. **minor** [provenance] `evidence.json limitations (WT lines 'not named'); characteristics[cell line]/[sex] WT rows` — The follow-up paper names the WT line isWT1.14 = UMGi014-C (male donor), matching the depositor label scheme WT1; manifest says WT lines are unnamed.
   - Evidence: PMC10851011 Methods: 'WT iPSC line UMGi014-C clone 14 (isWT1.14 ...) generated from ... a male donor'.
   - Fix: Mention as a possible but unconfirmed match in the manifest; do not change values without a deposit-level statement.
5. **minor** [provenance] `evidence.json, characteristics[individual] claim` — H1/H2 inference could cite the clone naming isHOCMx1 / isHOCMx2 (UMGi030-A / UMGi031-A) as additional support.
   - Evidence: PMC10851011 Methods line naming isHOCMx1.14 (NS1) and isHOCMx2.8 (NS2); Cellosaurus has no second (B) clone registered.
   - Fix: Add to the claim's evidence text.
6. **minor** [spec] `characteristics[sex] heavy rows` — Heavy pool rows carry sex 'not available'; the pool members' sexes are mixed/partly unknown, 'pooled' would be more precise if allowed.
   - Evidence: SDRF column 12 heavy rows.
   - Fix: Optional: use pooled if TERMS allow_pooled permits for sex.
