## Important finding: the DN-status block is not justified
BLOCKED.md and the manifest say that no source links the culture codes to Diab1–5 / Nephro1–5. That is refuted by deposited data:

1. The peptide-level H/L areas were read from all 30 deposited `.msf` files by HTTP range reads: PrecursorIonQuanResults channels 2/1, ConfidenceLevel 3, unique peptides only, median per protein.
2. A per-subject k was fitted as ln(r+1) = k·t over 4/7.5/24 h, keeping only proteins seen at 24 h. This is the paper's eq. 5.
3. These k values were compared with the per-subject k columns of Table S2.

| culture | best Table S2 column | median rel. deviation (best / next) | share within 2% (best / next) |
|---|---|---|---|
| cell36 | **Diab3** | 0.029 / 0.129 (Diab1) | 0.38 / 0.08 (Nephro1) |
| cell42 | **Diab4** | 0.038 / 0.105 (Diab2) | 0.32 / 0.10 (Diab5) |

| cell268 | **Diab1** | 0.029 / 0.101 (Nephro1) | 0.40 / 0.11 (Nephro1) |
| cell304 | **Nephro5** | 0.025 / 0.076 (Diab5) | 0.40 / 0.14 (Diab5) |

| cell515 | **Nephro1** | 0.033 / 0.087 (Diab1) | 0.32 / 0.13 (Diab1) |

The best matches form an unambiguous one-to-one assignment with 5 Diab and 5 Nephro subjects:
**Diab1 = cell268, Diab2 = cell160, Diab3 = cell36, Diab4 = cell42, Diab5 = cell504; Nephro1 = cell515, Nephro2 = cell325, Nephro3 = cell511, Nephro4 = cell80, Nephro5 = cell304.**

The deviation for the best column (about 3%) is at the level of re-computation noise. For every other column it is at least 7.6%. A second statistic, the correlation of subject-specific log-k residuals, agrees on 9 of 10 subjects. The exception is cell36, whose 24 h msf merges two acquisition series. cell36 also has the fewest k values (664), and so does Diab3 (649).

This is an identity match that reproduces the authors' own published per-subject numbers. It is not a biological-direction inference, so rule 6's prohibition does not apply. BLOCKED.md itself names this cross-check as the unblock route.

**Is an SDRF without the main comparison acceptable if it is disclosed?** Only when the arm is truly unrecoverable: rule 7 allows partial scope then, and the disclosure here was clear and honest. In that case the SDRF still has value as a turnover/time-course annotation, but it cannot reproduce Tables 2–3 or S2–S5. Here the arm is recoverable, so leaving it out is an omission, not a block.

**Fix:**
1. Add the key to `samples.tsv`. Cite it in the manifest as "msf-derived k matched to Table S2 (reviewer method)", stated as a data-derived identity match.
2. Set `characteristics[disease]` = `type 1 diabetes nephropathy` (EFO:0004996) for cell515/325/511/80/304, and keep `type 1 diabetes mellitus` (MONDO:0005147) for cell268/160/36/42/504.
3. Add `factor value[disease]`, keeping `factor value[sampling time]`. Optionally record the paper IDs Diab*/Nephro*.
4. Rebuild, then rerun validate, reconcile and convert-openms.
5. Delete or rewrite the BLOCKED.md section and manifest limitation [0].

Reproduce with the reviewer scripts `scripts/httpvfs.py`, `extract.py` and `match.py`, and the output `match.out`, all under `/tmp/claude-0/-home-user/a98b4c07-45f2-5d08-aa74-0c95b1e5e538/scratchpad/rev-PXD038541/`.

## Other probes (no blocking issue)
- **File mapping:** 312 RAW files in PRIDE equal the 312 SDRF files, each on an L row and an H row. The FileInfos of all 30 msf files hold 313 entries: those 312 plus the blank 07Mar2013_Blank_02.RAW, which was not deposited. Every file's msf subject and time point match its row.
- **Technical replicates 1–4:** 1 = first pass and 2 = static-exclusion-list re-run (paper 4.4); 3/4 = the second cell36 24 h series and the cell42 24h_E re-acquisitions. This is acceptable. The exclusion-list run is a complementary acquisition rather than a pure repeat; that could be stated in the manifest (minor).
- **Post-build fraction edit:** correct. Band letter → fraction id was recomputed on all 624 rows with 0 mismatches, including `_bis` and timestamp-suffixed names. It is deterministic and justified. On rebuild, supply fraction ids in technical.tsv so the edit is not needed (minor).
- **Disease 'type 1 diabetes mellitus' on all rows:** true for all 10 subjects (paper 4.1), but incomplete until the fix above.
- **clinical-metadata template:** appropriate for patient-derived primary cultures (rules 15/18). Age, sex and ancestry = `not available` is correct: only cohort means are given, and ref [20] is not open access.
- **Instrument:** LTQ Orbitrap XL (MS:1000556) is supported by paper 4.4 and by the RAW model string "LTQ Orbitrap XL MS" (5 headers range-read). "LTQ Orbitrap ETD" appears only in the file-header creator/computer fields. XL ETD (MS:1000639) is unproven, so keep MS:1000556 (minor note).
- **Lys-C only** (no trypsin), 10 ppm / 0.6 Da, Carbamidomethyl / Oxidation / Lys6 (UNIMOD:188), and multiplicity 2 (dynamic SILAC, light = pre-existing, heavy = newly synthesised) all match the paper. The light/heavy biology in the source names is correct for a pulse.
