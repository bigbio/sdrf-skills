## Findings

### Minor findings
1. **+TG replicate numbering differs from the publication's.**
   - **Location:** `characteristics[biological replicate]` and source names, rows 7–12.
   - **Evidence:** the SDRF numbers 0508 = 1 and 0465 = 2, following the raw-header names "3xStress#1" and "3xStress#2". EV1 sheet order and the Fig 1F "repeat" columns put 0465 first.
   - Either choice is a valid identifier and the manifest states the conflict. A reader cross-referencing EV1 may still be confused.
   - **Optional fix:** use the EV1 order, or keep the current numbering and record the EV1 sheet name per run in a comment.
2. **The channel-map data check is weaker than it could be.**
   - **Evidence:** the manifest says no data-internal marker distinguishes the channels. Medium = CGG is in fact supported by the consistent SRSF1/SRSF2 enrichment in Medium in all 4 runs (M/L 1.9–7.5), which agrees with the orthogonal Fig 2C co-IP western.
   - **Optional fix:** add this to the bait claim. Light vs heavy remains supported by the text and headers only.
3. **`characteristics[developmental stage]` = `not available`.**
   - **Evidence:** Cellosaurus AG is Fetus. The template description names "fetal stage" as an example, and 6 curated CVCL_0063 SDRFs in sdrf-annotated-datasets use `fetal stage`. The label exists as HsapDv:0000037 and NCIT:C89885, not in EFO, and the validator is warning-level.
   - **Optional fix:** set `fetal stage`, or keep `not available`. The current value is conservative and acceptable.
4. **The manifest's `artifact` field is an absolute path, not a repository-relative one.**
