### Findings (all minor)
1. **comment[data file].** It holds the inner `.raw` names, but PRIDE serves `<stem>.zip`. The producer disclosed this, and README.adoc:444 allows either form. Optional fix: switch to the zip names.
2. **characteristics[individual].** The values are curator-made placeholder donor keys. The grouping is correct; optionally use Cellosaurus root-line accessions instead.
3. **Heavy-row disease.** It is the parent term 'prostate carcinoma', although the mix contains LNCaP-AI. This is acceptable.
4. **Heavy-row storage temperature.** −80 °C is the storage of the lysate aliquots, while TERMS.tsv describes the term as cell-line storage. Optionally note this in the manifest.
5. **Unused optional columns.** Evidence exists for alkylation reagent (iodoacetamide), MS1 range 350–1600 and tissue mass 2–5 mg; none is required.
6. **Heavy-row biorepository.** The free-text value uses `; `. Optionally rephrase it without semicolons.
