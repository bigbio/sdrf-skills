## Requested checks
- **Ting_n = set n.** This is an inference: no summary.txt or experimentalDesign file was deposited, and README.txt has no mappings. It is consistent with the depth order SILAC1 > SILAC3 > SILAC2:
  - in the human search: 7279/7219/7007 protein groups;

  - in the deposited fraction counts: Ting_1 has 16 (+1 re-injection), Ting_3 has 13, Ting_2 has 9 (+2 totals).

  The manifest discloses the inference (minor finding 1).
- **Search parameters (rule 5).** The only deposited SILAC search uses an HIV-only FASTA (UP000002241; MaxQuant 1.6.0.16). The human search behind Supplementary Table 4 (MaxQuant 1.5.3.17) is described only in the PRIDE text. The modifications are identical in both:
  - Carbamidomethyl (C) fixed;
  - Oxidation (M) and Acetyl (Protein N-term) variable;
  - L/M/H multiplicity, confirmed by Intensity L/M/H in proteinGroups (rule 14).

  Precursor 4.5 ppm comes from the PRIDE text. Fragment 20 ppm is the FTMS value in parameters_NLRX1.txt; PRIDE's 0.5 Da equals that file's ITMS value. The MS2 spectra are Orbitrap, so the FTMS value applies. The manifest reasons this through (minor finding 3). There is no evidence that any run was left unsearched, so tolerances `not applicable` do not apply.
- **Post-build edit (rule 17).** I reran the cited gen_tables.py on the cited files0.json and raw_summary.txt, then ran `sdrf-tools build` (same templates). The output is identical to the artifact except `comment[fraction identifier]` 1→12 on the 3 rows of `20170404_Ting_1_12_170408070646.raw`. That is exactly the edit disclosed in validation.txt.

- **total1/total2.** Raw headers show the 240-min method (2–30% B over 210 min) and a 300–1650 m/z scan range; fraction runs use 180 min and 200–2000 m/z. The SDRF has them as technical replicates 2/3, fraction 1, `comment[fractionation method]` = `not applicable`, with the ms1 scan range per file. This is valid. - **Biological replicate numbering.**
  - sh-Ctr mock is numbered 1/2/3 across sets, and sh-NLRX1#1 mock 1/2. All other groups are 1. Numbers are unique within each group (rule 3).
  - No source says whether the medium reference channel was one culture or three. The paper says only "Samples were run in biological duplicates", and Supplementary Table 4 shows those are within-set derivations.
  - Separate source names per set are right, because each set is a separately mixed physical sample. The independence is a disclosed assumption (minor finding 2).

  - MOI 5 is not a column (minor finding 4).
  - `characteristics[sampling time]` = 24 hour (paper: "At 24 hpi").

## Minor findings (non-blocking)
1. Raw→set mapping is a name-based inference. Keep the limitation; confirm against summary.txt or with the authors if one becomes available.
2. Independence of the per-set sh-Ctr mock (and sh-NLRX1#1 mock) cultures is assumed; no source states it.
3. Fragment tolerance: 20 ppm (deposited HIV-only search, FTMS) vs the PRIDE text's 0.5 Da (ITMS). Which runs entered which search is not recorded.
4. MOI 5 could be added as `characteristics[multiplicity of infection]` (PXD021351 precedent).
5. `characteristics[developmental stage]` is absent. It could be added as `not available`, since 14Y is not adult.
6. The re-injection and the total runs form single-fraction technical-replicate groups. This is a valid encoding, but downstream quantification will treat them as separate run groups.
