## Channel → condition map (the key decision)

**Label isotopes.** These come from mqpar `labelMods`: light = Lys0/Arg0, medium = Arg6;Lys4, heavy = Arg10;Lys8.

**Forward, experiment 1:** light = uninduced WT, medium = S635A, heavy = induced WT.
- The source is the order of the PRIDE protocol's list ("uninduced WT, S635A mutant and induced WT"). The list does not state labels explicitly.
- **Bait check:** in Forward, the RBM20 (Q5T481) M/L ratio is 14.8 in Input and 14.9 in BioID; H/L is 12.2 and 10.7. Light therefore lacks RBM20, which matches uninduced.
- **Signature check:** the medium channel shows more proximity to cytoplasmic RNP-granule proteins than heavy does (median log2 M/H +0.48; nuclear markers about 0). This fits the S635A mutation in the RSRSP motif, which shifts the protein to the cytoplasm, and the abstract's statement that the sites affect association with cytoplasmic RNP granules.

**Reverse, experiment 1:** light = S635A, medium = induced WT, heavy = uninduced WT.
- This is **derived from the data**, because no source describes the swap.
- **Bait check:** in Reverse, H/L is 0.128 in Input and 0.021 in BioID, so heavy = uninduced.
- **Permutation test:** I compared proteome-wide log2 ratios between Forward and Reverse under all 6 channel permutations (`permtest_*.txt`). Among the permutations that keep the bait anchor (fwd L → rev H), fwd M → rev L, fwd H → rev M wins clearly:
  - BioID: r = +0.75 / +0.83 / +0.85, against +0.47 / +0.32 / −0.85 for the alternative.
  - Input: r = +0.45 / +0.08 / +0.68, against +0.10 / −0.31 / −0.68.
  - The Requantify search gives the same winner.
- The granule signature repeats in Reverse (median log2 L/M +0.58).
- **The swap is a cyclic shift, not a reversal of the light and heavy labels.**

**Experiment 2 (excluded).**
- The same test shows the same cyclic shift between Forward and Reverse.
- The sample in fwd H / rev M has higher RBM20 levels and more granule proximity.
- However, WT, A10 and D10 all express RBM20, so no channel can be anchored. Assigning them by list order alone, or by expected biology, would break batch rules 6 and 7.

## Values and evidence
- **Cell line:** Flp-In-T-REx cell (BTO:0006149) / CVCL_U427 / Flp-In-T-REx-293.
  - The Mendeley Data method text for the same RBM20 variant lines (paper Fig 5A/S5C) says "Flp-In TRex HEK293 cells stably expressing RBM20 variants … induced … 1 µg/mL tetracycline".
  - That the BioID SILAC cultures used these same lines is **inferred**; the PRIDE "uninduced/induced" wording fits.
  - The inducing agent is not written into the treatment values.
- **From Cellosaurus:** kidney (fetal kidney, UBERON:0002113), female, and no disease, so `normal` (PATO:0000461).
- **Instrument:** Orbitrap Exploris 480 (MS:1003028), present in all 8 RAW headers. **PRIDE's "Q Exactive" is wrong.**
- **Acquisition:** DDA (PRIDE:0000627); HCD (MS:1000422) at 28 NCE; orbitrap MS2; MS1 350–1800 m/z.
- **Fractions:** fraction 1 for every run. The FAIMS CVs are scans within one run; they were split into mzXML files only for the search.
- **Modifications, from mqpar:**
  - Fixed: Carbamidomethyl C (UNIMOD:4).
  - Variable: Oxidation M (35), Acetyl Protein N-term (1, `PP=`), Deamidated N,Q (7).
  - SILAC, `MT=Variable` (batch rule 11): Label:2H(4) K (481), Label:13C(6) R (188), Label:13C(6)15N(2) K (259), Label:13C(6)15N(4) R (267).
  - PRIDE's modification field lists only "iodoacetamide derivatized residue"; I ignored it.
- **Tolerances:** 4.5 ppm (mqpar main search) and 20 ppm (FTMS MS/MS).
- **Cleavage agent:** Trypsin (MS:1001251), per batch rule 2. The search rule was Trypsin/P, and I recorded it as a note.
- **Reduction / alkylation:** Input rows have DTT (PRIDE:0000608) and IAA (PRIDE:0000599). BioID rows have `not available`: the prep is not described, but the shared search fixed Carbamidomethyl, so alkylation may have happened.
- **Enrichment:** BioID rows have `sample enrichment` (EFO:0009106). No streptavidin/biotin term exists under EFO:0009090. Input rows have `not applicable`.
- **Factors:**
  - `factor value[treatment]`: untreated / induced expression of RBM20 S635A / induced expression of RBM20 wild type.
  - `factor value[enrichment process]`: I added this in round 2 so that convert-openms does not pool Input and BioID into one condition.
- **Biological replicate:** Forward culture set = 1 and Reverse = 2 within each factor group. Input and BioID rows of one culture share the number because they come from the same lysate. Their source names differ (`_Input` / `_BioID`) because the build row coordinate would otherwise collide.
- **Sample type:** uninduced = negative control (PRIDE:0000905, inferred role); others = study sample (PRIDE:0001013).

## Conflicts resolved
1. **Instrument:** PRIDE's field says Q Exactive; the protocol and RAW headers say Orbitrap Exploris 480. I used the RAW headers.
2. **Label swap:** "Forward/Reverse" suggests a reversal of light and heavy, but the data show a cyclic shift. I followed the data, anchored on the RBM20 bait.
3. **Cleavage agent:** reconcile reports Lys-C missing (MAJOR). That is true for the 2 Input runs, but the column is single-cardinality in the contract and `build` emits one column. Trypsin is common to all runs; the Lys-C step is a limitation.
