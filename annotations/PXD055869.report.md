## Study and publication
- **Title**: *Establishment of Salivary Tissue-Organoid Biorepository* (Mayo Clinic salivary regenerative biobank).
- **Publication**: Aalam et al., *npj Regenerative Medicine* 2025;10(1):23. PMID 40399315 · PMCID PMC12095476 · DOI 10.1038/s41536-025-00410-5 (open access; full Methods retrieved and used).
- **Design**: Label-free single-cell proteomics of FACS-enriched salivary gland stem/progenitor cells (SGSPCs) isolated with the cellenONE system, from human submandibular gland (SMG) and parotid gland (PG). Acquisition on a Bruker timsTOF SCP in **diaPASEF** (DIA) mode; quantified with **DIA-NN 1.8** against a DDA-PASEF spectral library.

## Templates chosen and why
- `ms-proteomics` — MS-based proteomics (base technology layer).
- `human` — *Homo sapiens* donors (PRIDE `organism` + paper; IRB-consented human biobank).
- `single-cell` — one deposited run per single cell isolated by cellenONE (adds `cell identifier`, `single cell isolation protocol`, `cells per well`, `sample type`, `enrichment marker`).
- `dia-acquisition` — diaPASEF/DIA (adds isolation/scan-window columns; restricts acquisition method to DIA).
- **Cell-lines template deliberately NOT used**: these are primary human gland cells (tumor-free clinical residual / autopsy tissue), not an immortalized line. Cell type / organism part classified from primary sources per the brief.

## Key per-column decisions (evidence)
All ontology accessions were verified live via OLS (label + definition), never guessed.
- `organism` = Homo sapiens / **NCBITaxon:9606**.
- `organism part` = parotid gland / **UBERON:0001831** or submandibular gland / **UBERON:0001736**.
- `cell type` = epithelial fate stem cell / **CL:0000036** (see judgment call below).
- `instrument` = timsTOF SCP / **MS:1003231** (PRIDE `instruments` and paper agree — no conflict here).
- `cleavage agent details` = Trypsin / **MS:1001251** — paper: "2 ng/µl trypsin protease"; DIA-NN command `--cut K*,R*`.
- `dissociation method` = collision-induced dissociation / **MS:1000133** — inferred from timsTOF diaPASEF (CID is the fragmentation on this platform; not separately stated in text). Flagged as inferred.
- `proteomics data acquisition method` = Data-independent acquisition (**PRIDE:0000450**); `dia method` = diaPASEF; `isolation window width` = 25; `scan window` = 400–1000 m/z — all stated verbatim in Methods ("Ions in the range of 400–1000 m/z … isolation window of 25 m/z").
- `label` = label free sample / **MS:1002038** — label-free SCP, no multiplexing (so no carrier/reference channel columns; those are `single-cell` recommendations that are genuinely N/A here and were omitted rather than padded with "not applicable").
- `single cell isolation protocol` = **cellenONE** (the device that deposits one cell per well). FACS was an upstream population enrichment, documented instead in `enrichment marker`.
- `enrichment marker` = ~~CD24+/EpCAM+/CD49f+/PSMA-~~ → **CORRECTED to DAPI-/CD45-/CD31-/EpCAM+** (see Correction below). The CD24/CD49f/PSMA panel was the SGSPC *characterization* immunophenotype, not the sort gate applied to the 271 deposited single cells.
- `cells per well` = 1; `sample type` = single cell; `cell identifier` = unique per-cell token (`N0628_A1`, `S2_PG_H10`, …); `source name` = same unique per-cell token; `assay name` = unique per run (`run 1`…`run 271`); `fraction identifier` = 1; `technical replicate` = 1 (direct injection, no fractionation, one injection per cell).
- `biological replicate` = specimen-level within each gland: parotid → N0628 = 1, S2_PG = 2; submandibular → N1168 = 1, S2_SMG = 2. (The `single-cell` template separates donor/sample-level `biological replicate` from per-cell `cell identifier`, so replicate is *not* incremented per cell.)
- `sample preparation batch` = specimen/plate token (`N0628`, `N1168`, `S2_PG`, `S2_SMG`) — batch is a documented SCP confounder; the paper explicitly Combat-corrects a Patient#1/Patient#2 batch effect.
- `factor value[organism part]` — the biological variable under study is the gland (parotid vs submandibular); disease is constant (normal), so it is not a factor.

## No Carbamidomethyl — but modifications ARE present (original claim of "not applicable" was WRONG; see Correction)
The sample-prep Methods describe lysis in 0.2% DDM / 100 mM TEAB / trypsin with **no reduction and no alkylation step**, so **no Carbamidomethyl** is correct (absent from the deposited data — confirmed). The *original* conclusion that `modification parameters` = `not applicable` was the review BLOCKER and is now corrected: the DIA-NN command line uses `--lib ...\Library\DDA\PTMSL\library.tsv`, an **external PTM spectral library**. With an external library DIA-NN takes modifications FROM the library, so the absence of `--var-mod` flags does NOT mean "no mods." The deposited `pr_matrix.tsv` (both Set01 and Set02) contain modified precursors carrying six variable modifications. See the Correction section for the enumeration and residue evidence.

## Values left `not available` / `not applicable`, and why
- `characteristics[age]`, `characteristics[sex]` (both required by `human`) = **not available**. Table 1 gives only cohort-level demographics (N=208); no per-specimen age/sex for the four SCP donors is provided. Per the brief, age/sex require individual-level mapping, so they are not guessed.
- `characteristics[individual]` = N0628 / N1168 for Set01 (specimen IDs are exposed); **not available** for both Set02 groups (filenames carry only "S2"; I cannot confirm whether S2_PG and S2_SMG are one donor or two, so donor identity is not asserted).
- `characteristics[disease]` = **normal** — inferred from "tumor-free clinical residual SG specimens" / autopsy SMG; the sampled tissue is non-neoplastic. (Inferred, not stated as "normal" verbatim.)
- `precursor/fragment mass tolerance` = **not available** — DIA-NN auto-optimized mass accuracy per run (log shows MS1 ~12–13 ppm recommendations, no fixed declared tolerance).

## Judgment calls a reviewer should attack hardest
1. **`cell type` = CL:0000036 "epithelial fate stem cell"**. There is no CL term for "salivary gland stem cell." The salivary-gland-*specific* candidate **CL:0020060 "basal duct cell of salivary gland"** is defined as "presumed to function as a salivary gland stem/progenitor cell," and the paper does link SGSPC cytokeratins to "rare salivary ductal basal cells." I chose the broader **CL:0000036** because the annotated cells are a **FACS-enriched, explicitly heterogeneous progenitor population** (EpCAM+/CD24+/CD49f+), and the paper does not claim every sorted cell is a basal duct cell — so asserting the terminal ductal-basal identity on all 271 rows over-specifies. The salivary context is carried by `organism part`. Reviewer should decide whether CL:0020060 is preferable.
2. **`disease` = normal** for all rows (inferred from "tumor-free"); a reviewer may prefer `not available` given the donors' varied clinical backgrounds.
3. **Set02 `individual` = not available** — could a reviewer recover donor identity from supplementary tables? I could not find a per-specimen key for S2.
4. **`biological replicate` scheme** (specimen-within-gland) vs an alternative (e.g., per-cell) — I relied on the template's separation of `biological replicate` from `cell identifier`.
5. **`modification parameters` = not applicable** vs listing the library-build variable mods.

### DEFECT 1 (BLOCKER, fixed) — modifications were wrongly `not applicable`
Evidence: the deposited DIA-NN command line (`Result.7z` → `Set01/sgSPC_Set1_Quan.log.txt`) is
`diann.exe … --lib Q:\SHARED\SCP_sgSC\Library\DDA\PTMSL\library.tsv … --met-excision --cut K*,R*
--relaxed-prot-inf --smart-profiling …` — an **external PTM spectral library** and **no fixed mod,
no `--var-mod`, no `--unimod4`**. With an external library DIA-NN inherits the library's
modifications, so "no `--var-mod`" ≠ "no mods." I enumerated the actual modifications directly from
the `Modified.Sequence` column of both deposited `pr_matrix.tsv` files and tallied the residue each
token modifies (token position → preceding residue, N-terminal if at sequence start):

| UNIMOD | Name | Residue evidence (Set01 / Set02 modified-precursor tally) | SDRF value |
|---|---|---|---|
| UNIMOD:35 | Oxidation | M only (720 / 1236) | `NT=Oxidation;AC=UNIMOD:35;TA=M;MT=Variable` |
| UNIMOD:1 | Acetyl | peptide N-terminus only, never on K (168 / 316) | `NT=Acetyl;AC=UNIMOD:1;PP=Protein N-term;MT=Variable` |
| UNIMOD:21 | Phospho | S 49/102, T 12/19, Y 8/7 | `NT=Phospho;AC=UNIMOD:21;TA=S,T,Y;MT=Variable` |
| UNIMOD:34 | Methyl | K only (50 / 63) | `NT=Methyl;AC=UNIMOD:34;TA=K;MT=Variable` |
| UNIMOD:36 | Dimethyl | K only (33 / 33) | `NT=Dimethyl;AC=UNIMOD:36;TA=K;MT=Variable` |
| UNIMOD:37 | Trimethyl | K only (10 / 17) | `NT=Trimethyl;AC=UNIMOD:37;TA=K;MT=Variable` |

Cross-checks:
- The paper Methods ("Unbiased … single-cell proteomic profiling") independently reports the same PTM
  set: "phosphorylation on serine/threonine/tyrosine (64 sites), lysine methylation (28 sites),
  di-methylation (16 sites) and tri-methylation (8 sites)" — matching Phospho on S/T/Y and
  Methyl/Dimethyl/Trimethyl on **K** exactly.
- Acetyl (UNIMOD:1) appears **only** at the peptide N-terminus in every modified precursor (never on
  a K side chain) and DIA-NN was run with `--met-excision`; this is protein N-terminal acetylation, so
  it is encoded with `PP=Protein N-term` (a positional value — **not** in `TA=`), per the convention
  used in `annotations/PXD054445.sdrf.tsv`.
- Each UNIMOD accession→label was verified live via OLS (`unimod`, exact single hits): 35=Oxidation,
  1=Acetyl, 21=Phospho, 34=Methyl, **36=Dimethyl**, 37=Trimethyl. UNIMOD:36 is the +28.03 methylation
  ("Dimethyl"), i.e. a lysine methylation PTM — **not** a SILAC/dimethyl-labelling reagent (the
  isotopic dimethyl labels are UNIMOD:199/510/etc.). The dataset is label-free (`label free sample`),
  and the token sits on K side chains alongside mono- and tri-methyl, confirming the methylation-PTM
  reading.
- **No Carbamidomethyl added** — correctly absent (no reduction/alkylation; not in the command line
  or the deposited precursors). This part of the original annotation was right and is preserved.

Six `comment[modification parameters]` columns (cardinality: multiple — duplicate columns are legal
and load-bearing) replace the single `not applicable` column.

### DEFECT 2 (fixed) — enrichment marker overstated the sort gate
The paper's single-cell-proteomics Methods and Fig. 5A state the deposited cells were FACS-sorted by
the immunophenotype **DAPI-/CD45-/CD31-/EpCAM+** ("isolated by FACS using DAPI-CD45-CD31-EpCAM+
immunophenotype … lysed and digested in 384-well plate using cellenONE platform"). The previous value
(`CD24+/EpCAM+/CD49f+/PSMA-`) was the SGSPC **characterization** panel used elsewhere in the study,
not the gate applied to these 271 cells. `characteristics[enrichment marker]` is now
**`DAPI-/CD45-/CD31-/EpCAM+`** on all 271 rows.

### DEFECT 3 (BLOCKER, fixed in round 2) — `assay name` was not unique per run
A second independent review caught a pre-existing defect that the modifications/enrichment repair did
not touch: `assay name` was the literal `run 1` on **all 271 rows**. `spec/.../base/1.1.0/base.yaml`
requires `assay name` to be a *"Unique identifier for the data acquisition run"* (unique per run), and
these are 271 distinct `.d` acquisitions. `parse_sdrf` did not flag it because it only enforces the
uniqueness of the *(source name, assay name)* pair, which held (source name is unique per cell). Fixed
by numbering `run 1`…`run 271` in row order, matching the corpus convention. Re-validated → exit 0.
