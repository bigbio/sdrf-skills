### Findings (all minor)
1. **sample type, mock IP rows 1-8, 17-24, 41-48:** a more specific term exists: `negative control` (PRIDE:0000905, is_a control sample). The paper calls these IPs the "negative control".
2. **sample type, DMSO vehicle IP rows 49-56 and 73-80:** these are `study sample`, while all inputs are `control sample`. The role assignment mixes two criteria. Consider `control sample` for the vehicle IPs, or document the rule.
3. **MC_2580 dose and exposure time (2 uM, 24 h; Fig. 4E):** not encoded. Custom characteristics columns would be allowed, the same mechanism already used for `characteristics[immunoprecipitation]`. The manifest's "no column licensed" overstates what the spec says.
4. **Manifest:** the limitation "REVIEW_PENDING_EXTERNAL / no review file written" is stale.
5. **convert-openms:** refuses the file because precursor tolerance is `not available`. This is genuine (the value is unrecorded) and disclosed.
