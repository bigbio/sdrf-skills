### Findings

1. **[important] design** — `characteristics[biological replicate], rows 5,6,7,9,11,13,15 (condition not applicable|not applicable|0 minute|hydrogen peroxide) and rows 2,4,10,18 (not applicable|not applicable|10 minute|hydrogen peroxide)`  
   Seven (resp. four) different source names in the same factor-value condition all carry biological replicate 1, which states they are one biological replicate while the source names (and the manifest: 'Each SILAC channel of each run is a distinct culture') say they are distinct samples. Fix: number biological replicates 1..n within each factor-value group (0-minute group: 1-7; H2O2-only 10-minute group: 1-4; all other groups stay 1), or, if the producer holds that the separate experiments are not comparable replicates, add a distinguishing factor/characteristic (e.g. an experiment identifier) so they no longer share one condition.  
   *Evidence:* spec/sdrf-proteomics/README.adoc lines 330-333: 'characteristics[biological replicate]: Independent biological samples. Numbering restarts per experimental condition (factor value group).' convert-openms output: condition 'not applicable|not applicable|0 minute|hydrogen peroxide' has 7 files/samples.

2. **[minor] source-evidence** — `rows 1-4 characteristics[sampling time]/factor value[sampling time] = 10 minute`  
   H2O2 exposure for the olaparib experiments is inferred from the general Methods sentence; H2O2 concentration in these runs is unstated, yet the heavy channels are pooled into the same condition as the 500 uM time-course and occupancy 10-minute channels. Keep the manifest disclosure; consider an experiment identifier column so the inference does not merge conditions.  
   *Evidence:* Paper Methods 'Cells were stimulated with H2O2 ... for 10 min'; Results olaparib paragraph gives no time or concentration.

3. **[minor] cross-file consistency** — `characteristics[sampling time] vs PXD004245-hela-lfq.sdrf.tsv characteristics[exposure duration]`  
   Here the H2O2 exposure time is in characteristics[sampling time] and characteristics[exposure duration] means olaparib exposure; the companion LFQ file puts the H2O2 time in characteristics[exposure duration]. The fix is recorded against the LFQ file; no change needed here if LFQ is aligned to this convention.  
   *Evidence:* Column values of both SDRFs; clinical-metadata template documentation pairs exposure duration with compound+dose.

4. **[minor] specificity** — `characteristics[treatment]/characteristics[dose]`  
   H2O2 dose 500 uM (file names '500uMH2O2', Results) is not encoded for time-course rows; dose column is used for olaparib. Optional: note in comment or a free-text treatment detail.  
   *Evidence:* Raw file names 20140818_..._500uMH2O2_*; paper Results time-course paragraph.

5. **[minor] omission** — `file (enrichment, cleavage agent)`  
   Af1521 ADP-ribose peptide enrichment and Lys-C co-digestion are not represented. Both are disclosed; optionally use the generic EFO:0009106 'sample enrichment' in characteristics[enrichment process].  
   *Evidence:* OLS descendants of EFO:0009090 contain no ADP-ribose enrichment term; ms-proteomics 1.2.0 comment[cleavage agent details] has no cardinality: multiple.

## PXD004245-hela-lfq.sdrf.tsv — **FAIL**

Valid and well sourced (label-free state, QE Plus, original run names confirmed from raw headers), but the H2O2 exposure time is placed in characteristics[exposure duration], which the companion SILAC SDRF of the same deposit uses for olaparib exposure while it records H2O2 time in characteristics[sampling time].

### Checks

- **spec_compliance**: pass — parse_sdrf validate-sdrf -t ms-proteomics -t human -t clinical-metadata -t cell-lines (bundled templates byte-identical to sdrf-templates@7da1747; diff -rq empty): 'Everything seems to be fine', exit 0; sdrf-tools structure OK; 3 rows x 40 cols.
- **ontology_integrity**: pass — Same term set as the SILAC file minus olaparib/QE HF, all resolved non-obsolete in OLS4; sdrf-tools check 15/15 CLEAN.
- **source_evidence**: pass — Raw headers: Rep1/2/3 were acquired as ..._PAR_PD_2xSep-pak/_normal/_Filter.raw on 'Q Exactive Plus'; experimentalDesignTemplate maps 2xSep-pak->Rep1, Filter->Rep2, normal->Rep3; msms.txt chunk: all three runs Labeling State 0 / K0R0 only. Paper: 'From three replicates ... after H2O2 treatment', 500 uM benchmark.
- **file_mapping**: pass — 3 PAR_PD .raw in PRIDE files/all, each mapped once; names exact.
- **design_consistency**: fail — Single condition (hydrogen peroxide), biological replicates 1-3 - consistent within the file; but the H2O2 time variable is encoded in a different column than in the sibling SILAC SDRF where characteristics[exposure duration] carries olaparib exposure.
- **omission_safety**: pass — 10 minute H2O2 is inferred from general Methods and disclosed; biological-replicate independence rests on author wording and is disclosed; sample preparation batch values are literal original run-name suffixes.
- **deterministic_validation**: pass — parse_sdrf validate-sdrf -t ms-proteomics -t human -t clinical-metadata -t cell-lines (bundled templates byte-identical to sdrf-templates@7da1747; diff -rq empty) exit 0; sdrf-tools structure/check exit 0; score 100/100; convert-openms (scratch copy) SUCCESS, 1 condition x 3 bioreps.

### Findings

1. **[important] cross-file consistency** — `characteristics[exposure duration], rows 1-3 (value '10 minute')`  
   The same quantity (time of H2O2 exposure before harvest) is encoded here as characteristics[exposure duration] but as characteristics[sampling time] in PXD004245-hela-silac.sdrf.tsv, where characteristics[exposure duration] instead means olaparib pre-incubation ('not available'). An aggregator merging the deposit's SDRFs would read one header with two meanings. Fix: move '10 minute' to characteristics[sampling time] (sample-metadata, number_with_unit) and drop characteristics[exposure duration] (or set it 'not applicable', as there is no compound), matching the SILAC file.  
   *Evidence:* LFQ column 12 = '10 minute'; SILAC characteristics[sampling time] carries H2O2 times and characteristics[exposure duration]='not available' for olaparib rows. clinical-metadata 1.0.0 documentation: 'use characteristics[compound] + characteristics[dose] + characteristics[exposure duration] together'.

2. **[minor] traceability** — `characteristics[biological replicate] / source name rows 2-3`  
   Replicate numbers follow the deposited file names, but the authors' MaxQuant experiments (and Supplementary Data 1 Rep columns) map Rep2<->_normal and Rep3<->_Filter the other way round (file _Rep2 = MQ 'Rep3', file _Rep3 = MQ 'Rep2'). Optional: renumber to the MaxQuant experiment names or add a comment so reusers of proteinGroups 'Intensity RepN' map correctly.  
   *Evidence:* experimentalDesignTemplate.txt lines for 20140515_..._PAR_PD_Filter (Rep2) and _normal (Rep3); raw headers of _Rep2.raw (= _normal) and _Rep3.raw (= _Filter).

3. **[minor] source-evidence** — `characteristics[biological replicate] rows 1-3`  
   Biological independence of the three runs rests on author wording ('replicate enrichment experiments'); all three were acquired the same day with different clean-up suffixes and could be one lysate processed three ways. Disclosed in the manifest; no change required unless contrary evidence appears.  
   *Evidence:* Paper Results 'we performed replicate enrichment experiments in HeLa cells'; raw headers 2xSep-pak/normal/Filter, all 20140515.

4. **[minor] omission** — `file (enrichment, cleavage agent, H2O2 dose)`  
   Af1521 enrichment, Lys-C co-digestion and the 500 uM H2O2 dose are not encoded (all disclosed). Optional: EFO:0009106 'sample enrichment' in characteristics[enrichment process].  
   *Evidence:* No ADP-ribose enrichment child under EFO:0009090; cleavage agent single-cardinality in ms-proteomics 1.2.0.
