### Findings

Blocker: none. Important: none.

1. **minor** — characteristics[disease], rows 1-18: Disease is the generic parent 'cervical adenocarcinoma' (MONDO:0005153) although the exact Cellosaurus CVCL_0030 disease term NCIT:C27677 'Human papillomavirus-related (endo)cervical adenocarcinoma' exists in an ontology the column's validator accepts (ncit). *Evidence:* Cellosaurus DI line: 'NCIt; C27677; Human papillomavirus-related endocervical adenocarcinoma'; OLS4 search returns NCIT:C27677. Manifest says only that no MONDO term exists. *Fix:* Optionally use 'Human papillomavirus-related cervical adenocarcinoma' (NCIT:C27677), or keep the parent and note the choice.
2. **minor** — comment[cleavage agent details]: Lys-C (MS:1001309) used together with trypsin is not recorded. *Evidence:* Methods: 'digested using endoproteinase Lys-C (1:100 w/w) and modified sequencing grade trypsin'. ms-proteomics 1.2.0 defines the column without cardinality: multiple, so the omission is template-driven and disclosed. *Fix:* None required now; add a second column if the template allows multiple cardinality.
3. **minor** — characteristics[dose], H2O2 rows: The H2O2 concentration (500 uM, in the time-course file names and the Results) is not encoded; dose reads 'not applicable' on H2O2-only rows because dose pairs with characteristics[compound]. *Evidence:* File names '..._500uMH2O2_...'; Results 'we treated HeLa cells with 500 uM H2O2'. Disclosed in manifest limitations. *Fix:* Optional: record 500 uM for the time-course runs (e.g. in characteristics[treatment] description or a future second compound/dose pair); leave the olaparib runs 'not available' for H2O2 dose.
4. **minor** — characteristics[sampling time]/factor value[sampling time], rows 1-4: The 10 minute H2O2 time for the two olaparib experiments comes from the general Methods protocol, not from an experiment-specific statement. *Evidence:* Methods 'Cells were stimulated with H2O2 for 10 min'; SI Fig 4g gives no time. Manifest marks it INFERRED. *Fix:* None required; keep the limitation.
