## Key question: the PP channel map under campaign rule 6

**Is there an explicit statement?** No. I searched each source below and found no sentence saying which pair is experiment 1/2/4/5 or which SILAC state carried shNEG vs shRBP:

| Source searched | What it says about labels |
|---|---|
| Paper text and Methods (PMC10140000) | Only which reagents are heavy and medium, and that 'upregulated in H/M' is the convention |
| Fig 7 legend and image | No scheme for which cells were labelled |
| Supplement mmc1 (Fig S8/S9) | Only that the ratio was computed as shRBP/shNEG |
| PRIDE sample and data protocols | List the four pairs, but not their order or orientation |
| Deposited zips | No experimentalDesign file. The only Perseus `.sps` is in the pp2 zip and covers only the CoCult/Norm analysis |

**What explicit evidence exists:**

- **Fig S8 legend:** it states the direction: "calculated ratio shRBP to shNEG".
- **Table S2 (mmc3):** the author table. It has per-comparison columns `in shTIAR_N`, `in shTIAR_CO`, `in shFMRP_N` and `in shFMRP_CO`, on sheets Up and down.

**Independent recomputation.** I took the mean of the median-centred log2 'Ratio H/M normalized' values from the deposited `txt_search_LMH_1245` proteinGroups and compared it with Table S2 (pooled Up and down, 633 proteins matched). Each Table S2 column matches exactly one experiment:

| Table S2 column | Experiment | Correlation r | Match | What it means |
|---|---|---|---|---|
| shTIAR_N | 1 | +0.995 | median abs(S2 − E) 0.010 | heavy = shTIAR |
| shTIAR_CO | 2 | −0.968 | median abs(S2 + E) 0.003 | S2 = −log2 H/M, so medium = shTIAR |
| shFMRP_N | 4 | +0.989 | median abs(S2 − E) 0.001 | heavy = shFMRP |
| shFMRP_CO | 5 | −0.974 | median abs(S2 + E) 0.002 | medium = shFMRP |

Every other pairing has abs(r) ≤ 0.75 and a median abs difference ≥ 0.46.

**Biological marker check.** TIAR is the TIAL1 gene product, so a knockdown should show up as a low TIAL1 ratio:

- TIAL1 H/M is 0.23 and 0.63 in 1B and 1C (MH search normalized: 0.15–0.43), so the knockdown is in heavy.
- TIAL1 H/M is 2.47 in 2C (MH search), so heavy = shNEG.
- FMR1 has no protein group of its own, so the FMRP pairs rest on the exact Table S2 identity alone. That identity is unambiguous.

**Judgement.** This is a data key tied to an explicit author table, with exact numerical identity and an explicitly stated ratio direction. It is the same category as the PXD013461 and PXD029030 precedents that passed, not the "no author table/key" case that was blocked. Under rule 6 it is acceptable. The experiment numbering (1,2,4,5 ↔ the PRIDE pair order) is not needed as a premise, because the exact match identifies each experiment by itself.

**pp2 runs.** These have an explicit source: the Fig 6A scheme labels N as "MEDIUM" (D4-Lys / 13C6-Arg) and CO as "HEAVY". Table S1 'Ratio CoCult/Norm A/B/C' equals log2 H/M normalized for 1c/1d/1e for 100% of the 2126/2085/2009 proteins.

## Findings (minor only)

1. **Provenance.** The manifest should cite the Fig S8 legend ("ratio shRBP to shNEG") as the explicit direction statement behind the PP data key, and the Fig 6A scheme (N = MEDIUM, CO = HEAVY) as the explicit pp2 source.
2. **Design.** shNEG rows in the PP_1x/PP_4x (N) and PP_2x/PP_5x (CO) runs share replicate numbers across distinct source names. That is right only if one shNEG culture per replicate fed both pairs. The label pattern supports this but it is not stated, and the manifest already records it. If separate cultures are ever documented, renumber them 1–6.
3. **Source evidence.** For pp2, `parental (not transduced)` is inferred from the Fig 6 vs Fig 7 legend wording. No sentence states it.
4. **Spec.** `characteristics[genetic modification]` holds free-text construct descriptions, while TERMS says the value should be an EFO term for the method. Curated precedent uses the same free-text style.
