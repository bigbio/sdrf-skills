tumor tissue was dissociated, individual neutrophils were FACS-sorted into 384-well plates, prepared
on a CellenONE X1, and analyzed by DIA on an Orbitrap Astral with a FAIMS Pro interface (50 SPD
method). Data searched with Spectronaut 19.4 against human SwissProt+isoforms.

## Key decisions and evidence

**Modifications — the load-bearing judgement call (attack this).** PRIDE's `modifications` field
says "No PTMs are included in the dataset." The **deposited Spectronaut setup**
(`...Report.setup.txt`, lines 124-128) states `Fixed Modifications: Carbamidomethyl (C)` and
`Variable Modifications:` (empty). So the deposited search used exactly **one** fixed mod,
Carbamidomethyl on C, and no variable mods — the Spectronaut default Oxidation(M)/Acetyl were
disabled. I annotated `NT=Carbamidomethyl;AC=UNIMOD:4;TA=C;MT=Fixed` because
`comment[modification parameters]` records *what was searched*, and this is sourced from the
deposited config, not a reflex.
  **However** — the CellenONE prep protocol (PRIDE `sample_processing_protocol`) contains **no
  reduction and no alkylation step**: cells are placed in the CellenONE, incubated, trypsin is
  added, then quenched with TFA/DMSO. Per the brief's landmine ("never assert Carbamidomethyl
  without an alkylation step"), this fixed mod is **chemically questionable** — it is almost
  certainly a Spectronaut default left enabled, not a real cysteine modification, since there is no
  iodoacetamide/chloroacetamide step. I kept it to faithfully mirror the deposited search but flag
  it as the single most attackable decision: a reviewer may prefer to drop it (leave
  `not available`) on the grounds that no alkylation occurred.

**Enzyme = Trypsin/P (`MS:1001313`), not plain Trypsin.** The setup file states `Enzymes / Cleavage
Rules: Trypsin/P`, `Digest Type: Specific`, `Missed Cleavages: 2`. Annotated to the precise
deposited value.

**Mass tolerances = `not available`.** Spectronaut used `MS1/MS2 Mass Tolerance Strategy: Dynamic`
(auto-calibrated per run) — there is no fixed ppm value to report. `not available` is honest; both
columns allow it (recommended).

**DIA windows from the protocol.** MS2 DIA scan range m/z 400-800 → `scan window lower/upper limit =
400 / 800`; non-overlapping isolation windows of m/z 20 → `isolation window width = 20`.
`comment[dia method] = not available` — a standard rectangular-window DIA with no named variant
(not SWATH/diaPASEF/MSE).

**Ontology terms — all verified live via OLS (never guessed):**
organism `Homo sapiens`/`NCBITaxon:9606`; organism part `brain`/`UBERON:0000955`; cell type
`neutrophil`/`CL:0000775` (the granulocyte lineage term — matched by definition, not label);
disease `glioblastoma`/`MONDO:0018177`; instrument `Orbitrap Astral`/`MS:1003378`; enzyme
`Trypsin/P`/`MS:1001313`; label `label free sample`/`MS:1002038`; acquisition `Data-independent
acquisition`/`PRIDE:0000450`; sample types `single cell`/`PRIDE:0000897` and `negative
control`/`PRIDE:0000905`.

**`disease = glioblastoma` on the single cells (judgement call).** The neutrophils are
tumor-infiltrating immune cells from GBM brain tissue — they are not themselves malignant. I set
`characteristics[disease] = glioblastoma` because the column records the *sample's disease state /
context* and every deposited cell derives from GBM tissue; there is no healthy arm. A reviewer could
argue for `normal`/`PATO:0000461` on the immune cells; I judged the tissue-of-origin disease more
informative and less misleading. Flagged for review.

**FAIMS.** A FAIMS Pro interface was used, but no compensation voltage is stated and no FAIMS CV
column exists in the declared templates, so it is documented here only, not in the SDRF.

## Judgement calls a reviewer should attack hardest

1. **Carbamidomethyl(C) kept despite no alkylation step** — faithful to deposited search vs.
   chemically implausible. The biggest call.
2. **`disease = glioblastoma` on tumor-infiltrating neutrophils** — context-disease vs. `normal`.
3. **`biological replicate` semantics** — I used the **patient** (1-6) as the biological replicate
   index and also as `characteristics[individual]` and `factor value[individual]`. An alternative
   treats each single cell as its own biological replicate. I chose patient-level replication (6
   biological sources); cell-level uniqueness is carried by `cell identifier` instead.
4. **Empty-well controls annotated in-line** (not excluded) with `not applicable` biology and
   `biological replicate = plate patient` — an SDRF describes the deposition, and these 12 runs are
   deposited; but their `biological replicate` integer is a least-bad placeholder.
5. **Factor value choice** — `factor value[individual]` is the only structured experimental axis
   (6 patients); there is no treatment/timepoint/disease contrast in this characterization study.
