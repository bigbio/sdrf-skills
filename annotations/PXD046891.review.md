## Independent evidence checks

- **Files:** PRIDE files/all lists 13 files (8 RAW). All 8 RAW files are annotated, each with a heavy row and a medium row, and no non-raw file is referenced. Every row matches both `sample_overview.xlsx` and the MQ_evidence Raw file→Experiment mapping: 36992/36993 = scr 24h, 36997/36998 = scr 48h, 37002/37003 = p14 24h, 37007/37008 = p14 48h.
- **Fractions:** MQ_evidence gives Fraction 101–104 for the Meth10J runs (z=2) and 201–204 for the Meth13K runs (z=1/3), each pair inside one Experiment. This supports fraction 1/2.
- **RAW method headers (all 8, range-read):**
  - The instrument is an "Orbitrap Fusion".
  - Meth10J: MS1 range 376–801, z=2, stepped HCD at 30/35/40, MS2 in the Orbitrap at 60K.
  - Meth13K: MS1 range 251–1601. z=1 precursors get HCD. z=3 precursors (m/z 251–534) get both an HCD event and an ETD event.
  - The acquisition date path is 2023-04-17.
  - So the ms1 scan range, collision energy, ms2 analyzer, dissociation (HCD on all runs, plus ETD on the fraction-2 runs) and date values are all confirmed.
- **Paper (PMC11459041, NCBI BioC full text):**
  - Ma-Mel-51 is RRID:CVCL_A186, provided by D. Schadendorf, grown in RPMI-1640 and authenticated by genetic fingerprinting.
  - Knockdown was induced with 2 µg/mL dox for 6 days, using a dox-inducible shRNA against p14 (NM_058195.4) or a scrambled control.
  - Dox-treated cells were pulsed with heavy Arg10/Lys8/Leu6 plus dox. Untreated cells got medium Arg6/Lys4/Leu3. Pulses ran 24 or 48 h, then the two cultures were mixed 1:1.
  - HLA-I peptides were enriched by immunoaffinity purification.
  - Search: PEAKS with variable C+57, M ox and pyro-Glu. MaxQuant 2.0 ran with no digestion and default settings otherwise.
- **Table S1** (MOL2-18-2449-s003.xlsx, fetched first-hand from the PMC OA S3 bucket): MaMel51 HLA-I is A\*01:01, A\*02:01, B\*08:01 and B\*18:01. Its source is "D. Schadendorf, University Hospital Essen". Both match the SDRF.
- **Cellosaurus CVCL_A186:** male donor, age 48Y, derived from a lymph node metastasis, NCIt melanoma.
- **OLS (live):** all controlled values resolve to non-obsolete terms with the right label and accession. See `ontology_integrity` in the JSON below.
- **Design:** 8 factor groups (genotype × sampling time × treatment), one culture each, so biological replicate 1 is correct.
  - `convert-openms` assigns 2 files to each of the 8 conditions.
  - Heavy is dox in every sample (no label swap), so label and treatment are confounded. This is inherent to the design and is disclosed in the manifest.
  - Leaving out the light channel is justified: in a pulsed SILAC design the light signal is pre-existing material from both mixed cultures.

## Findings (all minor)

1. **spec, the repeated `comment[dissociation method]` column:** ms-proteomics 1.2.0 does not mark this column `cardinality: multiple`. The content is correct (RAW headers show separate HCD and ETD events), and 41 curated SDRFs repeat the column the same way. *Fix:* none needed here. Raise the cardinality upstream. If a strictly single column is required, keep HCD and record ETD in the limitations.
2. **design, fraction vs technical replicate:** the Meth10J/Meth13K charge-state split is encoded as fraction 1/2. The same-lab curated PXD051190 encodes the identical method pair as technical replicates 1/2. *Fix:* keep this file as is (MaxQuant's fraction numbering supports it), and align the campaign convention later.
3. **omission, total dox exposure:** the dox rows had 6 days of induction plus the 24/48 h pulse, and this total is not encoded. *Fix (optional):* add `characteristics[exposure duration]` = 7 day / 8 day on dox rows and `not applicable` on untreated rows.
4. **provenance, manifest `table_s1` / `review_r1`:** the manifest still calls Table S1 second-hand. *Fix:* cite `https://pmc-oa-opendata.s3.amazonaws.com/PMC11459041.1/MOL2-18-2449-s003.xlsx` and drop the caveat and the `review_r1` source.
5. **ontology, instrument:** the runs contain ETD scans, which points to the ETD model MS:1002417 "Orbitrap Fusion ETD". However, the RAW model string and PRIDE both say "Orbitrap Fusion". *Fix:* keep MS:1002416 and optionally note this.
