## Study and publication

- **Title:** *Pro-regenerative fingerprints identified in a sub-population of adult mouse cardiomyocytes by integrative single-cell proteomics — Pilot dataset.*
- **Paper:** Marín-Vicente et al., *Genome Biology* 2026. DOI `10.1186/s13059-026-04110-1`; PMID 42174693; PMCID PMC13292336 (open access). CNIC (Madrid) / Karolinska.
- **This deposition = "dataset 1 / pilot dataset"** (paper refs [33]). Data-availability statement and Methods both state the pilot used **12 different 10-plex TMTs**, exactly matching the 12 raw files here.
- **Design:** single adult mouse cardiomyocytes, TMT-10plex multiplexed single-cell proteomics (SCoPE-MS/Scope-MS style), comparing **wild-type (control)** vs **Myc-overexpressing** cardiomyocytes to find a pro-regenerative subpopulation.

## Multiplex annotatability — how the channel→sample map was recovered

This is a multiplexed TMT dataset, so one row per (file × channel) requires a channel→sample map. PRIDE deposits only RAW/mzML/mzid — **no sample sheet, no PD study file**. The map was reconstructed from the paper's external repositories, in this order:

1. **Paper Methods (design, level-independent):** TMT-130N "left empty"; TMT-131 = **booster** (lysate of 200 cardiomyocytes = 100 control + 100 Myc); each TMT set = 4 control + 4 Myc single cells; **two alternating label designs (A/B)** to balance tag-type bias.
2. **Zenodo `10.5281/zenodo.19484833` [95] → `Raw_data_1.zip` → `Figure_1/additional/Figure1.xlsx`:** PD 2.5 PSM exports for tmt1 and tmt6 carry the `Spectrum File` column → **TMT1 = SCP_1.raw, TMT6 = SCP_6.raw**; chart titles + representation sheets label **TMT1 = Design A, TMT6 = Design B** with explicit per-channel `CTRL`/`MYC` label rows.
3. **Zenodo `10.5281/zenodo.19439667` [99] → `SCP_iSanXoT.zip` → `.isanxot/date_id/level_creator.tsv`:** the **authoritative, complete channel→sample table for all 12 batches** (120 rows: batch × channel → `CTRL_n` / `MYC_n` / `EMPTY_n` / `CARRIER_n`).
4. **`ID-q.tsv` (same zip):** cross-tabulating its `Batch` column against `Spectrum File` confirms **`SC_thermo_myc_control_N` ↔ `20220323_SST_cnic_SCP_N.raw`, exactly 1:1** (each batch's PSMs come from a single raw file).

**Resulting layout (verified, not inferred):** odd batches (SCP_1,3,5,7,9,11) = **Design A** (126=CTRL, 127N=MYC, 127C=CTRL, …, 130C=MYC); even batches (SCP_2,4,6,8,10,12) = **Design B** (exact inverse: 126=MYC, 127N=CTRL, …, 130C=CTRL). 130N empty and 131 booster in every batch. The per-channel genotype in the SDRF is a direct transcription of `level_creator.tsv`, not an intensity-based guess.

## Key decisions and evidence

- **Organism = Mus musculus** (NCBITaxon:10090). PRIDE + Methods; mouse Rosa26-Myc knock-in model. Not human/rat.
- **Cell type = cardiac muscle cell** (CL:0000746, primary label; "cardiomyocyte" is its synonym).
- **Organism part = heart** (UBERON:0000948). Langendorff-isolated cardiomyocytes after atria were excluded (i.e. ventricular myocytes); kept at the safe "heart" level rather than over-specifying a chamber.
- **Developmental stage = adult** (EFO:0001272). Methods: mice ">14 weeks" for the adult cohort (this pilot).
- **Sex = male** (all rows). Methods: "All experiments were conducted using male … mice."
- **Genotype (the study factor):** `wild type` (control) / `Myc overexpression` (Rosa26-Myc knock-in) per channel from `level_creator.tsv`. Carrier = pool of both → `not applicable`. Mirrored into `factor value[genotype]`.
- **disease = normal** for all: Myc overexpression is an experimental genetic manipulation, not a cardiac disease state.
- **Single cell isolation protocol = manual picking** (fixed-value match). Methods: cardiomyocytes individually picked under the microscope into a 96-well plate. (This pilot = manual isolation; the FACS variant is the *sibling* PXD064501.)
- **cell identifier** = the authoritative iSanXoT per-cell IDs (`CTRL_1..48`, `MYC_1..48`); `carrier` for booster channels.
- **cells per well** = 1 (single cells); 200 (booster = 200-cell pool). **biological replicate** = the cell's numeric index within its genotype (1–48); `pooled` for the booster.
- **Instrument = Orbitrap Eclipse** (MS:1003029). Methods: Orbitrap Eclipse tribrid + FAIMS Pro.
- **Acquisition = Data-dependent acquisition** (PRIDE:0000627). RETICLE = real-time-search-assisted **DDA**.
- **Dissociation = beam-type CID / HCD** (MS:1000422): the **TMT reporter quantification** MS2 is HCD in the Orbitrap (NCE 38). The RTS *identification* MS2 uses CID in the ion trap (NCE 30); a single SDRF value reflects the quantitative (reporter) scan → HCD.
- **Modifications** (from the deposited PD 2.5 workflow, Methods "Data analysis"): TMT-10plex static on **K** and **peptide N-term** (`NT=TMT6plex;AC=UNIMOD:737`, +229.1629 — TMT not TMTpro), Oxidation (M) variable (UNIMOD:35), Acetyl (Protein N-term) variable (UNIMOD:1). **No Carbamidomethyl** — the Scope-MS single-cell protocol has no reduction/alkylation step (only the *bulk* arm, which is a different deposition, alkylates). UNIMOD:1=Acetyl / UNIMOD:21=Phospho swap checked.
- **Cleavage = Trypsin** (MS:1001251); 75 ng trypsin per single cell, overnight.
- **carrier channel = TMT131** (every row); **reference channel = not applicable** — iSanXoT normalises single cells to the batch average, there is no dedicated reference/bridge channel.
- **sample preparation batch = TMT_set_N** — each raw file is one TMT set/plate; recorded for SCP batch-effect correction.
- **fraction identifier = 1**, **technical replicate = 1** — single-cell samples are unfractionated, one injection each.
- All 10 ontology accessions were verified **live via OLS** (NCBITaxon, CL, UBERON, EFO, MS×3, UNIMOD×3, PRIDE×2).

## Empty (130N) channels — deliberate exclusion (reconciliation)

The 12 × TMT-130N positions were "left empty" (no cell, no reagent sample). They are **not** emitted as SDRF rows because an empty channel has no organism and no biological replicate, and `characteristics[biological replicate]` (required) permits neither reserved word. The full 10-plex layout is still documented: `comment[carrier channel]=TMT131` plus the fact that 130N carries no sample. Reconciliation: 120 label positions − 12 empty = **108 annotated rows** (96 single cells + 12 carriers).

## Judgement calls a reviewer should attack hardest

1. **`comment[precursor mass tolerance] = 15 ppm`.** Methods describe a two-step Sequest HT search: **800 ppm** initial precursor window, then a documented **15 ppm** precursor post-filter (Bonzon-Kulichenko 2015). I annotated the effective **15 ppm** (the real precursor accuracy), not the 800 ppm loose window. Challenge if you prefer the literal search window.
2. **Excluding empty channels** vs. emitting them with reserved-word placeholders.
3. **`dissociation = HCD`** (quant scan) while identification used CID — single-value simplification of the RETICLE dual-fragmentation scheme.
4. **`organism part = heart`** vs the more specific `cardiac ventricle` (atria were excluded).
5. **biological replicate numbering** (cell index within genotype) — cells are pseudo-replicates of n=2 mice per genotype; mouse-of-origin per cell is not recoverable.
