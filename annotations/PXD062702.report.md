## Biological model (verified from SI Methods)

- Neural (**D11** = dorsal-animal midline) and epidermal (**V11** = ventral-animal midline) precursor blastomeres of **16-cell** *X. laevis* embryos (Nieuwkoop-Faber **stage 5**) were microinjected with fluorescent dextran, cultured to the **mid-blastula stage (NF stage 8)**, then the vitelline membrane was removed, the fluorescent tissue dissociated (Newport buffer), and **n = 8 D11 + n = 8 V11** descendant single cells were manually isolated with micropipettes. Cells were 50–75 µm diameter. All 16 cells came from **a single clutch (one parental pair)** → the 16 are biological replicates.
- Prep: lysed in 0.2% DDM / 50 mM AmBic, denatured 60 °C/15 min, digested 5 h/40 °C with Trypsin Platinum. **"The classical steps of proteome reduction and alkylation were omitted to alleviate sample loss and simplify the workflow."**
- File→cell mapping is from the filename tokens `_D1..D8` / `_V1..V8`; the V-arm mapping is independently corroborated by the "Found in Sample Group" fields in `EcoAI_V11clones.xlsx` (F141→…_V1 … F148→…_V8).

## Conflicts found (PRIDE vs paper) and how resolved — precedence: raw/SI > paper > PRIDE

1. **Instrument.** PRIDE `instruments` = `["Orbitrap Fusion Lumos", "Q Exactive"]`. The SI states all deposited runs were acquired on the **Q Exactive Plus**; the Fusion Lumos appears only as a *comparison reference* (a separate nanoLC run, not deposited here). Resolved → **Q Exactive Plus (MS:1002634)**. Also note PRIDE says just "Q Exactive"; the specific model is **Plus**.
2. **Modifications.** PRIDE `modifications` = `["monohydroxylated residue", "iodoacetamide derivatized residue"]`, i.e. oxidation + carbamidomethyl. The SI states reduction/alkylation were **omitted**. Resolved → **no Carbamidomethyl** in the SDRF (see judgment call #1). The "iodoacetamide derivatized residue" tag reflects the search parameter and/or the HeLa standard, not the Xenopus peptides.

## Judgment calls I want the reviewer to attack hardest

1. **Carbamidomethyl omitted despite being in the CHIMERYS search parameters.** SI line: static Cys carbamidomethylation was set in the search, **but** the SI also states reduction/alkylation were physically omitted. Per the brief's rule ("Carbamidomethyl only if an alkylation step is documented"), no carbamidomethyl modification exists on the peptides, so I annotated only Oxidation and set the reduction/alkylation reagent columns to `not applicable`. A reviewer prioritizing search-parameter reproducibility over sample chemistry could argue for including `NT=Carbamidomethyl;AC=UNIMOD:4;TA=C;MT=Fixed`. I chose chemistry-faithful; flagged explicitly.
2. **Scope: 27 HeLa method-development standard runs excluded** (rationale above). Alternative reading of "annotate every deposited run" would fold them in as `sample type = standard`, but that needs the cell-lines template the task excluded and mixes organisms/matrices.
3. **`factor value[developmental lineage]` is a descriptive (non-ontology) factor** with no mirroring characteristics column, because SDRF has no column for embryonic lineage/fate. parse_sdrf only requires factor columns to be last (verified in `validators.py`), which is satisfied. The dorsal→neural / ventral→epidermal assignment is the *fate map*, not measured differentiation.
4. **cell type = blastomere and organism part = animal hemisphere for both lineages** — I deliberately did **not** use UBERON `presumptive neural plate`/`presumptive ectoderm` (they exist) because at NF st.8 the cells are undifferentiated blastomeres; those terms would overclaim differentiation state.
5. **developmental stage = blastula st.8 (isolation stage), not the 16-cell labeling stage** — "developmental stage means the donor/embryo stage" at sampling.
