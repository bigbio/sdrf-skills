## Focus questions

| Question | Result |
|---|---|
| H/M/L channel map | **Confirmed.** Sources: the paper's Fig. 2A legend and Results, and the deposit readme ("Light is the internal control spiked into all samples comparing IVA (heavy) versus control (medium heavy)"). Data: the summed viral protein intensity (JD1–JD10) is H ≫ M ≈ L in all 24 deposit experiments. Example C_C_1: H 5.0e10, M 2.4e9, L 2.7e9. |
| Light pool encoding | **Acceptable.** sample type = reference (PRIDE:0000899), pooled sample = pooled, characteristics[cellular component] = not applicable. Each light pool is made from the four compartments of *one* experiment's light culture, so biological replicate 1/2 is right. The spec's `pooled` value (README.adoc:333) is for pools that span replicates. One source per aliquot (24) matches curated PXD000690; one per pool (6) would match curated PXD000332. Both are defensible. Optional: factor value[infection] = not applicable on light rows (F4). |
| NCBITaxon for the virus | **NCBITaxon:132504 is correct.** OLS: "Influenza A virus (A/X-31(H3N2))", not obsolete. The paper uses strain "X:31 (A/AICHI/68)". The PRIDE term NEWT:553341 is "A/Aichi/68/2007(H3N2)", a different taxon from the reassortant X-31. The search FASTA has Aichi/68 HA/NA/M/NS and Hong Kong/68 polymerases/NP. Putting the virus in a custom characteristics[infection] column, not organism, has many curated precedents (51 datasets). |
| Calu-1 fraction = 11 − slice index | **Correct, and now verified from data.** Method: median molecular weight of the proteins identified per file index. In A549 and NCI-H1299 it *falls* with index (index 1 ≈ 100–270 kDa, index 10 ≈ 15–25 kDa). In Calu-1 it *rises* (index 1 ≈ 15–55 kDa, index 10 ≈ 90–530 kDa). The MaxQuant renumbering therefore makes fraction k the same gel region in all three lines. comment[fraction identifier] equals the MQ design Fraction for 720/720 rows. The manifest still calls the slice order "undocumented" (F2). |
| Compartment as factor | **Correct.** Batch rule 16, as in PCP-SILAC. GO nucleus/mitochondrion/cytosol/vesicle match the readme's C/M/N/V and the centrifugation steps in the paper. |
| MOI/time not encoded | **Acceptable.** The values are constant and recorded in the manifest. But ms-proteomics *does* license characteristics[sampling time] (optional), which contradicts the manifest wording (F5). |
| Relation to PXD007809 | **Companion, not duplicate.** No RAW file is shared: PXD007809 holds 385 RAW from 2008–2013, none of them among the 240 here. All 132 runs in this deposit's MaxQuant design that are absent here (2012 AZ_fractions, 2013 WCL) are present in PXD007809. The readme says "an addition to the project PXD007809". The Data Availability section in the Europe PMC XML lists both accessions. |

## Findings

**F1 (important): recommended template columns are missing.** Batch rule 9 says to add recommended columns when evidence exists, and otherwise to use `not available` where it is allowed.
- Columns missing:
  - cell-lines marks `characteristics[sample storage temperature]` and `characteristics[passage number]` as [rec].
  - human marks `characteristics[individual]` as [rec].
- Evidence: the paper's cell-culture Methods say "cell pellets were stored at −80 °C for further use". The fractionation starts from those pellets ("Cell pellets were taken up in homogenization medium"). No passage number or donor ID is stated.
- Fix:
  - Add `characteristics[sample storage temperature]` = `-80 °C` on all rows.
  - Add `characteristics[passage number]` = `not available`.
  - Add `characteristics[individual]` = `not available`, or the Cellosaurus name if campaign precedent does that.
  - Rebuild with `sdrf-tools build`, update the manifest, and run a new review.

**F2 (minor):** the manifest says the Calu-1 slice order is undocumented. Replace that statement with the MW-gradient verification above; it supports the encoded values.

**F3 (minor):** the manifest says the overlap with PXD007809 was not checked. Update it: 0 shared files, 132/132 of the missing MQ-design runs are in PXD007809, and the paper lists both accessions. If PXD007809 is annotated later, coordinate the A549 replicate numbers. Here 1/2 corresponds to MQ C_3/C_4; PXD007809 holds C_1/C_2.

**F4 (minor):** for the light reference rows, consider factor value[infection] = `not applicable`, the curated convention for reference channels. The current value `uninfected` is true. It does not mix the light rows into the medium control group, because factor value[cellular component] = not applicable keeps the conditions apart.

**F5 (minor):** characteristics[sampling time] is licensed (optional). Either add `24 h` for infected rows and `not available` for control and light rows (no harvest time is stated for controls), or correct the manifest's "no licensed column" wording.

**F6 (minor, no change required):** medium rows could use `control sample` (PRIDE:0001014) instead of `study sample`. Both are acceptable. `uninfected`, not `untreated`, is the right control value for the custom infection column; rule 4's `untreated` targets characteristics[treatment].
