## Blocker

**B1. The L-363 arm (rows 1-69) annotates the wrong experiment.** The 23 deposited files `TO_R_Young_190220_110320_HFPlus_136_L6_*.raw` are MaxQuant experiment 140, not experiment 136.

What the evidence shows:
- **Raw files vs search.** I read the RunHeader last scan number of each deposited raw file by HTTP range and compared it with MS + MS/MS in `MaxQuant_136_139/summary.txt`.
  - Fractions 1, 2, 7, 12, 18 and 23 give 32624, 33345, 33984, 34530, 32753 and 30810.
  - Each value matches only `…_110320_HFPlus_140_L6_n`.
  - MaxQuant experiment 136 is `…_060320_HFPlus_136_L2_*` (fraction 1 = 33074). None of its files is in PRIDE `files/all`.
  - The raw header shows the deposited file was acquired in `Data\Mar_20\110320\`, on 2020-03-12.
- **Source Data match.** Source Data Fig. 3a "L363 shCTRL / shNRAS" equals exp **136** log2 M/L and H/L for 3007/3008 genes. Exp **140** matches 1-3 genes (r ≈ 0.64, no better than XG2, SKMM1 or 8226).
- **Deposit sample sheet.** Exp 140 is not in `File_assignment.txt`.
- **Different design.** Exp 140 also behaves unlike exp 136: RAS log2 M/L 4.3 and H/L 4.1, against 0.14 and 0.07.

Consequence: the channel map, hairpin and cell line in rows 1-69 have no explicit source checked against the deposited data. The request does not allow that.

**Fix:**
1. Remove rows 1-69 from the SDRF.
2. Add the 23 `HFPlus_136_L6_*` raws to the PXD031662 entry in `annotations/BLOCKED.md`. Give the reason: the deposited files are MaxQuant exp 140; exp 140 is undocumented; the L363 exp 136 raws (`HFPlus_136_L2_*`) were not deposited.
3. "Unblocked by" should read: authors identify exp 140, or deposit the 136_L2 raws.
4. Update the manifest scope (85 of 319 raws annotated), the claims and the limitations to match, then rebuild and re-review.

## Important

- The manifest says `summary.txt` lists the same raw names as the deposit for 136, 139, 983 and 984. That is wrong for 136.
- The BLOCKED.md scope statement does not mention that the searches include raw files PRIDE does not hold:
  - `MaxQuant_136_139`: experiments 135, 136 (L2), 137 and 138.
  - `MaxQuant_96_96B`: R1_95, R2_95, R2_96 and R2_96B.

**Fix:** correct the claim. In the BLOCKED.md entry and the manifest limitations, list these searched runs as not deposited.

## Minor

- **M1.** `characteristics[genetic modification]` is licensed in TERMS.tsv only by clinical-metadata, which is not declared, and TERMS.tsv expects EFO method terms there. The values here are free-text construct names. The spec allows custom columns, and the producer disclosed this.
- **M2.** The 983 medium/heavy orientation reverses `File_assignment.txt`. I accept it as documented:
  - It follows the manuscript Source Data. I reproduced the match: "XG2 shKRAS" = M/L and "XG2 shCTRL" = H/L, 2588/2589 genes each.
  - RAS M/L 1.95 is below H/L 2.6, which fits medium being the shKRAS channel.
  - It is already recorded in BLOCKED.md. Authors' confirmation would close it.
- **M3.** Encoding 96/96B as technical replicates is an inference. The search also has Rep2 runs, so 96 vs 96B may be separate preparations. This is disclosed.
