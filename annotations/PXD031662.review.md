## Findings (all minor)

1. **`sdrf-tools check` XG-2 flag (rows 70-138).** This is expected; no ontology term exists. No change needed. If CLO/EFO later add XG-2, use that label.
2. **`characteristics[genetic modification]` semantics (all rows).** TERMS.tsv (clinical-metadata) defines this column as the *method* (an EFO term such as knockdown or transduction). Here it holds construct/condition free text, which the column was not defined for, although campaign precedent uses it this way. Optional fix: keep the condition text and, if the campaign adopts it, add a separate method column (e.g. `transduction`/`knockdown`).
3. **96 vs 96B as technical replicates (rows 208-255).** This is an inference, and it is disclosed. MaxQuant also has Rep2 searches of both (R2_96 and R2_96B, not deposited), so "B" is not the replicate index. Both runs correlate equally with Fig. 4b, and `File_assignment.txt` gives them one Sample ID, which supports the encoding. Revisit if the authors describe what distinguishes "96B".
4. **Missing recommended columns.** These are `characteristics[sample type]` (spec default `study sample`, which could be filled on every row), `characteristics[individual]`, `characteristics[passage number]` and `characteristics[sample storage temperature]`. Fix: add `characteristics[sample type]` = `study sample`. The others are not available from the sources.
5. **Experiment 983 orientation overrides the deposit (rows 93-138).** This is justified by the exact Source Data identity, which the reviewer reproduced, and it is disclosed. It remains a conflict between two author sources. Keep the `BLOCKED.md` request for author confirmation.
6. **`BLOCKED.md` accuracy (outside the SDRF).** In MaxQuant_915, experiment 915 was searched from `TO_R_Young_181119_261119_Plus_915_L1_*`, but the deposited files are `…221119_Plus_915_L1_*`, and 221119 is the date of experiment 916 (`…221119_Plus_916_L2_*`). MaxQuant_350 searched `R_Young_260618_170818_L1_*` without the `_350` that the deposited names carry. Fix: note in the PXD031662 `BLOCKED.md` section that the identity of the 915 (and possibly 350) raws also needs checking against the RunHeader before they are unblocked. The SDRF is not affected.
