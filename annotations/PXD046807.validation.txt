## Justification of remaining findings

1. parse_sdrf WARNINGs (4, warning level, exit 0):
   - 'early stage' / 'late stage' in characteristics[disease staging] not in ncit;efo. The values are OLS SNOMED:234438000 "Early stage" and SNOMED:236040000 "Late stage" (both is_obsolete false). NCIT has only "Limited Stage" (C28065) / "Advanced Stage" (C93281), whose definitions ("too extensively ... to allow complete surgical removal") contradict resected tumours; the authors' grouping is only "early"/"late", so the exact labels are kept.
   - 'tumor' / 'normal tissue adjacent to tumor' in characteristics[sampling site] not in uberon;bto. These are exactly the example values listed for this column in clinical-metadata v1.0.0 (clinical-metadata.yaml lines 297-299: "Sampling site should be a valid UBERON or BTO term, or a descriptive term").
2. `sdrf-tools check` (online) exit 1: 'Gln->pyro-Glu' in comment[modification parameters] reported as hallucinated. False positive: OLS4 https://www.ebi.ac.uk/ols4/api/ontologies/unimod/terms?obo_id=UNIMOD:28 returns label 'Gln->pyro-Glu', is_obsolete false; the cell is NT=Gln->pyro-Glu;AC=UNIMOD:28;TA=Q;PP=Any N-term;MT=Variable, from the PD workflows (Sequest HT "Gln->pyro-Glu / -17.027 Da (Q)", Mascot "Gln->pyro-Glu (N-term Q)"). `check --offline` is clean (exit 0). Same false positive documented for PXD007931.
