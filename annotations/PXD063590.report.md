# PXD063590 annotation report

**Status: ANNOTATED** (multiplexed TMTpro35 single-cell proteomics — channel→sample map recovered from a deposited per-cell metadata table)

- Title: *Single cell proteomic analysis of human prefrontal cortex in Alzheimer's Disease*
- SDRF: `annotations/PXD063590.sdrf.tsv` — **2928 rows × 40 columns**
- Templates: `ms-proteomics`, `human`, `single-cell`, `clinical-metadata`
- Validation: `parse_sdrf` (sdrf-pipelines 0.1.5) exit 0 for **all four** templates, validated in **separate runs**. Only warnings: three `Braak stage …` free-text values in `characteristics[phenotype]` (expected — see below).

## Study
Single-cell proteomics of dissociated human dorsolateral prefrontal cortex (Brodmann area 9) from
**three female donors**: one non-AD control and two Alzheimer's disease patients at different Braak
stages. Cells were sorted with a **cellenONE**, prepared with **nPOP**, labelled with **TMTpro (35-plex)**,
and acquired on a **Thermo Orbitrap Exploris 480** (Vanquish NEO LC) using **prioritized single-cell
proteomics (pSCoPE)** — a DDA method. Search: Proteome Discoverer 3.2 + Chimerys.

**Publication: none.** PRIDE lists no publication; Europe PMC free-text search on `PXD063590`
returned hitCount 0. All biology comes from the PRIDE protocol text and the deposited files — no paper
was available to consult, so no per-cell cluster/cell-type calls exist to annotate.

## Annotatability — how the channel→sample map was recovered
This is a multiplexed design, so a per-(file×channel) sample identity was mandatory. It was found in a
**deposited sample sheet**, not inferred:

- **`metadata_pSCOPE.txt`** (in `files/all`, 2750 data rows) — one row per single cell, columns
  `PatientID, well_channel, CellPrepDate, MSdate, age, sex, Braak`. `well_channel` encodes well + TMT
  channel (e.g. `A01_130C`). This is the authoritative channel→sample map.
- **`results_pSCOPE_AD_plate1_matched.txt`** (PSM-level) header independently confirms the mapping:
  columns `FileName, …, Channel, Well, Label, matchingID, Type, Braak`; e.g.
  `FileName=L:\RawData\E480\AD_TMT_plate1_A1.raw, Well=A01, Label=126, Type=carrier` — confirming
  `well A01 → AD_TMT_plate1_A1.raw` and channel 126 = carrier.

**Layout flips (verified):** the channel→patient assignment is **not fixed** across wells. On plate1,
channel `130C` maps to donor 1703 in some wells and 2225 in others (24 wells each). Every cell's donor
was therefore taken from its own `metadata_pSCOPE.txt` row — never from a positional assumption.

### Plate / donor / channel structure (derived and asserted programmatically)
- `MSdate 4/12/2025` → **plate1** (`AD_TMT_plate1_*`); `MSdate 4/19/2025` → **plate2** (`Rep_AD_TMT_plate2_*`).
- **plate1** = donor **1703** (age 73, F, Braak 0, control) + donor **2225** (age 90+ → `>=90Y`, F, Braak V, AD): 1500 cells.
- **plate2** = donor **1854** (age 85, F, Braak III, AD): 1250 cells. (The `Rep_` prefix is misleading —
  plate2 is a *different donor*, not a technical re-injection of plate1.)
- Carrier = TMTpro **126** (10 ng bulk-tissue mix), Reference = TMTpro **127N** (1 ng bulk-tissue mix),
  per the PRIDE protocol; carrier confirmed in the results file. 32 further channels carry single cells.

## Key decisions and evidence
- **Single cells, not nuclei** — protocol: "dissociated to a single cell suspension and sorted using a
  cellenONE"; nPOP/cellenONE operate on whole cells. `sample type = single cell` (PRIDE:0000897).
- **Not a cell line** — primary post-mortem brain tissue; no `cell-lines` template.
- **Organism part** `dorsolateral prefrontal cortex` UBERON:0009834 (more specific than the generic
  prefrontal cortex UBERON:0000451; matches "DLPFC, Brodmann area 9" in the protocol).
- **Disease**: donor 1703 (Braak 0, "non-AD control") → `normal` PATO:0000461; donors 1854 & 2225 →
  `Alzheimer disease` MONDO:0004975. Factor = `factor value[disease]`.
- **Modifications** taken from the deposited search parameters (data processing protocol), not guessed:
  fixed TMTpro on K (`UNIMOD:2016;TA=K`) and peptide N-term (`UNIMOD:2016;PP=Any N-term`), variable
  Phospho on S/T (`UNIMOD:21;TA=S,T`). **No Carbamidomethyl** — the nPOP prep documents no
  reduction/alkylation step and the search parameters list no C-alkylation, so none was asserted.
- **Labels**: PRIDE ontology names the TMTpro-35 channels `TMT126 … TMT135CD` (not `TMTpro…`). Each of
  the 34 channels used was mapped to its PRIDE accession; all verified live via OLS.
- Instrument MS:1003028, Trypsin MS:1001251, DDA PRIDE:0000627, adult EFO:0001272 — all OLS-verified.

## Values left `not available` / `not applicable` (and why)
- `characteristics[cell type]` = **not available** for single cells — cellenONE sorted cells unbiased;
  per-cell type would be a post-hoc clustering call that is **not deposited** and there is no paper.
  `not applicable` for carrier/reference (bulk tissue pools, no single cell type).
- `comment[dissociation method]`, `comment[precursor/fragment mass tolerance]` = **not available** —
  not stated in the protocol (HCD is technically required for TMT MS2 reporter quant, but it is not
  documented, so it was **not** asserted).
- Carrier/reference rows: `disease`, `phenotype`, `cell type`, `cells per well`,
  `single cell isolation protocol` = **not applicable** (pooled bulk mix, not a single-cell sample);
  `age` = **not available** (the `age` column's pattern validator rejects the reserved word `pooled`,
  and `not applicable` is disallowed for `age`); `individual` = `pooled`.

## Conflicts found and how resolved (raw/deposited > PRIDE fields)
- **Braak stage of the higher-stage AD donor**: PRIDE description says "Braak III and VI";
  `metadata_pSCOPE.txt` says donor 2225 = **Braak V**. Deposited data wins → annotated **Braak V**.
- **PRIDE `modifications` = "No PTMs are included in the dataset"** contradicts the data processing
  protocol (TMTpro fixed + Phospho variable). Used the protocol/search parameters.
- **PRIDE `instruments` = Orbitrap Exploris 480** agrees with the protocol and the results-file raw path
  (`L:\RawData\E480\…`). No conflict.

- **Stated** (protocol / deposited files): organism, tissue, cellenONE, nPOP, TMTpro35, Exploris 480,

## Judgement calls a reviewer should attack hardest
1. **Donor 2225 age = `>=90Y`** (source: `90+`, a HIPAA age cap meaning ≥90). CORRECTED post-review:
   the first pass wrote `90Y`, which overstates a censored value by asserting exactly 90. The human
   template's `age` regex `^(>=?|<=?)?…` supports a leading comparison operator, so `>=90Y` is both
   validator-legal and the precise meaning of `90+`, preserving the ≥90 floor. (The template prose also
   lists `anonymized` for protected ages, but the parse_sdrf regex rejects that token — a spec/tool
   mismatch; `>=90Y` is used because it validates AND keeps the floor information.) Donors 1703 (73Y)
   and 1854 (85Y) are exact in the metadata and unchanged.
2. **Including carrier/reference as rows** with `disease = not applicable`, even though they are pooled
   bulk lysate mixing AD + control tissue. They are deposited channels with signal and are classified by
   sample type per the brief; they are excluded from `factor value[disease]`.
3. **`cell type = not available`** rather than assigning a broad term (e.g. neural cell). No per-cell
   type is deposited and there is no paper, so any biological cell type would be fabricated.
4. **Braak stage recorded in `characteristics[phenotype]`** as free text (`Braak stage 0/III/V`) — this
   produces the three warning-level messages (phenotype's ontology check is warning-only and explicitly
   permits free text per TERMS.tsv). This is the intended, licensed home for a disease-severity covariate
   (clinical-metadata adds no new required columns).
5. **`assay name` shared across a file's 34 channels** (one MS run = one assay) and **biological
   replicate** numbered sequentially per donor — both are conventions, not stated in the data.
6. **TMTpro N-term written `PP=Any N-term`** (peptide N-terminus after tryptic digestion), not
   `Protein N-term`.
