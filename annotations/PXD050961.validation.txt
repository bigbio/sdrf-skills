## Refutations / explanations
- reconcile BLOCKER cleavage_agent_unsupported (both files, exit 1): FALSE POSITIVE. The PRIDE sampleProcessingProtocol says "... digested with sequencing-grade LysC (Wako) at a 1:50 enzyme-to-protein ratio for 2 hours, then further diluted 1:4 with 50 mM Tris-HCl pH 8 and digested with sequencing-grade trypsin (Promega) at a 1:50 ratio overnight." tools/record_reconcile.sentences() fails to split after "at 4 °C." and merges this sentence with the previous one, which contains "protease inhibitors"; _PROTEASE_ROLE_EXCLUDE ("inhibitor") then discards the digest sentence (debug: sentences(prose(record)) returns one string starting "Cell pellets were lysed ... protease inhibitors ... at 4 °C. The lysate was reduced ..."). Paper Methods state the same Lys-C then trypsin digest. Values kept.
- check "Hallucinated" (spied, exit 1): the two hits are the deliberate free-text value 'synthetic phosphopeptide spike-in (not cell-derived)' in characteristics[cell line] / factor value[cell line] of the 56 SILAC heavy spike-in reference rows. cell-lines v1.1.0 forbids both reserved words there; free text follows the curated-batch precedent PXD021428 (super-SILAC reference row). Not an ontology claim. parse_sdrf reports it only as a warning.
- parse_sdrf WARNING 'untreated' not in NCIT/EFO for characteristics[treatment]: template-prescribed control value (campaign rule 4); vehicle DMSO / 0.1% BSA controls.
- convert-openms exit 1 (both files): "Cannot read precursor mass tolerance: not available". DIA-NN 1.8.2 auto-optimised mass accuracy (no --mass-acc-ms1 in any log); only per-run "Recommended MS1 mass accuracy" values are logged, so the applied MS1 tolerance is unrecorded. Sentinel kept per references/validation.md; the files cannot be converted as is.
- structure: OK on both files after the shared-reference source names were made one per physical aliquot (light reference per dilution mixture in Benchmark1; spike pool per Benchmark2 sample well; per run in panel/GFs), so technical replicates are contiguous and constant within each data file.
