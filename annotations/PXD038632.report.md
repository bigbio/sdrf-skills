## Row model
mDIA = one Evotip/run carries **3 dimethyl channels**: Δ0 reference + Δ4 single cell + Δ8 single cell.
Each of the 453 runs → **3 rows** (one per channel) = **1359 rows**. All 3 rows of a run share the
same `comment[data file]` (the `.d`); channels are distinguished by `comment[label]`.
- **Δ0 (light, DIMETHYL0)** = the ~10 ng bulk HeLa reference pool loaded into every Evotip.
  `sample type = reference`, `pooled sample = pooled`, `cell identifier = reference`,
  `cells per well = not applicable`, `single cell isolation protocol = not applicable`. NOT a single cell.
  All 453 Δ0 rows share `source name = HeLa_reference_pool` (one physical pool, aliquoted per tip).
- **Δ4 (DIMETHYL4)** and **Δ8 (DIMETHYL8)** = one FACS-sorted HeLa single cell each.
  `sample type = single cell`, `cells per well = 1`, `single cell isolation protocol = FACS`,
  unique `source name`/`cell identifier` = `<plate>_<injIdx>_delta{4|8}`.

## Key decisions & evidence
- **Dimethyl channel→UNIMOD (verified live via OLS by exact mass; the known trap)**:
  Δ0 light 28.0313 → **UNIMOD:36** (Dimethyl); Δ4 +4.0251 (2H(4)) → **UNIMOD:199** (Dimethyl:2H(4));
  Δ8 +8.0444 (2H(6)13C(2)) → **UNIMOD:330** (Dimethyl:2H(6)13C(2)). **Not UNIMOD:510** (2H(4)13C(2), +6).
  Confirmed against DIA-NN `report.log.txt`: fixed `Dimethyl 28.0313 at nK`; channels registered
  `0 [0]`, `4 [4.0251]`, `8 [8.0444]`. Encoded as fixed dimethyl on peptide N-term (`PP=Any N-term`)
  and on K (`TA=K`) per channel — matching `--fixed-mod Dimethyl,28.0313,nK`.
- **No Carbamidomethyl** (paper explicit: single cells not reduced/alkylated; DIA-NN log shows only
  Dimethyl fixed + Oxidation variable). `reduction reagent` / `alkylation reagent` = `not applicable`.
- **Variable mod**: Oxidation (M) UNIMOD:35, max 1 variable mod (log).
- **Enzyme**: Trypsin (MS:1001251) + Lys-C (MS:1001309); log cuts at K/R (trypsin/P). Two
  `cleavage agent details` columns.
- **Instrument**: timsTOF SCP (MS:1003231); Whisper40 SPD; dia-PASEF → `Data-independent acquisition`
  + `dia method = diaPASEF` (PRIDE:0000650); `ms2 mass analyzer = time-of-flight`;
  `dissociation = beam-type CID`. Tolerances 15 ppm/15 ppm (data_processing_protocol: ultra-high
  sensitivity fixed to 15 ppm MS1 + mass accuracy).
- **HeLa identity** (Cellosaurus, live): CVCL_0030 (generic HeLa; no HeLa-S3 basis — this is
  cultured HeLa C, not a commercial digest). Organism part `uterine cervix` (UBERON:0000002),
  cell type `epithelial cell` (CL:0000066), disease `cervical adenocarcinoma` (MONDO:0005153),
  developmental stage `adult` (EFO:0001272), age `30Y`, sex `female`.
- **No experimental factor**: untreated HeLa only; single cells are anonymous replicates keyed by
  channel + plate + well/run. No treatment/condition/disease contrast exists, so **no `factor value`
  column** is emitted (documented; the dataset is a methods benchmark, not a comparative study).
- **Batch**: `comment[sample preparation batch] = <plate>` (384-well plate = prep batch, the main SCP
  confounder).

## Values left not available / not applicable — and why
- `single cell isolation protocol`, `cells per well`, `cell identifier` (Δ0 rows) = **not applicable**:
  the reference channel is a bulk pool, not an isolated cell.
- `reduction reagent`, `alkylation reagent` = **not applicable**: no reduction/alkylation step.
- `carrier channel` = **not applicable**: mDIA uses a reference (not a carrier) channel.
- `scan window lower/upper limit`, `isolation window width` = **not available**: the dia-PASEF
  window scheme (Appendix Table S8) is not in the searched text; recovering it would require parsing
  `analysis.tdf` (`DiaFrameMsMsWindows`) from inside the 2.1 TB `mDIA_singleCell_raw.zip`. Deferred.

## Judgement calls a reviewer should attack hardest
1. **`biological replicate = 1` for every row.** Each single cell is a unique biological entity (unique
   source name) measured once; the reference is one pool. There is no replicate structure, so all values
   are 1. A reviewer may prefer 1..N numbering of single cells — defensible either way.
2. **Reference Δ0 as `sample type = reference` + `pooled sample = pooled`** (vs the sibling PXD038699
   which used `sample type = pooled` + `cell identifier = not applicable`). Chose the template-sanctioned
   `cell identifier = reference` special value and the more specific `reference` role; pooled-ness is
   captured in `pooled sample`.
3. **Including both `human` and `cell-lines`** (sibling used only the organism template). Adds
   Cellosaurus accession + donor sex/age but forces `age`/`sex` as required columns.
4. **Excluding the 9 `scBenchmark_empty` decoy runs** and the scReference/scBenchmark/scQuant/RefEx
   0.0625–0.25 ng "single-cell mimic" arms as dilution standards, not cells.
5. **Whole reference pool shares one `source name`** across 453 runs (physically one aliquoted pool).
