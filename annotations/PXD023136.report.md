## Open items and limitations
1. **Blocked:** the 36 pulse-chase runs (Fig 3F/3G). Experiment names are only 01-36, and the design is only in the inaccessible PNAS paper. See BLOCKED.md.
2. **Precursor tolerance:** `not available`, so convert-openms exits 1 for both files.
3. **Instrument conflict:** the preprint names an Orbitrap Fusion Lumos. The raw headers show Q Exactive Plus and Orbitrap Elite, and the raw headers were used.
4. **SILAC KO clone:** the clone (T126AKO-1 or another) is not named, so no clone id is given.
5. **Independence of cultures:** the 3 replicates per arm are assumed independent. For SILAC this follows from the label switch; for AE-MS it is not stated.
6. **reconcile on aems-lfq:** it flags the label (the project lists SILAC) and the instrument (the protocol text names Q Exactive plus). Both are refuted in validation.txt.
7. **`not available` values:** ancestry, age, passage number, storage temperature, cell type and individual.
