## Findings

### IMPORTANT: unsearched runs claim that no modifications apply
- **Location:** rows 669–676, the 4 runs `Animal_20180722_MH_SA_CTLA4_3_1`, `_3_2` and `_3_1_180725104610` (CTLA3), and `Animal_20170517_MH_SA_TIL_86_1_170525111353` (TIL86), light and heavy rows.
  - Affected columns: all 5 `comment[modification parameters]`, plus both tolerance columns.
- **Evidence:** on these rows every modification column says `not applicable`.
  - The same rows declare `comment[alkylation reagent]=Iodoacetamide`, so Carbamidomethyl on C applies.
  - The heavy rows declare `SILAC heavy` (Lys8/Arg10, UNIMOD:259/267).
  - `summary.txt` (Fixed Carbamidomethyl, Labels1 Arg10;Lys8) and the PRIDE protocol both apply these modifications to these samples.
  - The design file assigns these runs to CTLA3 and TIL86.
  - Per `technical-values.md`, `not applicable` asserts that the step did not happen.
  - Running `parse_sdrf convert-openms -t2` on the delivered file aborts with `ValueError: Cannot read precursor mass tolerance: not applicable`.
- **Fix:**
  1. Give the 8 rows the same 5 modification parameters as the other runs of the same samples.
  2. Set the tolerances to the dataset search settings (4.5 ppm / 20 ppm).
  3. State in the manifest that these runs are in the design file but missing from `summary.txt`.
  4. Re-run `validate-sdrf` and `convert-openms` on the full file.

### minor
1. **Survival time for patients still alive:** 14 patients have S1A Death = N (CTLA1, 10, 12, 18, 21; PD3, 22, 58; TIL64, 69, 72, 78, 80, 82). Their OS value is a censored follow-up time; for example, CTLA12 shows `3.87 month` but is alive. **Fix:** add `characteristics[last follow up]` and/or an explicit vital status, or move the censored values there.
2. **Metastasis site:** **fix:** consider filling `characteristics[metastasis site]` / `[biopsy site]` (oncology-metadata) from S1A "Biopsy site". The site is currently carried only in organism part.
3. **`NA` inside free text:** `clinical history` and `clinical data` contain the token `NA` (for example "prior MAPK inhibitor: NA"). **Fix:** write `not available` instead.
