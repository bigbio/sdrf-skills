## Findings

### IMPORTANT: the immunotherapy group is not a structured column

- **Location:** all 338 SILAC light rows. This affects `factor value[treatment response]` and `characteristics[treatment status]`.
- **Problem:** the therapy each patient received appears only inside the free-text `characteristics[clinical data]`. S1A "Immunotherapy group" gives:
  - TIL: 44 patients
  - anti-PD1: 6 patients
  - anti-CTLA4: 20 patients
- **Why it matters:**
  - The declared response factor mixes responses to three different therapies.
  - "on treatment" does not say which treatment.
  - The therapy group is fully confounded with technical set and instrument. The CTLA4 samples are set 3, run on the QE Plus in 2018; TIL45-86 are set 2, run in 2017.
- **Precedent:** PXD006003, the curated dataset from the same lab, carries therapy in `characteristics[compound]`.
- **Fix:**
  1. Add `characteristics[treatment]` (or `characteristics[compound]`) to each light row from S1A, using these terms:
     - TIL → Tumor Infiltrating Lymphocyte Therapy (NCIT:C15524)
     - a-PD1 → PD1 Inhibitor (NCIT:C124946)
     - a-CTLA4 → Anti-CTLA-4 Monoclonal Antibody (NCIT:C128036)
  2. Set `not applicable` on the heavy reference rows.
  3. Consider adding `factor value[treatment]`.
  4. Add a manifest claim citing `suppl_S1`.
  5. Rebuild, re-validate and request a fresh review.

### Minor findings (not blocking)

1. **Cell-line composition in a clinical column.** The heavy rows put the super-SILAC cell-line composition in `characteristics[clinical data]`, which is a patient-clinical column. Fix: move it to `characteristics[cell line]` or a comment, and set `not applicable` on those rows.
2. **Survival time.** Overall survival is free text. Fix: optionally add `characteristics[survival time]` (oncology-metadata), for example `88.7 month`.
3. **TIL68/69/71/74/79 second runs.** The second single-shot run is annotated as technical replicate 2 / fraction 1, but MaxQuant used it as Fraction 2 of the same experiment. This is defensible and disclosed, and the samples are low quality and excluded from the paper.
4. **Lys-C inference.** Lys-C for technical sets 2-3, including the unfractionated TIL68-79 runs, is inferred from the SCX method names and the PRIDE TFE protocol. Fix: keep it disclosed, and mention the single-shot runs explicitly.
5. **OpenMS conversion.** `convert-openms` fails on the full file because the 4 never-searched runs carry `not applicable` tolerances. The spec does not require a change. Optionally document that these runs must be filtered out before conversion.
