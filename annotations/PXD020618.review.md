## Findings (all minor)
1. **characteristics[clinical data]** stores the technical set (a sample-preparation batch) and the low-quality QC flag as free text. It also repeats OS unrounded (e.g. `21.23333333 months`). Fix (optional): move the technical set to `comment[sample preparation batch]` so the disclosed confounding is machine-readable, and round OS.
2. **comment[fractionation method]**: single unfractionated 240-min runs (TIL25, TIL68/69/71/74/79, CTLA20) are `not available`. Fix (optional): `not applicable`.
3. **convert-openms** fails on the full file because the campaign convention sets the tolerances of rows 669-676 to `not applicable`. No change is needed, but downstream users must drop those rows before conversion.
4. **characteristics[treatment]** on pre-treatment rows names the therapy the patient received after sampling. It can only be read correctly together with `characteristics[treatment status]`, which is present. No change needed.
5. **Replicate numbering**: the searched CTLA3 re-injections are TR1, although they were acquired after the unsearched originals (TR2/TR3). The TIL68/69/71/74/79 second injections are fraction 1 / TR2, whereas MaxQuant gave them Fraction 2. Both choices are documented and acceptable.
