## Templates chosen and why
Declared per row via `comment[sdrf template]`:
- **ms-proteomics v1.1.0** (technology) + **single-cell v1.0.0** + **dia-acquisition v1.1.0** — on
  **all 491 rows** (LC-MS/MS, CellenONE single cells, diaPASEF DIA).
- **cell-lines v1.1.0** — on the **395 cell-line rows** (Fig1–5) only.

**Why not `human`/`vertebrates`:** the dataset spans **both** human (RKO, MDA-MB-231) and mouse
(KPC PDAC, acinar) samples, and those two organism templates are **mutually exclusive**. To keep the
whole PXD in one file I used the organism-agnostic templates and carry organism as the base
`characteristics[organism]` column. Consequence: the human/vertebrate-specific columns
(`sex`, `age`, `ancestry`, `strain`, `developmental stage`) are **not licensed and omitted** — see
"left blank" below.

**The `cell-lines` cell-line trap and the mouse tissue arm.** `cell-lines` makes
`characteristics[cell line]` required with **no reserved words allowed**. The Fig7 acinar rows are
**primary tissue, not a cell line**, so they cannot carry a real cell-line value. I therefore do
**not** declare `cell-lines` on the 96 tissue rows (their `comment[sdrf template]` #4 = `not available`,
which the column allows) and set their `cell line`/`cellosaurus *` = `not applicable`. The 395
cell-line rows *do* declare `cell-lines` and carry real values.

**Validation (two passes, both `parse_sdrf` exit 0, warnings only):**
1. Full 491-row file vs `ms-proteomics + single-cell + dia-acquisition` → clean.
2. 395-row cell-line subset vs the same **+ `cell-lines`** → clean (proves the cell-line rows satisfy
   `cell-lines`; the tissue rows legitimately do not conform to it and are excluded from that pass).

## Key decisions with evidence
- **Cell-line identities (Methods, verbatim):** *"RKO, MDA-MB-231 and PDAC cells were cultured…"* →
  the "MDA" line is unambiguously **MDA-MB-231** (not -468). Cellosaurus confirmed:
  - **RKO** = `CVCL_0504` (Homo sapiens, colon carcinoma) — CLO:0008825. **Confirmed as requested.**
  - **MDA-MB-231** = `CVCL_0062` (Homo sapiens, breast adenocarcinoma; derived from a metastatic
    pleural effusion) — CLO:0007634.
- **Fig5 PDAC is MOUSE, not human** (contradicts the naive "pancreas = human" reading): Methods —
  *"a murine pancreatic ductal adenocarcinoma (PDAC) KPC (BL6J) cell line … pooling cells from
  tumours … KPC genetically-engineered mouse model."* Organism = *Mus musculus*. No Cellosaurus entry
  exists for this lab-pooled line → `cell line = KPC`, `cellosaurus accession/name = not available`.
- **Fig7 is mouse pancreatic acinar TISSUE** (in-vivo), *"a pancreas from a wild-type BL6/129 mouse …
  dissociated into single cells"* → organism *Mus musculus*, organism part pancreas (UBERON:0001264),
  cell type **pancreatic acinar cell** (CL:0002064), disease **normal** (PATO:0000461, wild-type).
- **NO Carbamidomethyl / no reduction/alkylation.** The SCP prep is a single master mix
  (0.2% DDM, 100 mM TEAB, 10 ng/µL trypsin) with **no reduction and no alkylation** step. Per the
  brief's warning, I did **not** add Carbamidomethyl. `reduction reagent` / `alkylation reagent` /
  `modification parameters` = `not applicable`. PRIDE `modifications` = "No PTMs" corroborates.
- **Acquisition:** `data-independent acquisition` (enum) + `comment[dia method] = diaPASEF`; instrument
  `timsTOF SCP` (MS:1003231, PRIDE lists it and it matches Methods); dissociation `CID` (MS:1000133);
  label `label free sample` (MS:1002038); cleavage `Trypsin` (MS:1001251; Methods specify Trypsin/P).
- **Isolation:** `single cell isolation protocol = cellenONE` (fixed-enum value; CellenONE dispensing);
  `sample type = single cell` (PRIDE:0000897); `cells per well = 1` for every annotated row.
- **All ontology accessions verified live via OLS** (organism, UBERON parts, MONDO diseases,
  CL types, CLO cell lines, MS/PRIDE technical terms). None guessed.

## Values left `not available` / `not applicable` and why

  `modification parameters` (no such steps / no PTMs searched); Fig7 tissue `cell line`,
  `cellosaurus accession`, `cellosaurus name` (primary tissue, not a cell line); Fig5 KPC
  `cellosaurus accession`/`name` = `not available` (line exists, has no Cellosaurus record).
- `not available` (exists but not stated): `precursor/fragment mass tolerance`, `collision energy`
  (Spectronaut defaults, not reported), `scan window lower/upper limit`, `isolation window width`
  (two py_diAID window schemes are described but **not mapped to individual figures/runs**, so I did
  not assert a per-run value); Fig7 tissue `comment[sdrf template]` #4.
- **Omitted columns (not licensed here):** `sex`, `age`, `ancestry`, `strain`, `developmental stage`.
  These are cohort-relevant (MDA-MB-231 female; acinar mice 15 wk / adult) but require the
  `human`/`vertebrates` templates, which are mutually exclusive and cannot both be declared. Noted as
  a deliberate limitation of unifying human+mouse in one file.

## Conflicts found and how resolved
- **PRIDE vs paper — organism per figure.** PRIDE lists organisms `[Homo sapiens, Mus musculus]` at
  the project level with no per-run split. Resolved per figure from the Methods (RKO/MDA = human;
  KPC PDAC + acinar = mouse).
- **PRIDE `modifications` = "No PTMs"** — consistent with the no-alkylation prep; accepted.
- **Search-table columns vs deposited raw.** The search TSVs list more samples than the raw deposit
  (blanks/dilutions/library). Resolved by treating the **raw `.d` set as authoritative** for what is
  deposited (brief precedence: raw > Methods > PRIDE).

## Inferred vs stated
- **Stated:** cell-line names & organisms; fixation reagent/%/duration; instrument; DIA/diaPASEF;
  CellenONE; trypsin; no reduction/alkylation; wild-type mouse pancreas.
- **Inferred:** `cell type = epithelial cell` (CL:0000066) for the carcinoma lines (lineage inferred
  from carcinoma origin; paper gives no finer subtype — deliberately kept generic per the
  specificity rule); `dissociation = CID` (standard timsTOF fragmentation, not explicitly stated);
  disease `colorectal carcinoma` for RKO (Cellosaurus: "colon carcinoma"); `treatment` free-text
  condition labels; `biological replicate` = unique integer per cell (SCP convention; each cell is a
  distinct biological entity).

## Warnings accepted (parse_sdrf)
- `characteristics[treatment]` free-text values not in NCIT/EFO — **accepted**: the preservation
  conditions ("0.3% paraformaldehyde fixation, 24 h", "cryopreservation, 10% DMSO in FBS", "sgGSTP1
  knockout", …) have no single clean ontology term; free text is the honest representation and drives
  `factor value[treatment]`.
- `characteristics[cell line]` "MDA-MB-231"/"KPC" not label-matched in CLO/BTO/EFO — **accepted**:
  the CLO label is "MDA-MB-231 cell" (suffix mismatch) but the accession `CLO:0007634` is verified
  correct; KPC has no ontology entry.

   the mouse tissue arm. I chose completeness + a single deposit-faithful file, trading away
