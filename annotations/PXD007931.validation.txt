- sdrf-tools check (online) exit 1: 'Gln->pyro-Glu' in comment[modification parameters] is reported as hallucinated. This is a false positive. The independent review reached the same conclusion. check --offline is CLEAN (exit 0).
- sdrf-tools reconcile exit 1, cleavage_agent_unsupported: refuted (rule 13). The accessible record does not name the digestion enzyme: PRIDE says 'Protein digestion and MS analysis were performed as described previously', and the paper is closed access.
  - The value comes from the deposited MaxQuant searches: Enzyme 'Trypsin', Enzyme mode 'Specific', max 2 missed cleavages in all three.
  - Those searches gave 72,527-76,559 MS/MS-identified evidences and 12-18 % identified MS/MS per run, which a non-tryptic digest could not reach under a specific-trypsin search.
  - The contract allows only 'not applicable' as a reserved word for this column. The independent review accepted this refutation.
- parse_sdrf convert-openms exit 1: 'Cannot read precursor mass tolerance: not available'. This is the expected failure, because MaxQuant 1.5.2.8 records no precursor tolerance and no mqpar.xml was deposited.
  - Apart from that, conversion passes: on a scratch copy with only that cell set to '20 ppm' (test value, not annotated), convert-openms exits 0 for each of the three files ('SUCCESS (WARNINGS=1)'), writing openms.tsv (16 runs + header) and experimental_design.tsv.
