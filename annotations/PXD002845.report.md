## Design (super-SILAC / spike-in standard)
- **Light** = patient endometrial stromal cell (ESC) lysate; **heavy (Lys8/Arg10)** = spike-in SILAC standard
  (2:1 secretory-phase ESCs : Ishikawa endometrial cancer cells, CVCL_2529), mixed 1:1 before eFASP digestion.
  Source: PRIDE sample protocol ("spiked 1:1 with the SILAC standard ... labelled with heavy isotope lysine and arginine");
  MaxQuant Labels0 empty / Labels1 Arg10;Lys8, multiplicity 2 for all 160 runs (rule 14 verified).
  Data check: Ishikawa epithelial markers are heavy-enriched (median log2 H/L KRT8 +3.5, CDH1 +3.0, EPCAM +2.9, KRT18 +2.2;
  stromal VIM −0.8).
