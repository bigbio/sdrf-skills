## Study
- PRIDE: "Conserved GTPase LepA (Elongation Factor 4) functions in biogenesis of the 30S subunit of the 70S ribosome"; organism *Escherichia coli*; SILAC; protocols say only "published in PMID 28096346".
- Paper: Gibbs MR, Moon KM, Chen M, Balakrishnan R, Foster LJ, Fredrick K. PNAS 2017;114(5):980-985. PMID 28096346, PMC5293072, doi:10.1073/pnas.1613665114. Not open access (see limitations); Methods/SI read via WebFetch of the PMC page, short exact quotes in scratch `evidence/paper_quotes.txt`.
- Design: SILAC (Lys− Arg− auxotroph derivatives of BW25113). Light = WT (MRG03 / MRG06), medium Arg 13C6 + Lys 2H4 = deletion mutant (MRG04 ΔlepA / MRG07 ΔrsgA), heavy Arg 13C6 15N4 + Lys 13C6 15N2 = complemented mutant (MRG05 ΔlepA/lepA+ / MRG08 ΔrsgA/rsgA+). Each strain's lysate went through its own sucrose gradient; corresponding fractions of the strains were mixed, TCA-precipitated, short SDS-PAGE, in-gel digested, measured on an Impact II Q-TOF (Easy nLC 1000), searched with MaxQuant 1.5.1.0.

## Key decisions and evidence
1. **Channel map** (batch rule 6) — explicit SI Methods statement (light MRG03/MRG06, medium Arg13C6/Lys2H4 MRG04/MRG07, heavy MRG05/MRG08) + data check: in lepA_3plex1 LepA M/L 0.45 and H/M 9.0; in rsgA_3plex1 RsgA M/L 0.18 and H/M 11.7 (mutant channel depleted, plasmid-complemented channel overexpressed; the non-targeted GTPase is flat). The 2-plex searches quantify neither target, so the 2-plex map rests on the text alone. The 2-plex Arg6/Lys4 state is labelled `SILAC medium` (the paper's "medium"), although MaxQuant calls the second state of a 2-plex search "H".
2. **Data file** = `.d` member name inside the ZIP (reviewed PXD004817 precedent; a ZIP name cannot identify a run). Run → ZIP mapping is in scratch `run_fraction.tsv` and follows from the naming (`lepA_2plex-1.zip` holds the lepA_2plex1 runs, etc.).
3. **Modifications** from the deposited searches (identical in all 11): Carbamidomethyl C fixed; Oxidation M, Acetyl Protein N-term variable; SILAC labels as variable (rule 11) — Label:13C(6) R UNIMOD:188 and Label:2H(4) K UNIMOD:481 for all; Label:13C(6)15N(4) R UNIMOD:267 and Label:13C(6)15N(2) K UNIMOD:259 only in 3-plex rows, `not applicable` in 2-plex rows (rule 5, identical headers).
4. **Tolerances**: fragment 40 ppm (TOF MS/MS tolerance in all parameters.txt). Precursor: 0.006 Da (lepA_2plex1 mqpar), 10 ppm (rsgA_3plex2/3/4 mqpar), `not available` for the other 7 searches (no mqpar; parameters.txt/summary.txt do not record it; the two recorded values differ, so no value is carried over).
5. **Instrument** impact II (MS:1002666) from paper + `.d` method files (PRIDE only gives "Bruker Daltonics instrument model"). DDA; beam-type CID; TOF MS2 analyzer.
6. **Sucrose-gradient fraction = sample property and factor** (round 2, review finding 2; curated PXD004650 pattern). Each run is one gradient fraction in which the matching WT/M/C fractions were mixed, and the paper's readout is the per-fraction ratio profile (Fig. 1 fractions 6–16, Fig. 3 6–18). So `characteristics[sucrose gradient fraction]` and `factor value[sucrose gradient fraction]` hold the fraction number (1–18; MaxQuant `Experiment` cross-checked against the run name), each search × strain × fraction has its own source name (e.g. `lepA_3plex1_MRG04_fr07`), and `comment[fraction identifier]` = 1 on every row. (source, technical replicate, fraction, label) and (source, assay, label) are unique (asserted). The only post-build step is the concatenation of the 2-plex and 3-plex builds; it is needed because `build` takes one constant modification set per technical table, and it changes no cell (verified byte-identical).
7. **Re-injections**: five runs whose original injection is also deposited (JM_KurtF1REDO; rsgA2plex-1 F01/F02/F03-redo; rsgA3plex-1 F11-redo) are `comment[technical replicate]` = 2. Runs named redo/repeat whose original is not deposited are the only injection of that fraction (technical replicate 1).
8. **Biological replicate** numbered per genotype group, unique per culture (rule 3) and shared by all gradient-fraction sources of that culture. Both WT strains (MRG03, MRG06) are written `wild type`, so WT runs 1–11.
9. **Organism** `Escherichia coli BW25113` (NCBITaxon:679895): the paper names BW25113 as the parental strain. organism part / cell type / disease = `not applicable` (whole bacterial cultures).
10. **Cleavage agent** Trypsin (MS:1001251) per rule 2; all searches used Trypsin/P. The paper does not name the protease ("digested out of the gel as described", Chan et al. 2006).
