### Clinical values
All clinical values come from individual-level Table S1A rows only (rule 18).
- **age:** `Age at treatment`, floored to whole years (e.g. 44.24 → `44Y`).
- **sex:** from `gender`.
- **organism part:** `Biopsy site` mapped to UBERON. SC is `hypodermis`; its UBERON synonym is "subcutaneous tissue".
- **genotype:** BRAF status.
- **treatment response:** the response to the patient's immunotherapy, as NCIT terms.
- **treatment status:**
  - pre-treatment when the S1A sampling-day cell is empty;
  - on treatment for the 8 samples with a day count;
  - `not available` for the 4 "NA" cells.
  - PRIDE's "except for 12 samples" matches the 12 numeric cells in the full table.
- **treatment:** S1A "Immunotherapy group" as NCIT terms, verified live in OLS: TIL → Tumor Infiltrating Lymphocyte Therapy (NCIT:C15524), a-PD1 → PD1 Inhibitor (NCIT:C124946), a-CTLA4 → Anti-CTLA-4 Monoclonal Antibody (NCIT:C128036). That gives 44, 6 and 20 patients. This is the therapy whose response is recorded; most samples were taken before it started.
  - **Confounding:** therapy group coincides with technical set, preparation batch and acquisition period. TIL25/TIL33 are set 1 (2014, QE Plus); TIL45–86 are set 2 (2017, QE HF and QE Plus); PD samples ran 2016–17 on the QE HF (PD58 in 2018 on the QE Plus); CTLA samples are set 3 (2018, QE Plus).
- **survival and follow-up:** S1A gives one overall-survival value (months, rounded to 0.01) plus `Death`. They are split as follows:
  - Death = Y: the value goes in `survival time` (e.g. `88.7 month`), and `last follow up` is `not applicable`.
  - Death = N: the value is censored. It goes in `last follow up`, and `survival time` is `not applicable`.
  - OS or Death NA (TIL25 and TIL33 have no OS): both are `not available`.
  - Clinical data also states the vital status.
- **biopsy site:** S1A "Biopsy site", with the same UBERON mapping as organism part (oncology-metadata column).
- **Free text:** S1A "NA" inside the free-text clinical columns is written as `not available`.
- **developmental stage:** adult (all annotated patients are at least 20 years old).
- **clinical data:** free text holding the immunotherapy group, LDH, overall survival, death, technical set and the low-quality flag.
- **clinical history:** prior MAPKi drug and the initial response to it.
- **individual:** the S1A id. PD58 is written `PD49PD58`, the S1B column name, because `PD49/58` fails the validator pattern.

### Super-SILAC reference (rule 18)

- pooled sample `pooled`
- material type `cell line`
- disease `melanoma` (MONDO:0005105)

The names come from Harel et al. 2019, the protocol that PRIDE cites. PRIDE's text for this deposit only says "five SILAC-labeled melanoma cell lines".

### Factor values
There are four factor columns:
- `treatment` (therapy group). Response is meaningful only within a therapy; this was added in round 2 after the reviewer's important finding.
- `organism part` (metastatic site, the "organ specificity" in the title).
- `genotype` (BRAF status).
- `treatment response` (immunotherapy response).

The abstract names site, BRAF status and immunotherapy response. Biological replicates restart per (treatment, site, genotype, response) group. Heavy rows carry `not applicable`.

### Tolerances

### Cleavage agents
- The first column is Trypsin on all rows. MaxQuant searched with the Trypsin/P rule (rule 2).
- The second column is Lys-C for technical sets 2–3. The PRIDE protocol uses "Lys-C-Trypsin mix ... and trypsin" with SCX fractionation. This is assigned per technical set. For the unfractionated single-shot runs of sets 2–3 (TIL68, TIL69, TIL71, TIL74, TIL79, CTLA20), nothing run-specific confirms the digest; Lys-C rests on the technical set alone.
- TIL25 and TIL33 (technical set 1, acquired 2014-04-29) carry `not applicable` in the Lys-C column. Harel 2019's TIL-cohort protocol is FASP with "sequencing grade trypsin" and "six fractions using SAX". TIL33 has exactly 6 runs named by SAX pH (3, 4, 5, 6, 8, 11).

### Fractionation
- SCX for SCX runs.
- SAX for TIL33.
- `not available` for single 240-min runs (TIL25, TIL68/69/71/74/79, CTLA20). These runs show no fractionation, but none is stated either.

TIL68/69/71/74/79 each have two identical 240-min single-shot runs. MaxQuant labelled them "fraction 1" and "fraction 2"; I annotated them as fraction 1, technical replicates 1 and 2.
