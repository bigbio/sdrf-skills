## Key decisions with evidence
- **Spheroids are HCT116, not HeLa.** Methods: *"HCT116 cells were seeded … multicellular spheroid
  generation … treated for 24 h with 2 µM 5-FU (IC50) … disaggregated … sorted using cellenONE."*
  The bundle is named `HeLa_spheroids_datasets.zip`, which is misleading — precedence (paper Methods
  > PRIDE/filenames) puts HCT116 (colon carcinoma) on the spheroid rows. Cellosaurus HCT 116 =
  CVCL_0291, colon carcinoma, colon, donor male 48Y.
- **HeLa = parental HeLa** (CVCL_0030), DMEM + 10% FBS; no clone/S3 stated → CVCL_0030 / EFO:0001185,
  cervical adenocarcinoma, uterine cervix, donor female 30Y6M, African American (HANCESTRO:0568).
  (30Y6M is Cellosaurus's compound age and validates.)
- **No carbamidomethyl / no alkylation.** Methods: *"cysteine carbamidomethylation was not included as
  a modification."* Only variable **Oxidation (M, UNIMOD:35)** and **protein N-term Acetyl
  (UNIMOD:1)** are annotated — the reflex Carbamidomethyl(C) would be wrong on every row here.
- **Two enzymes:** master mix contains **trypsin + Lys-C** → two `cleavage agent details`
  (MS:1001251, MS:1001309).
- **Instrument Orbitrap Astral** (MS:1003378) — PRIDE and paper agree.
- **Dissociation HCD** = beam-type CID (MS:1000422); NCE 27% (nDIA Evosep methods).
- **Isolation window width** populated from the nDIA method embedded in each filename (2/4/8/16 Th) —
  raw-grounded, not left `not available`. Scan range 380–980 m/z from Methods.
- **Multi-cell pools (10/20/40 cells):** classified `sample type = pooled`, `cells per well =
  10/20/40`, `cell identifier = not applicable` (they are not single cells) — matching the
  reviewer-accepted convention in sibling PXD049181. These are cellenONE-sorted N-cell samples
  (real cells, an input-titration benchmark), not diluted standards.
- **Biological replicate** enumerates distinct biological samples **within each group that shares all
  characteristics** (56 HeLa single cells 1–56; each pool group 1–12; each spheroid arm 1–48). nDIA
  window is a technical comment, so it does not split the single-cell group.

## Judgement calls a reviewer should attack hardest
1. **`sample type = pooled` for the 10/20/40-cell samples.** Alternative readings: `study sample`
   with a separate pooled flag, or `standard`. I followed sibling PXD049181's accepted convention.
2. **Single factor = `factor value[treatment]`.** This dataset mixes a technical benchmark (HeLa
   cell-count / nDIA-window titration, no biological factor) with one biological perturbation (HCT116
   ± 5-FU). Consequently 140/188 factor values are `not applicable`; only the 48 5-FU-treated
   spheroid rows carry an explicit value (the 48 control spheroids and 92 benchmark rows are
   `not applicable`). An alternative would be `factor value[cell line]` or emitting two SDRFs.
3. **HCT116 `cell type` = epithelial cell** — inferred, not stated in Cellosaurus.
4. **HeLa disease MONDO:0005153 (cervical adenocarcinoma)** vs Cellosaurus's more specific
   "HPV-related cervical adenocarcinoma" (no MONDO term for the HPV-qualified form).
5. **Phospho and DIA-NN are secondary re-analyses of the same raws**, not separate runs; modification
   columns reflect the primary directDIA search (Ox+Ac). Phospho(STY) is therefore not annotated.
