## Study & publication
- **Title:** Single-Cell Proteomic and Transcriptomic Characterization of Drug-Resistant Prostate Cancer Cells.
- **Paper:** Mol Cell Proteomics 2025, PMID 40090465, PMC12008537, DOI 10.1016/j.mcpro.2025.100949 (open access; full text read).
- **Design:** Label-free single-cell proteomics (SCP) by high-throughput DIA (60 samples/day) on an Evosep-coupled **Orbitrap Ascend with FAIMS (CV −55 V)**. 144 single cells were analyzed: **72 parental PC3** ("CONT") vs **72 cisplatin-induced drug-resistant cells / DRC** ("PACC"). Cells isolated with **cellenONE** into a 384-well plate; on-plate lysis + trypsin/LysC digestion. Data searched with DIA-NN 1.8.0 against a FragPipe spectral library.

### Why the 54 NCI-7 dilution runs are excluded (legitimate per brief)
They are a **CPTAC NCI-7 reference standard** — a defined *mixture of seven distinct cell lines* — run as a benchmarking dilution series (400 ng → 0.12 ng), not biological samples of the study. Under the declared **cell-lines** template, `characteristics[cell line]` is **required and forbids both reserved words** (allow_not_available = allow_not_applicable = false; the #35 B1 trap). A 7-line mixture cannot receive a single valid cell-line value, so these runs meet the brief's *sole* legitimate exclusion criterion. They also sit on a different instrument (timsTOF HT / Ascend 100 SPD) from the single-cell measurements.

## Key decisions with evidence
- **organism part = `bone tissue` (UBERON:0002481), NOT prostate.** PC-3 (Cellosaurus CVCL_0035) was *"Derived from site: Metastatic; Bone; UBERON=UBERON_0002481"* — the cell line is from a bone metastasis of a prostate adenocarcinoma. The tumour of origin is captured separately in `disease = prostate adenocarcinoma (MONDO:0005082)`. Classic site-vs-tumour trap.
- **No Carbamidomethyl on the single cells.** The on-plate SCP prep uses 5 mM TCEP (reduction) but **no alkylation step** (Methods). Single-cell `modification parameters = not applicable`, `alkylation reagent = not applicable`. The **bulk** library prep *does* alkylate (20 mM IAA) → bulk rows carry `Carbamidomethyl;UNIMOD:4;TA=C;Fixed` and `alkylation reagent = Iodoacetamide`. This directly follows the brief's "never assert Carbamidomethyl without an alkylation step" rule and resolves PRIDE's misleading `modifications = "No PTMs"`.
- **Donor demographics from Cellosaurus CVCL_0035**, applied to all PC-3-derived rows: `age = 62Y`, `sex = male`, `ancestry = European ancestry (HANCESTRO:0005)` (Cellosaurus "Population: Caucasian"), `developmental stage = adult (EFO:0001272)`.
- **Instrument = Orbitrap Ascend (MS:1003356)** for every annotated row — single cells and the spectral library were both acquired on the FAIMS-Ascend at 60 SPD (Methods). timsTOF HT appears in PRIDE `instruments` but was used *only* for the excluded NCI-7 benchmark.
- **cisplatin = NCIT:C376** (verified by *exact* OLS query). Smart-mode returned the wrong single hit `Cisplatin Liposomal (NCIT:C2502)` — the documented smart-mode trap; corrected.
- **Acquisition numerics from Methods:** scan window 380–780 m/z, 25 m/z isolation window (16 scan events) for the 60-SPD single-cell/library method.
- **Search tolerances = 10 ppm / 10 ppm** (DIA-NN MS1 & MS2 accuracy, data-processing protocol) on the single cells; `not available` for bulk (FragPipe library-build params not deposited).
- **cleavage agents:** two `comment[cleavage agent details]` columns, Trypsin (MS:1001251) + Lys-C (MS:1001309) — the deposited protocol uses a trypsin/LysC mixture.
- **Experimental factor:** `factor value[treatment]` = cisplatin (DRC) vs not applicable (parental). The biological contrast is drug-resistance status, induced by 6 µM cisplatin (72 h) then 10-day recovery per Methods.

Every ontology accession above (NCBITaxon, UBERON, CL, MONDO, EFO, HANCESTRO, MS, UNIMOD, NCIT, PRIDE) was verified live via OLS in this run.

## Values deliberately left not available / not applicable
- **Single cells:** `modification parameters`, `alkylation reagent` = *not applicable* (no alkylation, no variable mods stated). `sample type` = single cell; isolation/cells-per-well filled.
- **Bulk library rows:** `sample type` = *not available* (live OLS `getChildren(PRIDE:0000895)` returns no clean "bulk / study-sample" child term to cite; the material is genuinely a bulk cell-line lysate). `single cell isolation protocol`, `cell identifier`, `cells per well` = *not applicable* (bulk, not single cells). `precursor/fragment mass tolerance` = *not available* (FragPipe params not deposited).
- **`dia method`** = *not available* for all rows (recommended; no specific DIA-scheme PRIDE term asserted — the scheme is fixed-window, non-overlapping 25 m/z, but I did not invent a CV term).
- **`cell diameter`** column omitted: per-cell diameters were captured by cellenONE but are not in any deposited table here; parental were gated 22–25 µm and DRCs up to ~102 µm, but exact per-cell values are unavailable, so the optional column is left out rather than guessed.

## Conflicts found and how resolved
- **PRIDE `modifications = "No PTMs are included in the dataset"`** contradicts the deposited bulk protocol (IAA alkylation ⇒ Carbamidomethyl). Resolved from Methods/raw-prep logic: CAM on bulk only, none on single cells.
- **PRIDE `instruments` lists both Orbitrap Ascend and timsTOF HT.** Resolved via Methods + file names: single-cell + library = Ascend; timsTOF only for the excluded NCI-7 dilution benchmark.

## Judgement calls a reviewer should attack hardest
1. **Including the 6 bulk library runs** in the same SDRF as the single cells (they are library-generation, not quantitative study runs). They are deposited PC-3 samples and not excludable by the brief's cell-line rule, so I included them; a reviewer may argue they belong out of scope.
2. **`sample type = not available` for bulk rows** — no live-confirmed PRIDE child term for a bulk cell-line lysate; is "not available" the right reserved word vs leaving/omitting?
3. **`CONT`→parental / `PACC`→DRC** token interpretation (inferred, not spelled out verbatim in the file names).
4. **organism part = bone tissue** rather than prostate — correct per Cellosaurus derived-site, but reviewers often expect the tumour site.
5. **cell type = epithelial cell (CL:0000066)** — PC-3 is poorly differentiated with reported neuroendocrine/small-cell features; a more specific term was deliberately avoided.
6. **`developmental stage = adult` applied to a cell line** from donor age — acceptable cohort-level inference, but it is a donor property, not a cell-culture property.
