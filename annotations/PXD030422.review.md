## What was checked independently

- **Cohort join.** All 122 light rows were checked against the deposited individual-level `Cohort_file_IDs.txt`, joined on the raw-file number. The script compared source name, individual, sex, age, grade, cTNM, pCR/non-pCR and the clinical-data string. It found 0 mismatches. Every Non-pCR patient has ypT>=1 or ypN>=1, so `Residual Disease` (NCIT:C4809) is justified.
- **Super-SILAC heavy channel.** It is treated as a reference: `sample type = reference`, a pooled cell-line source, and `factor value = not applicable`. These rows carry no patient clinical values. Cellosaurus confirms the five pool lines are human colorectal adenocarcinoma lines from donors of both sexes (3 male, 2 female).
- **Files.** The 122 deposited `.raw` files match `comment[data file]` 1:1, with 2 rows (light and heavy) per file.
- **MaxQuant name conflict.** For 7 runs, the MaxQuant "Experiment" names disagree with the file names. In each case the Xcalibur acquisition path inside the raw header equals the deposited file name. The MaxQuant names also collide: four names are each assigned to two files. The file name is therefore the reliable key.
- **Technical values.** These were confirmed from raw headers on 4 runs, from MaxQuant `parameters.txt` and `summary.txt`, and from the PRIDE protocol. They are the instrument split (12 Q Exactive HF runs, 110 Orbitrap Fusion runs), MS2 analyser, NCE 28/35, tolerances, modifications and SILAC labels.
- **Ontology.** All controlled terms resolve in OLS4, with exact labels and none obsolete.
- **Templates.** The union of ms-proteomics 1.2.0, human 1.1.0, clinical-metadata 1.0.0 and oncology-metadata 1.0.0 was resolved against upstream templates 7da1747. No required or recommended columns are missing and no columns are unlicensed.
- **Deterministic checks.**
  - `parse_sdrf validate-sdrf` exits 0 with warnings only.
  - `sdrf-tools check` reports CLEAN. `sdrf-tools score` gives 96/100. `sdrf-tools structure` reports OK.
  - `convert-openms` succeeds.
  - `reconcile` exits 1 on an organism BLOCKER. This is a verified false positive: it keys on the word "murine" in the project description, which describes the paper's mouse arm. PRIDE organisms lists only Homo sapiens, and the search used a human FASTA.

## Findings (all minor)

1. `characteristics[treatment status]` = `pre-treatment` is an inference, not a stated fact. It is forced for the 32 ypT0pN0 patients and is disclosed in the manifest. Keep it, or cite the paper's Methods if the full text becomes available.
2. `characteristics[pooled sample]` uses `SN=` with cell-line names. The spec defines SN= as a list of source names. Curated precedent PXD001370 uses the same form, so it is accepted.
3. `characteristics[tumor stage]` is `not available` on rows where only one TNM component is n.a. The individual components are kept in `clinical data`.
4. `comment[sample preparation batch]` is not filled. The file-name prefixes (231115, 171215, 070316) mark batches. Patient 22's third run comes from a later preparation, yet it is encoded as technical replicate 3.
5. The optional `characteristics[developmental stage]` column is omitted.
