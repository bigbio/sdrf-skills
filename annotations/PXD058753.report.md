## Annotatability
**Pulsed SILAC in single cells** (SC‑pSILAC): within one cell/run the *light* channel is pre‑existing
protein and the *heavy* channel is newly synthesised protein — an intra‑cell pulse readout, **not** isobaric
multiplexing. **1 raw file = 1 biological sample**, so no channel→sample map is required and the dataset is
fully annotatable one row per raw file. The heavy label is encoded as **variable** `comment[modification
parameters]` (Lys8 + Arg10) with `comment[label] = SILAC`, exactly as in the sibling PXD051942.

## Key decisions and evidence
- **SILAC labels (stated, not guessed):** heavy medium = L‑lysine‑¹³C₆¹⁵N₂ (Lys8) + L‑arginine‑¹³C₆¹⁵N₄
  (Arg10) (PRIDE `data_processing_protocol`: *"channel2 with Lys8 and Arg10"*; preprint Methods identical).
  Encoded as variable mods `NT=Label:13C(6)15N(2);AC=UNIMOD:259;TA=K;MT=Variable` and
  `NT=Label:13C(6)15N(4);AC=UNIMOD:267;TA=R;MT=Variable` (UNIMOD:259/267 verified live via OLS).
  `comment[label] = SILAC` (PRIDE:0000315), one value per run.
- **No Carbamidomethyl / no alkylation:** PRIDE protocol states *"carbamidomethylation was not included in the
  fixed modifications"*; lysis/digest buffer is 0.2% DDM + 100 mM TEAB + LysC + trypsin with **no
  reduction/alkylation step**. The reflex Carbamidomethyl annotation was deliberately omitted (would be wrong
  on every row). No `comment[reduction reagent]`/`[alkylation reagent]` columns added.
- **Other search mods:** Spectronaut directDIA+ default variable mods Oxidation (M, UNIMOD:35) and Acetyl
  (Protein N‑term, UNIMOD:1). UNIMOD:1 (Acetyl) ≠ UNIMOD:21 (Phospho) — verified; positional value in `PP=`,
  not `TA=`.
- **Enzymes:** dual lysyl endopeptidase + trypsin → two `comment[cleavage agent details]`:
  `NT=Trypsin;AC=MS:1001251`, `NT=Lys-C;AC=MS:1001309`.
- **Instrument / acquisition (PRIDE protocol, corroborated by preprint):** Orbitrap Astral (MS:1003378),
  Evosep One 40 SPD (31‑min gradient), full MS 240k res, **380–980 m/z**, MS/MS **4 Th** isolation window,
  6 ms max IT, **HCD 27% NCE**. → `Data-independent acquisition` (plain string required by dia‑acquisition),
  dissociation `NT=beam-type collision-induced dissociation;AC=MS:1000422`, `27 NCE`,
  scan window 380/980, isolation window width 4.
- **hFF identity — the foreskin/sex call (the point to attack hardest):** the preprint Methods state, for
  these exact ATCC cells, *"human foreskin fibroblasts (hFF)"* and *"a homogeneous human foreskin (hFF) cell
  line"* (`HeLa, HEK 293T and hFF cells (ATCC)`). Because foreskin origin is **explicitly stated in the
  paper** (not inferred from the "hFF" token alone), I set `organism part = prepuce of penis`
  (UBERON:0001332) and `sex = male`, matching the review‑**passed** PXD051942 and **avoiding** the PXD054066
  overreach (which asserted the same anatomy from a token the manuscript never defined and failed review).
  `cell type = fibroblast` (CL:0000057). `disease = normal` (PATO:0000461) — healthy primary/finite line.
- **Cell‑line vs primary:** the paper calls hFF a "cell line" but gives **no ATCC catalog number**, so no
  Cellosaurus CVCL can be verified. I followed the sibling PXD051942 precedent: `cell-lines` template with
  `cell line = hFF` (free text) and `cellosaurus accession/name = not available` (the resolved cell‑lines
  template makes `cellosaurus accession` **required but `allow_not_available = true`**, so this is legal).
  The #35 B1 reserved‑word trap does **not** fire: every row is hFF, so `characteristics[cell line]` carries
  the real value `hFF` on all 384 rows — no reserved word under a file‑wide cell‑lines declaration.
- **Isolation / counts:** cells were **cellenONE / Cellenion proteoCHIP‑sorted** (PRIDE protocol: *"sorted
  into … proteoCHIPs (Cellenion)"*), so `single cell isolation protocol = cellenONE` — **not FACS** (the
  screen hint's "FACS‑isolated" was checked against the Methods and rejected). 1‑cell runs →
  `sample type = single cell` (PRIDE:0000897), `cells per well = 1`, `cell identifier = <source name>`.
  10‑cell pools → `sample type = pooled` (PRIDE:0000902), `cells per well = 10`,
  `cell identifier = not applicable` (a pool has no single‑cell identity; `allow_not_applicable = true`).
- **Proliferation state = experimental factor:** `characteristics[treatment]` and `factor value[treatment]`
  carry the growth state (`proliferating` / `confluent` / `serum-starved`) — the variable that separates
  dividing from non‑dividing cells.

## Values left as reserved words — and why
- `characteristics[age] = not available` (all rows): donor age of the hFF line is not reported and is not a
  per‑single‑cell property. `age` forbids `not applicable` (resolved human template `allow_not_applicable =
  false`), so `not available` is the only legal reserved word.
- `characteristics[cellosaurus accession] = not available`, `characteristics[cellosaurus name] = not
  available` (all rows): no ATCC catalog number is given, so the specific Cellosaurus line cannot be resolved.
- `characteristics[cell identifier] = not applicable` (12 pooled rows): a 10‑cell pool has no single‑cell
  identity.

## Points a reviewer should attack hardest
1. **Use of `cell-lines` for hFF.** The task brief cautions against `cell-lines` for a *primary* fibroblast.
   hFF foreskin fibroblasts from ATCC without a catalog number are plausibly primary/finite, but the paper
   calls them a "cell line" and the identical cells were annotated with `cell-lines` in the review‑passed
   PXD051942. Alternative: drop `cell-lines`, carry identity via `cell type = fibroblast` + organism part +
   sex only (as PXD054066 ultimately did). I chose repo/sibling consistency.
2. **`organism part = prepuce of penis` + `sex = male`.** Paper‑backed (preprint states foreskin for these
   exact ATCC cells), but the foreskin statement lives in the *bulk* hFF control description; the single‑cell
   Div/conf/starved Methods paragraph (Cell 2025) was not machine‑readable. If those single cells came from a
   different fibroblast source, anatomy/sex would be wrong.
3. **`treatment` as the home for growth state** (proliferating/confluent/serum‑starved) — a free‑text,
   NCIT/EFO‑absent value. A reviewer may prefer `characteristics[cell cycle phase]` (single‑cell template) or
   leaving it out; I judged treatment the most faithful available column and cell‑cycle‑phase inappropriate
   (no per‑cell phase data).
4. **10‑cell pools as `pooled` (PRIDE:0000902)** vs the sibling's `bulk control` — I chose the literal
   "pool of sorted cells" reading; count preserved in `cells per well = 10`.
5. **`disease = normal`** (PATO:0000461) vs the sibling's `not applicable` for hFF.
