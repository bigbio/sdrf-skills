## Design and channel maps
- **silac-dilution (Benchmark1).** HCT116 cells were grown in light or heavy SILAC (Lys8/Arg10) DMEM. The heavy lysate was diluted 1:1, 1:3 … 1:2047 into the light lysate. There are 11 mixtures × 3 injections (technical replicates 1–3).
  - Light channel: the reference, one source per mixture (aliquots of one light lysate).
  - Heavy channel: the diluted target, `factor value[mixing ratio]`.
  - Source of the map: Methods ("heavy labeled cell lysate was sequentially diluted into the light"; "all the SILAC lights as references").
  - Data check: median log2(H/L) per run is −0.04 at 1:1, −1.33 at 1:3, −2.37 at 1:7 and −3.08 at 1:15, then plateaus near −3.5 (the paper reports this ratio compression).
- **spied.** In every run the SILAC heavy channel is the JPT SpikeMix synthetic heavy phosphopeptide pool, encoded as a shared reference: sample type reference, material synthetic, pooled, one source name per physical aliquot (manifest says they are aliquots of one pool). It is spiked at 200 fmol per 100 µg sample, or 50 fmol in Benchmark2. The light channel is the study sample.
  - **Cell-line panel (35 runs).** Caco-2 (C), HCT116 (H) and DLD-1 (D), samples 1–12:
    - 1–3: DMSO + BSA (untreated / untreated)
    - 4–6: selumetinib + BSA
    - 7–9: DMSO + GF mix (EGF, HGF, FGF2, VEGF-C)
    - 10–12: selumetinib + GF mix
    - Biological replicates 1–3 within each group. DLD-1 D7 was not deposited.
    - Source of the map: the authors' code on Zenodo (global normalisation script and limma designs).
    - Conflict: one unused label block in `CellLinePanel_TargetedAnalysis.R` swaps 4–6 and 7–9. The ERK1 pY204 / ERK2 pY187 data in Supplementary Data 8–10 confirm the limma/global mapping, so I used it.
  - **HCT116 individual growth factors, MEKi arm (15 runs).** Selumetinib + BSA / EGF / FGF2 / HGF / VEGF-C, replicates 1–3. The BSA group is numbered 4–6 so it stays distinct from the panel's HCT116 selumetinib + BSA cultures.
    - Suppl. Fig. 15 documents these 5 conditions × 3 replicates.
    - The design (AZD6244 + BSA/EGF/HGF/FGF2/VEGF-C only) is also shown in the Zenodo README image `HCT116_indGFs.jpg`.
    - The ligand letter for each file comes from its initial; this is an inference. JNK1 pY185 does not separate HGF from BSA or BSA from VEGF-C, so there is no data check per ligand.
    - MEKi status is checked against ERK2 pY187 in the deposited SPIED matrix.
  - **Benchmark2 (9 DIA runs, all in the JPTlib_SILAC search):**
    - HEK293 with spike-in (well E4)
    - HEK293 without spike-in (well E3; heavy channel unused)
    - Peptide pool only (well C9; light channel unused)
    - Each sample was injected 3 times from the same well, so I encoded them as technical replicates. The Fig. 1G legend says "biological replicates" (this conflict is recorded).

- **benchmark3 (Rev_Benchmark3, 18 runs).** Targeted dilution series. Each run has:
  - a HEK293 light row with `characteristics[mass]` 25–400 ng (none in the 0 ng runs; that amount is also `factor value[mass]`)
  - an E. coli background light row (100 ng, sample type negative control) in its own row, per SAMPLE-GUIDELINES.adoc:424
  - a JPT heavy spike row (50 fmol)
  - Source: paper Results and the Fig. 1H legend, plus the Zenodo README and `Analysis_BM3.R`. Amounts come from the run names. The three runs per amount sit in separate wells of one HEK293 lysate, so each is its own source with biological replicate 1.

## Technical values (DIA-NN logs, raw metadata and Methods)
- Instrument: timsTOF Pro 2 (MS:1003230) for silac-dilution and spied, and timsTOF HT (MS:1003404) for benchmark3.
  - Source: the analysis.tdf GlobalMetadata of each series. The serial number is the same, so this is the same instrument. The paper says Pro2 throughout; the conflict is recorded.
  - Benchmark3 isolation window: 26 m/z (diaSettings.diasqlite).
- DIA (dia-PASEF), CID, TOF analyser, IM 0.6–1.6, m/z 400–1201.
- Digest: Lys-C then trypsin (two cleavage columns). Reduction DTT, alkylation IAA.
- Modifications: Carbamidomethyl C fixed. Variable: Oxidation M, Acetyl protein N-term, Phospho STY, Lys8 (UNIMOD:259), Arg10 (UNIMOD:267).
- Fragment tolerance is the DIA-NN "Optimised mass accuracy" of each search:
  - Benchmark1: 15.4157 ppm
  - Benchmark2: 8.83098 ppm
  - Panel: 9.34972 ppm
  - GFs: 5.22028 ppm
  - benchmark3: 12.8404 ppm
- Precursor tolerance is `not available`: DIA-NN auto-optimised it and did not log the applied value. The "Using MS1 mass accuracy: 20 ppm" line in the HCT116GFs log is the calibration fallback of the first optimisation pass (it follows "Cannot perform MS1 mass calibration"), not the search setting.
- Storage temperature is -80 °C for HCT116, Caco-2 and DLD-1 (Methods), `not available` for HEK293 and `not applicable` for spike rows. Passage number is `not available` for cell rows and `not applicable` for spike rows.
