## Findings

1. **[minor] semantics** at characteristics[treatment] / factor value[treatment] rows 17-24, 53-58 (lane C heavy) vs rows 33-40, 65-70 (lane D heavy)
   - 'untreated' means two different things in one file. In lane C it means 'no HGF', although those cells were biotinylated, warmed to 37 C and MesNa surface-reduced (Methods: 'Biotin remaining at the cell surface was removed by surface reduction as above'). In lane D it means 'not MesNa-reduced'. The lane C +HGF rows likewise omit that their cells were MesNa-reduced too.
   - Evidence: PMC8613289 Methods (nuclear-capture paragraph); manifest limitation 8 discloses this. The rows stay distinguishable because the sampling time differs (30 minute vs not applicable), and the template prescribes 'untreated' for controls.
   - Fix: Optional: use 'vehicle control' (SAMPLE-GUIDELINES example) or another value that names the HGF contrast for lane C heavy, or add a second treatment-type column so MesNa reduction is recorded on every reduced arm.

2. **[minor] provenance** at evidence manifest, claims for comment[label] and characteristics[treatment] (lane C)
   - The manifest does not disclose that the main-text Results ('SILAC-labelled with medium (M) or light (L) amino acids ... presence or absence of HGF') and the Methods analysis sentence ('ratios between light-isotope and medium-isotope peptides') name M/L, not L/H, as the +/-HGF pair. It also does not cite the strongest evidence that resolves this.
   - Evidence: PMC8613289 Results paragraph 1 and Methods 'Analysis of MS data'. My exact match of the Supp Data 1 'Nuc HGF/Nuc Ctl' columns to deposited -log2(H/L) (1220/1220, 1494/1494) shows that the published HGF/Ctl ratio is L/H, so the SDRF map is correct.
   - Fix: Add a limitation noting the Results/Methods M-vs-L wording, and add the exact column-to-channel reproduction as evidence in the label and treatment claims.

3. **[minor] consistency** at characteristics[sampling time] rows 9-16, 47-52 ('0 minute') vs rows 25-40, 59-70 ('not applicable')
   - Lane C's no-internalisation arm and the surface arms both skipped the 37 C internalisation step, but one is encoded '0 minute' and the other 'not applicable'. The '0 minute' value is inferred from the 'No int' header and is marked INFERRED.
   - Evidence: Supp Data 1 header 'No int nuclear'; Methods surface protocol (4 C only).
   - Fix: Optional: use the same encoding for both no-internalisation states, either '0 minute' everywhere or 'not applicable' for the M arm with the label kept in the source name.

4. **[minor] completeness** at file (columns)
   - The recommended cell-lines/human columns characteristics[passage number], characteristics[sample storage temperature] and characteristics[individual] are absent.
   - Evidence: cell-lines 1.1.0 and human 1.1.0 mark these columns 'recommended'. The paper states neither passage nor storage temperature.
   - Fix: Optional: add these columns with 'not available'. For individual, use a single donor identifier or 'not available'.

5. **[minor] documentation** at annotations/BLOCKED.md line 1-11 preamble vs line 1016 entry
   - BLOCKED.md's preamble says it lists 'genuine MS-based single-cell proteomics' datasets. PXD027268 is a bulk SILAC dataset, so the PXD027268 entry sits under a header that does not describe it.
   - Evidence: BLOCKED.md line 1 heading and intro paragraph.
   - Fix: Optional: broaden the preamble, or add a sub-heading for non-single-cell partial blocks.

6. **[minor] technical** at comment[cleavage agent details] all rows
   - The deposited search used Trypsin/P (MS:1001313), but the SDRF gives Trypsin (MS:1001251). This is defensible as the digestion enzyme and is disclosed in the manifest note.
   - Evidence: mqpar.xml <enzymes>Trypsin/P</enzymes>; Methods 'Trypsin gold'.
   - Fix: None required. Keep the manifest note.

No blocker or important findings.
