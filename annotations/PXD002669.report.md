## Study

Noberini R, Uggetti A, Pruneri G, Minucci S, Bonaldi T. *Pathology tissue-quantitative mass spectrometry analysis to profile histone post-translational modification patterns in patient samples*. Mol Cell Proteomics 2016;15:866. PMID 26463340, PMC4813706 (open access).

The study introduces PAT-H-MS, a method for extracting histones from FFPE tissue:
1. Lysines are derivatised in-gel with D6-acetic anhydride.
2. The gel bands are digested with trypsin. Because the lysines are blocked, trypsin cuts like Arg-C.
3. Samples are run on a Q Exactive in DDA mode and searched in MaxQuant 1.3.0.5.

Three experiments are deposited:
1. **Mouse, label-free**: FFPE vs frozen histone H3 and H4 from three sample sets:
   - spleen stored a few weeks, from an APL-transplanted recipient mouse (2 biological replicates);
   - liver stored a few weeks (2 technical replicates);
   - spleen stored 6 years (2 technical replicates).
2. **Human, super-SILAC**: FFPE vs frozen tumour portions from breast cancer biopsies 1–3, each run in technical triplicate.
3. **Human, super-SILAC**: 20 FFPE biopsies, 5 patients for each subtype (Luminal A-like, Luminal B-like, Triple Negative, HER2+).

In both human experiments, the heavy channel is an Arg10-labelled spike-in. It is a histone mix from four cell lines: MDA-MB-231, -468, -453 and -361.

## Conflicts found and resolution

1. `experimentalDesignBiopsies1-3me1me2ac.txt` labels the Sample10 *Frozen* runs as Biopsy3_FFPE and the *FFPE* runs as Biopsy3_frozen. The file names and the other two design files say the opposite. The data side with the file names. Light-only evidence counts per run:
   - Sample10_Frozen: 155–179, like the other frozen runs (75–126);
   - Sample10_FFPE: 386–409, like the other FFPE runs (429–545).

   The file names were followed.
2. PRIDE's quantificationMethods = SILAC is project-wide. The mouse arm is label-free (above).
3. Fragment tolerance: the paper says 6 ppm, parameters.txt says 20 ppm FTMS. The deposited value was used.
4. `sdrf-tools reconcile` exits 1 on all files. Each finding is refuted in validation.txt:
   - cleavage agent: Arg-C is the search rule, trypsin is the reagent (rule 2);
   - "liver run names vs spleen": a tool defect, since it reads only the first organism-part value;
   - "SILAC record vs label free": the mouse arm, see above.

## Limitations / open items

These are also in each manifest.
- techsdrf is not installed. The instrument was checked by HTTP range-reading 12 raw headers only.
- Arg-C search vs trypsin reagent: a reprocessing tool using an unrestricted trypsin rule will not reproduce the deposited search.
- The mods are a union over 3–4 parallel MaxQuant jobs, not one search.
- The NCIT subtype terms are gene-expression-profile classes; the paper used IHC surrogates ("-like").
- Mouse strain, sex and age are not reported. FFPE vs frozen pairing within one mouse is implied but not stated per file, so `individual` is omitted.
- The SN= pooled-sample warning comes from a values validator in the template that contradicts the template's own pattern validator.
- The paper says a formalin-adduct search was run "for the mouse samples", but no such job is deposited for the 6-year spleen.
