## The split into three files

**Judgement: sound.** The deposit contains three raw archives, and each SDRF maps to exactly one of them:
- `UHN_Lung_Tissue_IMPACT_Samples_Raw_Data.7z` holds 49 `.raw` files from Orbitrap Elite super-SILAC runs, 2015.
- `Brain-Metastasis-Library-Raw-Data.7z` holds 60 `.d` folders from timsTOF Pro DDA-PASEF runs of the high-pH library fractions.
- `Brain-Metastasis-Samples-Raw-DIA-Data.7z` holds 50 `.d` folders from timsTOF Pro diaPASEF runs, 2023.

Why the split holds:
- **LUAD vs BM.** The two arms are separate cohorts with different patients, instruments, labelling and sample preparation. The paper does not pair them; the paired LUAD–BM proteomics it uses is an external dataset (ref. 22).
- **Library vs DIA.** The `dia-acquisition` template allows only one value for the acquisition method, so the DDA library runs had to go in their own file.
- **PRIDE record.** The SILAC/diaPASEF quantification tags and the "Orbitrap Fusion Lumos" instrument are project-wide labels. A raw-header read confirms the LUAD arm was acquired on an Orbitrap Elite, so the `reconcile` disagreements in the validation output are correctly refuted.
