- **Channel maps.** Every (plex, channel) and SILAC light row was compared against the label key: 0 mismatches in source, individual, organism part, phenotype or genotype. Undocumented channels are blocked rather than filled: SWOG27 TMT131 and E2/E3 TMT131N/C, plus the SILAC AML1036 group.
- **Clinical values.** Age, sex, treatment response and clinical data appear only for the 30 Table S13 individuals, and they match S13 exactly in every arm. Developmental stage is set only from per-channel Age_Group. SILAC heavy rows are encoded as `reference` and carry no clinical values.
- **Raw ↔ search identity by scan count.** I read the Thermo RunHeader last-scan number from each deposited raw and compared it with MaxQuant MS+MS/MS. All 215 SILAC, 72 SWOG27 and 287 NPM1 searched raws match the entry with the same name.
  - The `AML1027_..._R2` runs differ from the searched non-R2 AML1027 runs, so they really were never searched (`not applicable` tolerances are correct).
  - NPM1 Gr08 F11 is missing from `summary.txt` and has no readable RunHeader, which agrees with the SDRF.
  - **New:** the six blocked `AML1036_Blast_BLD_2D_F01-F06` raws match `AML1089_Blast_BLD_2D_F01-F06` of the SILAC search exactly (56695, 55013, 53042, 50719, 53105, 22785).
  - `AML1019_Blast_BM_2D_F06` has MS = 0 in the search, and its RunHeader reports only 293 scans.
- **Search parameters.** Checked against MaxQuant `parameters`/`summary` (versions 1.5.3.30, 1.6.0.16 and 1.6.10.43) and the PD WorkflowXML (10 ppm / 0.6 Da; protein N-terminal Acetyl / Met-loss / Met-loss+Acetyl).

## Blocking finding (SILAC file)

**IMPORTANT — `comment[precursor mass tolerance]` = 20 ppm on the 432 searched SILAC rows has no source.** The SILAC search is MaxQuant 1.5.3.30 (`AML_SWOG_1st` `parameters.txt`, 07/11/2016), and that file records no precursor tolerance. The cited sentence "Peptide MH+ mass tolerances were set at 20 ppm" (PRIDE dataProcessingProtocol / Supplemental Methods) describes the discovery-cohort searches "using MaxQuant ... 1.6.0.1 or ... 1.6.10.43", which are the TMT searches. The publication never describes the SILAC arm, and 20 ppm may in any case be MaxQuant's first-search value.

**Fix:** set `not available` on those 432 rows and update the manifest claim, unless an AML_SWOG_1st-specific source (e.g. mqpar.xml) states the value.
