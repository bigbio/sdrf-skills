## Key decisions and evidence
- **Instrument per file from raw headers**: 42 files Q Exactive HF (MS:1002523); LuA4N/T, LuA5N/T, TN3N/T are
  **Q Exactive** (MS:1001911; 150-min method, NCE 25, 70k/17.5k resolution). Paper says only Q Exactive HF; PRIDE says
  Q Exactive. Collision energy per file: 28 NCE (HF) / 25 NCE (QE).
- **Modifications from the deposited searches** (two parallel MaxQuant 1.5.2.8 jobs per file): Acetyl (UNIMOD:1),
  D3 = Acetyl:2H(3) (UNIMOD:56, +45.0294, the D6-acetic-anhydride derivatization), M-d3 = Methyl+Acetyl:2H(3)
  (UNIMOD:768, +59.0454), Dimethyl (UNIMOD:36), Trimethyl (UNIMOD:37; named "Tri (K)" in breast, "Trimethyl (K)" in
  OC/HNC), Arg10 = Label:13C(6)15N(4) (UNIMOD:267, MT=Variable per batch rule 11), all TA=K except the label (TA=R).
  Masses checked against Unimod and paper 3.9. **Carbamidomethyl (C) Fixed only on OV/HNC rows** (txtOCHNC
  parameters.txt), `not applicable` on breast rows (txtbreast parameters.txt "Fixed modifications" empty) — built as two
  groups with identical headers (rule 5). No propionylation here: this lab uses D6-acetic anhydride.
- **Cleavage agent** `NT=Trypsin;AC=MS:1001251;CS=(?<=R)(?!P)` (coordinator decision; precedent PXD003958): trypsin is the
  digestion enzyme, D6-acetylation blocks lysines so cleavage is Arg-C-like; all 4 MaxQuant searches use ArgC.
  reconcile against the live v3 record flags MAJOR `cleavage_agent_incomplete` (missing Arg-C): refuted, because Arg-C
  appears only as the search specificity and as the 'Arg-C-like' outcome, never as a digestion enzyme.
- **Tolerances**: precursor 6 ppm (paper/PRIDE prose; not in parameters.txt); fragment **20 ppm** from deposited
  parameters.txt (`MS/MS tol. (FTMS) 20 ppm`), overriding the paper's "6 ppm for … fragment ions".
