## Requested stress tests

- **Forward/reverse assignment of U1–U6.** Confirmed.
  - The PRIDE protocol gives the labelling: forward = shUSP9X in light (R0K0) and shGFP in heavy (R10K8); reverse is reciprocal. It does not say which experiment is which.
  - In MaxQuant, Labels0 is empty (light) and Labels1 is Arg10;Lys8 (heavy).
  - Reviewer-recomputed normalized H/L for the knockdown target USP9X (Q93008): U1 2.34, U2 4.86, U3 1.27, U4 0.42, U5 0.17, U6 0.75. For NFX1: 1.68, 2.73, 1.08, 0.60, 0.27, 0.86. GAPDH is 0.94–1.09.
  - H/L > 1 means less USP9X in light, so the knockdown is in light, which is the forward orientation. U1–U3 are therefore forward and U4–U6 reverse.
  - U3 and U6 are weak. They are settled by the log2 H/L correlation over 5026 proteins:

    | pair | correlation |
    |---|---|
    | U1–U4 | −0.80 |
    | U2–U5 | −0.89 |
    | U3–U6 | −0.85 |
    | off-pair (forward vs reverse) | −0.32 to −0.52 |
    | within forward | +0.43 to +0.56 |
    | within reverse | +0.35 to +0.54 |

  - Side finding: the data form three label-swap pairs (minor finding 2).
- **U1 fraction order (file name vs MaxQuant).** The file-name order is right, but for a different reason than the manifest gives.
  - The peptide-set Jaccard index of U1_1, U1_2 and U1_3 against U2 at the same fraction number is 0.46, 0.54 and 0.46. Every other fraction scores ≤ 0.18.
  - U2 follows file-name order in MaxQuant. MaxQuant's U1 reorder (U1_2→1, U1_3→2, U1_1→3) would break that alignment.
  - New observation: {U1,U2} and {U3–U6} are two fractionation batches offset by about two fractions. For example, U1_3 is closest to U3_5 (Jaccard 0.34), and U1_4 is closest to fraction 6 of U3–U6 (minor finding 1).
- **Blocked IP runs (header-name conflict).** The conflict is confirmed in all six raw headers:

  | deposited name | acquired name (raw header) |
  |---|---|
  | EV_Up / EV_Down | `20181216__HF_ZHW_Ludayun_293T_Over_NFX1_Ub_*` |
  | NFX1_1_Up / NFX1_1_Down | `..._Over_NFX1_*` |
  | NFX1_2_Up / NFX1_2_Down | `..._Over_EV_*` |

  All six are Q Exactive HF runs. The txt_IP MaxQuant experiments are EV, NFX1_1 and NFX1_2. In the IP proteinGroups, NFX1 is 0 / 1.93e9 / 1.53e8 and co-IP USP9X is 0 / 8.4e7 / 3.8e7. The deposited names therefore fit the data, and the acquired name "EV" does not, since that run contains both bait and prey. The block is still defensible, because:
  - the deposited "EV" run was acquired as "NFX1_Ub";
  - the abstract describes separate ubiquitination experiments;
  - the replicate status of NFX1_2 is unknown.

  BLOCKED.md should say that the deposited names are consistent with the data (minor finding 4).
- **Instrument (Q Exactive vs PRIDE LTQ Orbitrap).** The SILAC raw headers say "Q Exactive - Orbitrap MS" / "Method of Q Exactive". The method settings are MS1 at 70,000 over 300–1500 m/z, MS2 at 17,500, Top15, isolation 2.0 m/z, NCE 28 and dynamic exclusion 25 s. NCE is 28 even though the method name says NCE30. The SDRF values match. PRIDE's "LTQ Orbitrap" is correctly overridden.
- **Replicate numbering.** Biological replicates are numbered 1–6 per factor group, unique per mixture culture. This is consistent with rule 3 and with curated label-swap precedents: PXD000559 and PXD001769 number each swap experiment separately. The pair structure in the data should be recorded in the manifest (minor finding 2).

## Findings (all minor)

1. **Fraction batches.** The fraction identifiers follow the file names, but fraction k in U1/U2 corresponds to fraction k+2 in U3–U6. The manifest's U1 argument from MS/MS counts is weak.
   - *Fix:* cite the U1_k↔U2_k peptide overlap in the manifest and add the batch-offset caveat. Keep the values.
2. **Replicate pairing.** The anticorrelation is pair-specific (U1/U4, U2/U5, U3/U6), and the knockdown depth matches within each pair. The six numbers per condition probably overstate the number of independent knockdowns.
   - *Fix:* add a manifest limitation with these numbers. Keep 1–6 unless an author source says otherwise.
3. **`characteristics[sample type]` is missing.** It is recommended in base 1.1.0, with default `study sample`.
   - *Fix:* add it as `study sample` for all rows through the build tables.
4. **IP block wording.** BLOCKED.md says "data do not settle it". In fact the deposited names fit the NFX1 and USP9X intensities.
   - *Fix:* add the co-IP numbers. Note that the campaign owner could accept unblocking on the deposited names, with the conflict recorded; otherwise an author statement is needed.
5. **Trypsin refutation.** It can cite the C-terminal residue distribution (52% K, 47% R) as direct digest evidence.
