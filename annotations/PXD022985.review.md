## Focus 1: label-swap assignment (4NHF, RDEBD)

- Explicit source: the deposited `readme.txt` channel table. RDEB1 and 4NHF_1 are Light 10 min / Medium 0 min / Heavy 5 min. The other five samples are Light 0 / Medium 5 / Heavy 10.
- Deposited ratios (`proteinGroups.txt`, normalized, log2 M/L / H/L / H/M), recomputed independently:
  - PDGFRB: 4NHF −3.8/−0.1/+3.7, RDEBD −3.3/−0.3/+3.0. In 2NHF, 4NHFnew, 8NHF, RDEBM and RDEBR, M/L is +3.4 to +4.6 and H/L is +3.7 to +4.2.
  - PDGFRA, PLCG1, PTPN11, RASA1, SHC1 and GAB1 show the same pattern.
  - So the unstimulated channel is medium in exactly 4NHF and RDEBD, and light in the other five.
- 5 vs 10 min within the swaps: the producer says the data cannot tell these apart. I tested it. On PDGF-induced proteins, I correlated the reference log2(H/M) (10/5 min) with the swapped −log2(H/L) (10/5 min under the readme map).
  - r = 0.71 (4NHF, n = 39) and r = 0.78 (RDEBD, n = 48).
  - A reversed 5/10 assignment would give a negative r. Any heavy-label bias would also push r negative, not positive.
  - So the readme order is supported by the data.
