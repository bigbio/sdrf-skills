# PXD053053 — SDRF annotation report

**Result: ANNOTATED** (1344 rows × 48 columns) — `annotations/PXD053053.sdrf.tsv`

Multiplexed single-cell proteomics (SCoPE2 / TMTpro-16, RETICLE acquisition) of a hypoxia
time-course in HEK293-F cells expressing the PIP-FUCCI cell-cycle reporter. This is a genuinely
multiplexed dataset that required a deposited per-(file × channel) map — that map **exists** (in the
authors' Zenodo deposit) and was recovered and cross-validated, so the dataset is annotatable.

## Study and publication

- **Title (PRIDE):** *Multiplexed single cell proteomics of hypoxia in HEK293 expressing PIP-FUCCI.*
- **Publication:** Barry CP et al., *Mol Cell Proteomics* 2026;25(1):101475. PMID **41317903**,
  PMCID **PMC12892064**, DOI 10.1016/j.mcpro.2025.101475 (open access; Experimental Procedures read in full).
- **Design (from Methods):** one bioreactor hypoxia time-course of HEK293-F/PIP-FUCCI cells; cells
  sampled at 6 time points, **192 cells per time point sorted into four 384-well plates, each plate
  representing all time points** to spread batch effects. Single cells were index-FACS-sorted, TMTpro
  labelled per the SCoPE2 workflow with a booster (carrier) + reference channel, and acquired on an
  Orbitrap Eclipse Tribrid + FAIMS with the RETICLE real-time-search method. scRNA-seq was collected in
  parallel (GSE273172) — out of scope for the proteomics SDRF.

## Templates chosen

`comment[sdrf template]` (4): **ms-proteomics v1.1.0**, **human v1.1.0**, **cell-lines v1.1.0**,
**single-cell v1.0.0**.

- **ms-proteomics** — MS acquisition columns (instrument, label, cleavage, mods, tolerances).
- **human** — organism *Homo sapiens*; licenses donor sex/age.
- **cell-lines** — HEK293-F is a cultured line; licenses cell line + Cellosaurus accession/name + disease-of-origin.
- **single-cell** — the reason this study is annotatable in SDRF at all: licenses
  `single cell isolation protocol`, `cell identifier` (with special values `carrier`/`reference`),
  `cells per well`, `cell cycle phase`, `carrier channel`, `reference channel`, `sample preparation batch`.
- **clinical-metadata deliberately NOT added.** PIP-FUCCI is a stable genetic modification, and
  `characteristics[genotype]` is licensed only by clinical-metadata — but that template is semantically
  for patient/clinical cohorts, and the construct is constant across every sample (not a per-sample
  variable). The functional readout of PIP-FUCCI (cell-cycle phase) is captured by
  `characteristics[cell cycle phase]`; the construct itself is documented here rather than forced into a
  clinical template. Flagged for the reviewer.

## The channel → sample map (the critical question)

An SDRF for a multiplexed run needs one row per (file × channel) **with an identity**. The map was
**not** in PRIDE and **not** in the deposited search output, but **was** in the authors' Zenodo deposit:

| Source | Verdict |
|---|---|
| PRIDE `files/all` (109 files: 96 raw + 1 .pdResult + 1 .pdAnalysis + 11 PD .txt) | **No sample sheet** — no csv/xlsx/tsv |
| PD `..._StudyInformation.txt` (deposited) | All 16 channels of all 96 files marked generic `"Sample"` with **empty Sample Group/Replicate Group** → **PD default, NO map** |
| Supplementary `mmc1.xlsx` (Table S1) | Protein abundance matrix; columns `Abundance: F1: 126, Sample` … → generic channel labels, **NO identity** |
| **Zenodo record 12615623** (cited in Data Availability) | **Contains the SCeptre layout + FACS + collated per-cell tables** — the map |

Recovered from Zenodo and combined deterministically:
- `label_layout.txt` — well → TMTpro channel (rotating diagonal layout; **layout is fixed across the 4 plates**).
- `sort_layout.txt` — well row → hypoxia time point.
- `sample_layout.txt` / `file_sample_mapping.txt` — plate column → one multiplexed run → raw file name.
- `compiled_FACS_data.txt` — **all 1152 index-sorted single cells** with well, plate, time point (`tp`) and
  FUCCI-derived phase (`Population` = S_phase / G0_G1).
- `scMS_filtered_data.h5ad` — the authors' **collated per-cell table** (666 QC-passing cells) with
  `File Name`, `Channel`, `Well`, `timepoint`, `time_hypoxia` (hours), and `phase`.

**Cross-validation:** I built the (file × channel) → (time point, phase) map for all 1152 single cells
from the layout + FACS files, then checked it against the 666 cells in the collated h5ad. **All 666
matched on well, time point and phase with 0 discrepancies.** Time-point → hours came from the h5ad
`time_hypoxia` field: TP00→0, TP01→0.25, TP03→0.75, TP05→2, TP06→4, TP08→8 hour.

Per-file channel roles (from protocol + `label_layout` + the fact that `mmc1` drops 127C):
`126` = **carrier/booster** (~120 cell-equivalents), `127N` = **reference** (~6 cell-equivalents),
`127C` = **empty** (always), the **12** single-cell channels = wells C–O (excl. I) of that plate column,
and **one** of the 128N–134N labels is unused per run (empty; the diagonal skips it).

## Scope: deposited vs annotated (reconciled)

- Deposited raw runs: **96** (each TMTpro-16 = **1536** channel slots).
- **Annotated: 1344 rows** = 96 × (12 single cells + 1 carrier + 1 reference).
- **Excluded: 192 empty channel slots** = 96 × (127C + the 1 rotating unused label). These carry no
  sample material, so they are not rows.
- Single cells: **1152** (= 96 files × 12 = 4 plates × 24 columns × 12 wells = paper's 6 tp × 192).
  All 1152 carry a deterministic (time point, phase); 666 of them additionally passed the authors' QC.
  I annotate **all deposited single cells**, not only the QC survivors — QC filtering is an analysis
  choice, not a change of sample identity.

## Key technical decisions (evidence)

- **Label = TMTpro-16**, one row per channel. `label_layout` uses 128N–134N; PD StudyInformation says
  `TMTpro 16plex VL310412`. Channel labels written `TMT126`…`TMT134N` (PRIDE ontology: TMT126=PRIDE:0000516,
  TMT134N=PRIDE:0000643).
- **Modifications** taken from the deposited `.pdAnalysis` search settings (authoritative UnimodAccession
  attributes), consistent with the paper: TMTpro K + peptide N-term (UNIMOD:2016, Fixed), Oxidation M
  (UNIMOD:35), Acetyl protein N-term (UNIMOD:1), Met-loss (UNIMOD:765), Met-loss+Acetyl (UNIMOD:766).
- **Carbamidomethyl OMITTED** — see conflicts.
- **Cell line = HEK-293F / CVCL_6642** (FreeStyle 293-F suspension line; Expi293 medium, suspension
  culture per Methods), **not** parental HEK293/CVCL_0045. Live Cellosaurus: HEK293-F, derived from
  fetal kidney (UBERON:0002113), Female, age Fetus, cross-refs EFO:0022564 ("HEK-293F") / BTO:0003032.
  (The offline `cellline` helper mis-maps "HEK293F" → parental HEK293/CVCL_0045 — overridden.)
- **Instrument = Orbitrap Eclipse (MS:1003029)** (paper: "Orbitrap Eclipse Tribrid"; PRIDE: "Orbitrap Eclipse").
- **Acquisition = DDA (PRIDE:0000627)**; **dissociation = HCD / beam-type CID (MS:1000422)** — the TMT
  reporter quant MS2. RETICLE also uses **linear-ion-trap CID** for the real-time-search identification
  MS2; only one dissociation value is written (HCD, the quantitative one) and CID is noted here.
- **Cleavage = Trypsin (MS:1001251)**; precursor tol **10 ppm**, fragment tol **0.02 Da** (paper + pdAnalysis).
- **Factors:** `factor value[sampling time]` (hypoxia duration) **and** `factor value[cell cycle phase]`
  — the paper's statistical model is explicitly `~cell cycle phase + time hypoxia`, so both are design
  variables. Sampling time is the applied perturbation; phase is the FUCCI-measured covariate.
- **biological replicate = 1** for all rows: there was a **single** bioreactor time-course. The 4 plates
  are process/prep batches, captured in `comment[sample preparation batch]` (plate_01…plate_04), not
  biological replicates.

## Values left `not available` / `not applicable` (and why)

- `characteristics[cell type] = not available` — HEK293 lineage is genuinely debated (embryonic-kidney
  epithelial vs. neuronal/adrenal-precursor origin); no confident CL term. (recommended, not required)
- `characteristics[age] = not available` — donor is a fetus; a numeric Y/M/W/D age is undefined
  (Cellosaurus AG=Fetus). `sex = female` is known.
- `characteristics[individual] = not applicable` — an immortalized cell line, not a donor cohort.
- `developmental stage` **column omitted** — donor is fetal, but no clean EFO term resolved; not guessed
  (column is optional).
- **Carrier / reference rows**: `sample type`, `cell cycle phase`, `sampling time` and both factor values
  = `not applicable` — they are pooled cell mixtures spanning all time points and phases, not single cells.

## Conflicts found and how resolved (precedence: raw/search output > paper Methods > PRIDE)

1. **Carbamidomethyl.** The deposited PD search settings include static Carbamidomethyl/C (a carry-over
   from the Furtwängler RETICLE settings), **but** the sample prep describes **no reduction/alkylation**
   (cells are heat-lysed + sonicated, then digested directly) and the paper's own fixed-modification list
   is **TMTpro only**. Cysteines cannot be carbamidomethylated without an alkylating reagent, so
   Carbamidomethyl is **omitted** from `comment[modification parameters]`. (Per the annotator brief's
   explicit rule; this is the single most attackable call — see below.)
2. **PRIDE `modifications` = "monohydroxylated residue"** (i.e. Oxidation only) contradicts the paper/PD
   (TMTpro + Oxidation + Acetyl/Met-loss variants). Used the deposited search settings + paper.
3. **Instrument** wording differs (Eclipse vs Eclipse Tribrid) — same instrument, MS:1003029.
4. **Screen hint framing.** The task framed this as a cell-cycle study; the deposited files
   (`scMS_hypoxia_*`) and the paper show it is a **hypoxia time-course** in which cell-cycle phase is a
   covariate. Both are represented as factors.

## Stated vs inferred

- **Stated / deposited (hard):** every channel identity, time point and phase (Zenodo layout + FACS +
  collated h5ad, cross-validated 0-discrepancy); labels, mods, enzyme, tolerances, instrument (PD search
  files); cell-line origin/sex (Cellosaurus).
- **Inferred (documented):** carrier ≈120 and reference ≈6 cell-equivalents (computed from the protocol's
  dilution arithmetic: 100 cells/µl ×1.2 µl and 5 cells/µl ×1.2 µl); exclusion of the 192 empty channel
  slots; biological replicate = 1; choosing HCD as the single dissociation value.

The single warning: `characteristics[cell cycle phase]` value **`G0/G1`** is not in the template's fixed
enum {G1,S,G2,G2/M,M,G0,not determined}. This is deliberate and scientifically accurate: PIP-FUCCI's
mAzamiGreen reporter marks the **combined G0/G1** state and cannot separate G0 from G1; the authors' own
label is `G0_G1`. The validator is warning-level, so the file still validates. `parse_sdrf` exit 0 proves
well-formedness only — all accessions here were verified live against OLS / Cellosaurus.

## Judgement calls a reviewer should attack hardest

1. **Omitting Carbamidomethyl** even though the deposited PD search includes it (I weighted the absence of
   any alkylation step + the paper's explicit fixed-mod list over the search parameter).
2. **Annotating all 1152 single cells**, not just the 666 that passed the authors' QC.
3. **Excluding the 192 empty channel slots** (127C + the rotating unused label) rather than emitting blank rows.
4. **carrier=120 / reference=6 `cells per well`** (nominal cell-equivalents from dilution math, not integer cell counts).
5. **`G0/G1`** cell-cycle value (enum warning) vs. collapsing to `G1` or `not determined`.
6. **HCD as the single dissociation method** when RETICLE also uses CID for the RTS identification MS2.
7. **biological replicate = 1** (one bioreactor course; plates as prep batches) vs. treating plates as replicates.
8. **cell type = not available** for HEK293.
