## Channel map (campaign rule 6)

- **Explicit source.** The PRIDE dataProcessingProtocol states "Experimental setup: Fw: Light- Wt, Heavy-Mut Rev: Light-Mut, Heavy-Wt". It also gives a Fw/Rev/ID table: 132 IDs with Fw = 2k-1 and Rev = 2k, followed by "B blank".
  - I parsed the table myself and recomputed `characteristics[bait]`, `factor value[bait]`, `characteristics[bait variant]`, the source-name prefix, the light/heavy membrane suffix and the biological replicate for every row. All 528 rows matched (0 mismatches).
  - MaxQuant experiment E<NNN> corresponds to file PepArray2_<NNN> (summary.txt).
- **Check against the deposited data.** In proteinGroups.txt (Ratio H/L normalized), log2 H/L for CLTC is:
  - GLUT1 P485L: +4.09 (Fw), -5.92 (Rev)
  - ITPR1 P1059L: +5.64 (Fw), -6.92 (Rev)
  - CACNA1H P648L: +3.55 (Fw), -4.27 (Rev)

  So the mutant gains clathrin, which is the paper's dileucine result. For SOS1_cntrl, GRB2 is -4.38 (Fw) and +5.24 (Rev), so GRB2 prefers the wild-type PxxP peptide. Across all pairs, every strong CLTC pair (|log2| > 2 in both runs) flips sign between Fw and Rev, and every one points to a gain in the mutant.
- **Blanks B1-B3.** Each blank run has L and H intensities of 0.8-2.1e11 and 770-823 protein groups. This is lysate-level signal, so they are blank membrane spots and not LC blanks. Treating each channel as a separate spot is an inference from the two-membrane design; the manifest discloses this.

   - Fix: either use `juvenile stage`, which removes the validate-sdrf warning, or keep HsapDv `pediatric stage` and correct the rationale.
2. **minor: provenance.** Location: evidence.json limitations. The PRIDE sample protocol says "128 wild-type ... 128 mutant ... plus one control peptide pair", but the Fw/Rev table lists four cntrl IDs: SOS1_cntrl, ARHGAP36_cntrl_1, ARHGAP36_cntrl_2 and WIP_cntrl. The SDRF correctly follows the table.
   - Fix: record the discrepancy in the limitations.

   - Fix: fill it in only if a citable source for the MaxQuant 1.5.2.8 defaults turns up.
