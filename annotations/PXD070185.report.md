  lysis+digestion buffer (LysC + trypsin), no separate reduction/alkylation, then nanoLC (Vanquish

  DIA** (400–800 m/z precursor, 20 m/z windows, HCD NCE 25%). Search: **Spectronaut 19.4 directDIA+**,
  Trypsin/P, ≤2 missed cleavages, variable Oxidation (M) + protein N-term Acetyl. No fixed Cys mod.

## Key value decisions & fields left reserved (with reasons)
- **`comment[proteomics data acquisition method]` = plain `Data-independent acquisition`** (not
  `NT=…;AC=…`): the `dia-acquisition` template enforces an exact-string `values` validator on this cell.
- **`characteristics[age]`**: liver = `6W` (Methods state 6-week-old mice; hepatocytes taken from these).
  HEK293 = `not available` (fetal donor, no `{N}{Unit}` value; age column disallows `not applicable`).
  MC38 immune/non-immune = `not available` (mice were 6 wk at start but tumors harvested +21 d; exact
  age at collection not stated — not guessed).
- **`characteristics[sex]` = female** for all: Methods "in all experiments … female C57BL/6JOlaHsd";
  HEK293 (CVCL_0045) donor is Female.
- **`developmental stage`**: mouse = `adult` (EFO:0001272; inferred from 6-week/adult mice); HEK293 =
  `not applicable` (immortalized line, human template optional).
- **Reaction temperature / volume** (HEK293 optimization variables) are preserved in
  `cell identifier` (e.g. `HEK293_temp_0p2_50C_1`, `HEK293_vol_0p3_37C_2`); there is no licensed SDRF
  column for digestion temperature/volume.
- **Zonation gate** is preserved in `characteristics[enrichment marker]` for liver rows
  ("CD73 and E-cadherin; FACS zonation gate N of 8 …") because `characteristics[spatial coordinates]`
  requires an `X=…;Y=…` pattern that a 1-D gate does not fit.
- **No `Carbamidomethyl`**: the EasySCP protocol has no reduction/alkylation step (confirmed — zero
  iodoacetamide/chloroacetamide/DTT/TCEP/carbamidomethyl in Methods), so a Cys fixed mod would be wrong.
- **Mass tolerances omitted**: Spectronaut directDIA+ uses dynamic MS1/MS2 tolerances; the recommended
  tolerance columns were left out rather than fabricated.
- `source name` disambiguated for HEK293: `HEK293_0p2_37C_1-6` are reused across the temperature AND
  volume sheets (different raw files); the experiment tag (`temp`/`vol`) makes each source unique.

## Judgement calls a reviewer should attack hardest
1. **`characteristics[cell line] = not applicable` for the 618 non-cell-line rows — RESOLVED via
   per-row `cell-lines` declaration (post-review correction).** The `cell-lines` template forbids
   **both** reserved words on `characteristics[cell line]` / `[cellosaurus accession]` / `[cellosaurus
   name]` (allow_not_available = allow_not_applicable = false — the #35 B1 trap). The first pass
   declared `cell-lines` file-wide (on all 650 rows) and wrote `not applicable` on the 618 primary-cell
   rows, which an independent reviewer correctly flagged as an illegal reserved word (parse_sdrf does
   not enforce the flag, so it passed exit 0 but the spec was violated). **Fixed** by making the
   `cell-lines` slot of `comment[sdrf template]` **per-row** — `NT=cell-lines;VV=v1.1.0` on the 32
   HEK293 cell-line rows only, `not available` on the 618 primary-cell rows (`comment[sdrf template]`
   is cardinality:multiple with allow_not_available:true in base.yaml). Once `cell-lines` is no longer
   declared for a primary-cell row, its `not applicable` cell-line facets are legal. This mirrors the
   approved `PXD061710.sdrf.tsv` (its pancreatic-acinar tissue rows use the same construction) and
   avoids both excluding 618 legitimately deposited cells and losing the HEK293/CVCL_0045 identity. The
   32 HEK293 rows are unchanged. Re-validated → exit 0.
2. **Immune (CD45+) cells carry `disease = colon adenocarcinoma`.** They are non-malignant
   tumor-infiltrating leukocytes; I annotated disease at the *source-tissue* level (both populations
   isolated from the MC38 colon-adenocarcinoma tumor) and encoded the immune/non-immune distinction via
   `cell type` (leukocyte vs neoplastic cell) and `enrichment marker` (CD45±). A reviewer may prefer
   `disease = normal` for the immune cells.
3. **MC38 arm `organism part = not applicable`.** The tumor is a syngeneic **subcutaneous** transplant
   of a colon-adenocarcinoma line, so the cells reside in no native organ; "colon" (origin) would be
   anatomically false. Debatable.
4. **HEK293 `cell type = epithelial cell` (CL:0000066).** Conventional (ATCC/EFO) annotation, but the
   embryonic-kidney line's lineage is debated (possible neuronal/adrenal precursor). Identity is
   otherwise fully carried by the cell line + Cellosaurus columns.
5. **`developmental stage = adult` for 6-week mice** — 6 wk is young-adult/borderline; `adult` is the
   closest EFO term the column allows.
