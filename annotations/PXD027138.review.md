## Summary

The SDRF is structurally valid. Its ontology terms are clean, and every technical value I checked matches the PRIDE protocol and mqpar. It fails on the request's central rule: **the SILAC channel→condition map must have an explicit source and must not be derived from data patterns alone.**

For the annotated RBM20ctl arm, no read source says which label carries uninduced WT, S635A or induced WT:
- **Forward medium = S635A, heavy = induced WT** rests on the order in which the PRIDE protocol lists the conditions, plus an RNP-granule proximity signature.
- **The whole Reverse map** comes from a permutation test of the data.

`BLOCKED.md` rejects exactly this reasoning for the RBM20mut arm, so the partial scope is not justified consistently. Only the uninduced channel is checkable against the data, through RBM20 bait depletion. The reviewer confirmed it: Forward Input H/L 12.2, M/L 14.8; Reverse Input H/L 0.125, H/M 0.168.

## Blocker / important findings

1. **BLOCKER — unsourced channel map** (rows 2–5 and 8–11; Forward medium/heavy and all Reverse channels).
   - **Evidence.** The PRIDE protocol lists the three conditions but assigns no label to any of them. mqpar.xml, experimentalDesignTemplate.txt and the proteinGroups headers show only experiment names and L/M/H. The manifest itself says "No source read for this annotation states the label of each condition explicitly" and that the reverse map "was derived from the data (permutation test)".
   - **Fix.** Either obtain an explicit source, or move the 4 RBM20ctl RAW files to BLOCKED.md.
     - Explicit-source route: the Mol Cell 2022 STAR Methods, a figure legend, a supplementary table, the bioRxiv Methods, or an author label sheet. Cite it in the manifest and check it against the bait ratios.
     - Blocking route: the whole dataset is then blocked.
2. **IMPORTANT — inconsistent partial-scope justification** (`BLOCKED.md` lines 1115–1143; manifest limitations).
   - **Evidence.** RBM20mut is blocked because "list order cannot be read as L/M/H", and the granule signature was "deliberately not used". RBM20ctl is annotated using both. BLOCKED.md says the uninduced channel "anchors the map", but it anchors only 1 of 3 channels.
   - **Fix.** Apply one rule to both arms and rewrite the PXD027138 entry to match.

Minor findings, which do not block on their own:
- Lys-C pre-digest of the Input runs is not encoded. The template column is single-cardinality and the omission is disclosed.
- The Flp-In T-REx 293 cell line is sourced from Mendeley imaging data, not from an MS statement.
- The free-text treatment values merge genotype and induction, and the negative-control role is inferred.
