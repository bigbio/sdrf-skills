## Scope
The paginated PRIDE v3 file list has 360 files: **352 `.raw`** (8 groups × 44 SCX fractions, suffixes `-1`…`-44`) and 8
Proteome Discoverer `.msf` files, one per group. All 352 raw files are annotated, with 2 rows each (SILAC light = tissue,
SILAC heavy = super-SILAC reference), giving 704 rows. Nothing is excluded or blocked. The `.msf` files are search output,
not data files. **No BLOCKED.md entry was needed.**

## Multiplexing verified (rule 14)
I read all 8 `.msf` files over HTTP range requests (an apsw SQLite VFS) and compared their search parameters, which are
identical:
- Proteome Discoverer 2.2.0.388, workflow template "20180621 SILACprocessing woContaminate".
- Minora quantification method **"SILAC 2plex(Arg6, Lys6)"**.
- Sequest HT + Mascot (SwissProt human), Trypsin (Full), 2 missed cleavages, precursor 10 ppm, fragment 0.5 Da.
- Static modification: Carbamidomethyl (C).
- Dynamic modifications: Label:13C(6) (K, R), Oxidation (M), Gln->pyro-Glu (N-term Q), Acetyl (protein N-term).

Note: the PRIDE protocol says PD 1.4 / Mascot only. The deposited workflows show PD 2.2 with Sequest HT and Mascot, and the
workflow values are used.

## Channel map (rule 6)
Source: the PRIDE sample protocol. "the LUAD cell lysate protein, together with the SILAC and tissue protein, was combined
in equal proportions", and the description says "proteins obtained from three locally established LUAD cell lines were
pooled with LUAD tissues". Surgical tissue cannot be metabolically labelled, so **heavy (Arg6/Lys6) = super-SILAC
cell-line reference, light = patient tissue**. There is no label swap, so the rule-6 check against deposited ratios does
not apply. Each group's 2D-LC run carries its own reference source name (`super-SILAC reference in <group>`). These eight
names are aliquots of the shared super-SILAC reference, one per run (validation.md:22-23).

- Each factor combination has exactly one measured sample, so the biological replicate is 1 in every group. Heavy rows
  are `pooled`, with factor values `not applicable`.
- Fraction identifier = SCX salt step 1-44. I checked this on all 352 raw headers: the original name
  `<date>_<group>_20ug-sNN.raw` matches the deposited `<group>-N.raw` with 0 mismatches, and each `.msf` lists the same
  44 files.
- Factor values: custom `tumor EGFR status` (the patient group's tumour EGFR status, on both tumour and normal rows),
  `disease staging` (early stage / late stage = SNOMED:234438000 / SNOMED:236040000 labels; the exact stages are not
  given), and `disease` (tumour = MONDO lung adenocarcinoma, adjacent normal = `normal`).
- `characteristics[genotype]` (EGFR wild type / EGFR mutant) appears on tumour rows only. The adjacent normal tissue was
  not genotyped, so those rows are `not available`.
- `characteristics[sampling site]` = tumor / normal tissue adjacent to tumor (the clinical-metadata example values).
  `developmental stage` = not available.
- Sex = female and smoking status = Never Smoker (NCIT:C65108) come from the PRIDE description ("LUAD tissues from women,
  never smokers"). I treated that sentence as a selection criterion covering every tissue sample. Age, ancestry and
  individual are `not available`.

## Technical values
- Instrument: Orbitrap Elite MS:1001910 (raw header and PRIDE).
- Acquisition: DDA, top-12. CID (MS:1000133) at 35 NCE, MS2 in the linear ion trap (MS:1000083).
- MS1 scan range: 350-2000 m/z, from the raw FTMS scan event. The protocol says 400-2000.
- Fractionation: SCX (PRIDE:0000561). Reduction DTT, alkylation IAA.
- Tolerances: 10 ppm / 0.5 Da. The 20 ppm value in the workflow is the recalibration node, not the search.
- Modifications: as in the `.msf` files. The SILAC label is Label:13C(6) UNIMOD:188 on K and on R, with MT=Variable
  (rule 11).

## Limitations (also in the manifest)
- The paper's full text and supplementary information were inaccessible.
- Pooling is unknown: the record does not say whether a group is one patient or a pool, or how many patients it holds.
  `pooled sample` and `individual` are therefore `not available`.
- It is not stated whether the N and T groups come from the same patients (paired).
- The exact stages behind "early" and "late" are not given. The SNOMED early/late stage labels draw a validator
  warning.
- The three reference cell lines are not named, and it is not stated whether the identical mix was used in all 8 groups.
- Sex and smoking status come from a project-level sentence, not from an individual-level sheet.
