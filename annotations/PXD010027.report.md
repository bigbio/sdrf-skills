## Dataset
Meyer et al., *Cell* 2018 (doi:10.1016/j.cell.2018.08.019), "Mutations in disordered regions cause disease by creating dileucine motifs", peptide–protein interaction screen sub-deposit. 128 wild-type/mutant 15-mer peptide pairs plus control pairs (SOS1_cntrl, ARHGAP36_cntrl_1/_2, WIP_cntrl) were synthesised on two cellulose membranes. One membrane was incubated with light SH-SY5Y lysate and the other with heavy (Arg10/Lys8) lysate. Matching wild-type and mutant spots were then combined, one per SILAC channel, and each pair was run once on a Q Exactive Plus (45 min DDA). MaxQuant 1.5.2.8 confirms SILAC: Multiplicity 2, Labels1 Arg10;Lys8.

## Design and channel map
- **Source:** PRIDE dataProcessingProtocol says "Experimental setup: Fw: Light- Wt, Heavy-Mut Rev: Light-Mut, Heavy-Wt", followed by a table assigning spot pairs 1–264 (Fw = odd, Rev = even) to 132 IDs, plus "B blank". The run number is the file number `PepArray2_NNN`, which is also the MaxQuant experiment ENNN.
  - Fw run (2k−1): SILAC light = `<ID> wild-type peptide`, SILAC heavy = `<ID> mutant peptide`
  - Rev run (2k): SILAC light = `<ID> mutant peptide`, SILAC heavy = `<ID> wild-type peptide`
  - Blank runs B1–B3: both channels = `no peptide (blank membrane spot)`
- **Checked against the deposited ratios** (proteinGroups Ratio H/L normalized):
  - Clathrin CLTC/CLTA/CLTB has H/L 8–50 in the Fw run and 0.007–0.05 in the Rev run for GLUT1 P11166_P485L (E205/206), ITPR1 Q14643_P1059L (E129/130) and CACNA1H O95180_P648L (E17/18). This matches the paper's mutation-induced gain of clathrin binding.
  - SH3 proteins GRB2/NCK1 have H/L 0.05/0.11 in Fw and 37.7/14.3 in Rev for SOS1_cntrl. This matches wild-type-preferring SH3 binders (preprint Fig. 1C).
- **Columns:**
  - `characteristics[bait]` = `factor value[bait]` (263 groups)
  - custom `characteristics[bait variant]` = wild type / mutant / not applicable
  - `characteristics[biological replicate]`: 1 = pull-down from the light-lysate membrane, 2 = from the heavy-lysate membrane (two independent pull-downs per bait). The Q9UQN3_T104N groups have one replicate each (wt = 2, mut = 1), because the Fw run was not deposited.
- **Sample:** SH-SY5Y (CVCL_0019) from Cellosaurus: female, 4Y, neuroblastoma, bone marrow (metastatic site), Caucasian → European ancestry, pediatric stage. Culture medium: SILAC DMEM.

## Technical values
- Instrument: Q Exactive Plus (raw headers; the PRIDE dropdown says Q Exactive). HCD at 26 NCE, Orbitrap MS2, DDA Top10.
- Digestion: Trypsin + Lys-C, written as two cleavage columns. MaxQuant used the Trypsin/P rule.
- Reduction/alkylation: DTT / IAA.
- Modifications: Carbamidomethyl C (fixed); Oxidation M, Acetyl protein N-term, Arg10 (UNIMOD:267), Lys8 (UNIMOD:259), all variable.
- Mass tolerances: fragment 20 ppm; precursor `not available`.

## Open items / limitations
- The 3 searched runs are missing from the deposit (see Scope).
- The Cell paper is paywalled (Unpaywall PDF 403, not bypassed), so Table S1 (peptide sequences) was not retrieved. Methods come from the PRIDE protocol and the bioRxiv preprint doi:10.1101/141622.
- Baits are named by the submitters' `UniProt_mutation` IDs; gene symbols and sequences are not asserted. For ARHGAP36 controls, the wt/mut forms rest only on the uniform Fw/Rev statement.
- Blank runs are documented only as "B blank". Both L and H lysate proteins are present. That each channel is a separate blank spot from its membrane is inferred from the design.
- `comment[precursor mass tolerance]` = not available (not recorded by MaxQuant 1.5.2.8).
- `characteristics[developmental stage]` pediatric stage (HsapDv) gives a validator warning.
- `not available` values: cell type, passage number, sample storage temperature, precursor mass tolerance.
