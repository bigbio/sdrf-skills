### Findings (all minor)
1. **disease staging**: early/late stage are SNOMED terms, while the template expects NCIT/EFO (warning level). If the full text gives AJCC stages, switch to NCIT stage terms.
2. **sex / smoking status**: female / Never Smoker come from one PRIDE sentence ("LUAD tissues from women, never smokers"). I accept it because it is an inclusion statement covering every proteomic tissue, not a cohort proportion. Re-check against a patient table if one becomes available.
3. **heavy rows**: `characteristics[disease]` is lung adenocarcinoma but `factor value[disease]` is `not applicable`. The spec only says a factor value SHOULD mirror the characteristic. This looks deliberate, so the reference forms one condition.
4. **heavy rows**: age is `pooled` but sex is `not available` (cosmetic). The curated precedent PXD000332 uses age `not available` and sex `not applicable`.
5. **paper not open access**: the full text was unreadable, so pool size, N/T pairing, exact stages and the cell-line names are unverified. They are correctly left `not available` and recorded under limitations.
