## Study
"LC-MS/MS analysis of soluble lysosomal enzymes" is the lysosomal-proteome arm of Di Lorenzo G et al., *Mol Cell Proteomics* 2018 (PMID 29773673, PMC6072544). The sister deposit PXD007546 holds the M6P secretome. Gnptg-KO (light) and WT (heavy) MEF were SILAC-labelled. Lysosomal fractions were isolated with magnetic beads, then separated by SDS-PAGE into 10 slices. The slices were digested in-gel and run on an LTQ Orbitrap Velos. The data were searched with Proteome Discoverer 2.0 / Mascot.

## Duplicate / overlap check
PXD007547 shares no raw file with PXD007546; names, sizes and SHA-1 all differ. It is not a duplicate. The 30 deposited raws match the 30 inputs of the deposited pdResult by exact byte size.

## Key decisions
- Fractions: the gel slice is taken from the file suffix. Fractionation method is SDS PAGE (PRIDE:0000568).
- Search: the deposited msf has a two-pass Mascot search.
  - The primary pass is encoded: Trypsin, 8 ppm precursor, 0.6 Da fragment, Propionamide C fixed. Oxidation M, Acetyl protein N-term, Lys8 (UNIMOD:259) and Arg10 (UNIMOD:267) are variable.
  - The PRIDE text gives 10 ppm and 1 missed cleavage. Those values belong to the second semiTrypsin pass on unmatched spectra, which is recorded in the manifest.
- Cleavage agent: Trypsin, from the msf Mascot enzyme. The PRIDE prose does not name the enzyme, so reconcile raises a BLOCKER. It is refuted in validation.txt.
- Alkylation: acrylamide. No reduction agent is stated, so there is no reduction column.
- characteristics[cellular component] = lysosome (rule 16).
- Disease, strain, organism part, cell type and developmental stage: same as PXD007546.
