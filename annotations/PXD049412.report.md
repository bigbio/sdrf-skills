## Study & publication

- **Title:** *Challenging the Astral mass analyzer to quantify up to 5,300 proteins per single cell…*
- **Journal:** Nat Methods 2025. **PMID:39820751 · PMCID:PMC11903296 · DOI:10.1038/s41592-024-02559-1** (open access; full Methods read).
- A single-cell proteomics **methods/benchmarking** study: zero-dead-volume Aurora column + Orbitrap
  Astral in DIA mode, benchmarked against an Orbitrap Exploris 480. Sample matrix is heterogeneous:
  commercial dilution standards, two-proteome mixes, several cell lines as single cells, pooled
  cell "libraries", and FACS-sorted stem-cell lineages.
- Label-free throughout; **1 raw file = 1 injection = 1 sample** (no multiplexing → no channel-map
  blocker for the annotated arms).

### Why the 68 are excluded
- **Two-proteome mixes (18):** each injection is **HeLa-S3 + yeast in one sample** at defined pg
  ratios (150:100, 200:50, 240:10). `characteristics[organism]` is single-valued per row; there is no
  faithful SDRF representation of a two-organism sample. Not fabricated. Recorded as a partial block
  in `BLOCKED.md`.
- **Process blanks (34):** empty wells run through the SCP workflow (no cell). `characteristics[cell
  line]` (required by `cell-lines`) forbids **both** reserved words (`allow_not_available=false`,
  `allow_not_applicable=false`, the #35-B1 trap), so a blank cannot be represented under the declared
  templates.
- **Column washes (16):** `..._direct_wash_*` — solvent/column washes, no biological sample.

## Key decisions & evidence

**Instrument — resolved from raw headers, not PRIDE.** Range-read (first ~300 KB, UTF-16-LE) of one
raw file per naming family: every filename containing **`E0_NEO6`** decodes to **Orbitrap Exploris
480 (MS:1003028)**; all others to **Orbitrap Astral (MS:1003378)**. → 60 Exploris rows (HeLaSC
proteoCHIP benchmarking + A549 Armadillo/Evo96 prep benchmarking), 229 Astral rows. PRIDE lists both
instruments but does not map them to files; the raw headers do (precedence: raw > Methods > PRIDE).

**No carbamidomethyl — PRIDE `modifications` overruled.** PRIDE lists "iodoacetamide derivatized
residue" (= Carbamidomethyl), but the data-processing protocol states verbatim: *"Carbamidomethylation
of cysteines as a static modification was removed for single-cell searches as no alkylation step was
performed."* The cellenONE/FACS master mix (DDM/TEAB/trypsin/ProteaseMAX/DMSO) contains **no
reduction/alkylation** step. → **no fixed Carbamidomethyl on any row** (the SCP reflex-annotation trap).
Modifications = Spectronaut factory variable mods only: **Oxidation (M) UNIMOD:35** and **Acetyl
(Protein N-term) UNIMOD:1** (`MT=Variable`).

**Cell-line identities (all verified live; traps avoided):**
- **A549** → CVCL_0023 / EFO:0001086, lung adenocarcinoma MONDO:0005061, 58Y male, European.
- **NCI-H460** → CVCL_0459 / EFO:0003044, lung large cell carcinoma MONDO:0003050, male, age n/a.
- **HeLa (single cells, cultured in DMEM)** → **parental HeLa CVCL_0030 / EFO:0001185**, cervical
  adenocarcinoma MONDO:0005153, 30Y6M female, African American.
- **HeLa dilution standards (Pierce 88328)** → **HeLa-S3 CVCL_0058 / EFO:0002791** — a *different*
  clone from the cultured HeLa. Confirmed on the Thermo/vendor product page (the standard is derived
  from HeLa S3 and vendor-digested with **LysC + trypsin**, reflected as a second
  `comment[cleavage agent details]` = Lys-C on those 54 rows only).
- **K562 dilution standards (Promega V6951)** → CVCL_0004 / EFO:0002067, chronic myeloid leukemia
  MONDO:0011996, bone marrow, 53Y female.
- **H9 → the #1 OLS trap here.** A naïve lexical/offline lookup of "H9" returns **CVCL_1240** (H9 HTLV
  T-cell line, Sézary syndrome) — **WRONG**. The paper's H9 is the **WiCell H9 embryonic stem cell
  line = WA09 = CVCL_9773** (Cellosaurus: Female, Blastocyst stage, embryonic stem cell, derived from
  blastocyst UBERON:0000358). Cell-line accession **CLO:0037313** ("H9 ES cell", unambiguous; the
  bare EFO "H9" term is ambiguous). Both naïve-hPSC and TE-like arms are this one line; disease =
  `normal` (PATO:0000461).

**Dilution standards are a mass, not a count.** 250 pg / 10 ng are input amounts →
`sample type = standard`, `cells per well = not applicable`, `single cell isolation protocol = not
applicable`. Not "2–3 cells".

**Pooled libraries.** 20×/40× (A549) and 100× (hPSC, TE) are pooled cells for spectral-library
generation → `sample type = pool`, `cells per well = 20/40/100`, `pooled sample = pooled`.

**DIA acquisition parameters (from Methods + filenames):** `proteomics data acquisition method =
Data-independent acquisition`; scan-window 400–800 (MS2 range, both instruments);
`isolation window width` set per file from the `NNTh` filename token (5 / 20 / 40 Th), consistent
with the Methods rules ("m/z 5 for 100-cell libraries and 5–10 ng bulks; m/z 20 for 1–40 cells and
50–500 pg bulks; m/z 40 on Exploris"). Cleavage = Trypsin (Trypsin Gold; MS:1001251).

**Isolation protocol:** cellenONE for A549/H460/HeLa (+ their libraries); **FACS** for hPSC (SUSD2⁺)
and TE-like (TROP2⁺) and their 100× pools — the paper isolates these two lineages by FACS, not
cellenONE.

## Values left `not available` / `not applicable` — and why
- `age` = **not available** for NCI-H460 (Cellosaurus has none) and WA09/H9 (blastocyst stage, no
  numeric donor age; `allow_not_applicable=false` on `age`, so `not available` is the only legal token).
- `ancestry category` = **not available** for K562, H460, H9 (not documented).
- `cell type` = **not available** for K562 (leukemia line; no confident single CL term for a digest std).
- Standards: `culture medium / single cell isolation protocol / cell identifier / cells per well` =
  **not applicable** (commercial digests, no cells isolated).
- Second `cleavage agent details` = **not applicable** on all non-HeLa-S3 rows (single enzyme).
- `comment[dia method]` = **not available** (no PRIDE-ontology term applied).

## Conflicts found & how resolved
- **PRIDE `modifications` vs Methods:** PRIDE implies Carbamidomethyl; Methods say it was removed →
  followed Methods (no Carbamidomethyl).
- **PRIDE `organism` = {human, yeast}:** yeast appears **only** in the excluded two-proteome mixes;
  all annotated rows are Homo sapiens.
- **PRIDE two instruments, no file map:** resolved per-file from raw headers.
- **"H9" ambiguity:** resolved to WA09/CVCL_9773 (embryonic), not the T-cell CVCL_1240.

## Inferred vs stated
- **Stated in Methods/PRIDE/raw:** all cell lines & media, cellenONE vs FACS isolation, DIA, trypsin,
  no alkylation, instruments (raw), input amounts, cell numbers, isolation-window tokens.
- **Inferred:** `dissociation method = beam-type CID (HCD, MS:1000422)` — standard for Astral/Exploris
  DIA, not printed in the paper. HeLa-S3 organism-part/cell-type/disease and K562 origin = the cell
  line's Cellosaurus tissue of origin. hPSC/TE `organism part = blastocyst` = the H9 line's
  developmental origin (Cellosaurus "derived from site: blastocyst"), not a current in-vitro tissue.
