## Study

DIA-ME ("matching enhancer") single-cell proteomics. Low-input single cells are co-analysed in
DIA-NN with a higher-input **matching enhancer (ME)** run to raise sensitivity/data completeness.
**"ME" is a computational co-analysis strategy, NOT a chemical label** — the experiment is
**label-free**, no carrier, no multiplexing (screen row confirmed against Methods + the deposited
DIA-NN command line). Applied to U-2 OS osteosarcoma cells ± IFN-γ.

## Key decisions and evidence

**Cell line — `CVCL_0042`, not the naive guess.** U-2 OS resolves in Cellosaurus to **CVCL_0042**
(recommended name `U2OS`); the plausible-looking `CVCL_0029` is a *different* line ("EFO-21") and
would be wrong. Confirmed live against the Cellosaurus API: CVCL_0042 synonyms include "U-2 OS",
cross-refs `CLO:0009454` / `EFO:0002869` / `BTO:0001938`, donor **female, 15Y**, derived from
**tibia** (`UBERON:0000979`), disease osteosarcoma. `characteristics[cell line]` uses
`CLO:0009454` (OLS-verified label "U-2 OS cell"); `cellosaurus accession = CVCL_0042`,
`cellosaurus name = U2OS`.

**No modifications — Carbamidomethyl deliberately absent.** The deposited DIA-NN 1.8 command line
(`03_SingleCell_Searches/.../report.log.txt`) is
`--cut K*,R* --missed-cleavages 1 --min-pr-charge 2 --max-pr-charge 4 --window 5 --mass-acc 15 --mass-acc-ms1 15 ...`
with **no `--unimod4` and no `--var-mod`/`--mod` of any kind** — the single-cell search used **zero
modifications**. This matches the wet-lab prep, which has **no reduction/alkylation step** (lysis in
TEAB+DDM → 70 °C denature → trypsin → acidify → inject). PRIDE's `modifications` field
("iodoacetamide derivatized residue" = Carbamidomethyl; "monohydroxylated residue" = Oxidation) is
**wrong for this deposit** — those belong to the paper's SP3-prepped two-proteome/bulk arms (DTT +
chloroacetamide + MaxQuant), which are not in PXD048179. `comment[modification parameters]` =
`not applicable` on all rows.

**Instrument = timsTOF Pro** from the paper Methods ("timsTOF Pro mass spectrometer (Bruker
Daltonics)"). The `.mzML` header carries only the generic series term
`MS:1003123` "Bruker Daltonics timsTOF series" (ProteoWizard); Methods is more specific and wins
(precedence: paper > raw-header-generic > PRIDE). Note sibling PXD053464's PRIDE record says
"timsTOF Pro 2" — not adopted; the peer-reviewed Methods say Pro.

**DIA window params from Methods (fixed-width diaPASEF).** `scan window lower/upper limit` = **475 /
1000** (Methods: "only precursors with a mass ratio of 475 to 1,000 m/z were considered for DIA
window isolation"). `isolation window width` = **25** (Methods: "equally sized windows of 25 Th
width" — genuinely fixed-width here, unlike the variable-width diaPASEF in PXD052416, so a real
scalar exists). `dia method` = `diaPASEF`. `proteomics data acquisition method` =
`Data-independent acquisition` (literal string the template validator mandates).

**Enzyme / tolerances / dissociation from the DIA-NN log.** Trypsin (`--cut K*,R*`, `MS:1001251`);
precursor + fragment mass tolerance both **15 ppm** (`--mass-acc-ms1 15` / `--mass-acc 15`,
"fixed to 1.5e-05"); dissociation = collision-induced dissociation (`MS:1000133`) — timsTOF
IM-dependent collision-cell fragmentation (45→27 eV), which is CID, not HCD.

**Treatment = the factor.** IFN-γ arm: `NT=Recombinant Interferon Gamma;AC=NCIT:C583` (Methods:
"50 ng/mL recombinant IFN-γ", 24 h). `factor value[treatment]` mirrors
`characteristics[treatment]`. NCIT is the treatment ontology (`values: NCIT, EFO`); the CHEBI
IFN-γ hits are out-of-ontology and the NCIT smart-mode hit for "interferon gamma" was the wrong
receptor term (`NCIT:C37288`) — `Recombinant Interferon Gamma` is the correct substance term.

**Replicate model.** Each sorted single cell = one distinct `biological replicate` (numbered within
each condition; matches the reference's single-cell convention). Each cell injected once → all
`technical replicate` = 1, all `fraction identifier` = 1. `cell identifier` = plate index+well
(unique within group; bare well repeats across sort batches). `source name` = per-run unique.

## Judgement calls I want the reviewer to attack hardest

1. **`cell type = epithelial cell` (`CL:0000066`)** — taken verbatim from the paper ("Human
   osteosarcoma epithelial cells"). Osteosarcoma is ontologically **mesenchymal** (osteoblast
   lineage), so a reviewer may argue this is imprecise vs leaving it `not available`. I followed the
   authors' explicit wording; Cellosaurus gives no cell type.
2. **`organism part = tibia` (`UBERON:0000979`)** — the exact site Cellosaurus assigns to CVCL_0042,
   more specific than a generic "bone". A reviewer may prefer `bone tissue` (`UBERON:0002481`) at
   organ granularity. Chose the authoritative, specific term.
3. **10-cell ME rows annotated as full samples** (cells per well 10) rather than treated as
   reference/carrier. They are real deposited 10-cell U-2 OS runs, not an isobaric carrier channel,
   so `carrier channel`/`reference channel` columns were not used. Defensible; flagged.
4. **Control treatment / factor = `not applicable`** — encodes "no IFN-γ" but reads oddly as a
   factor level; alternative encodings (separate stimulus/time column) were not used.
5. **`modification parameters = not applicable` for all rows** — the strongest evidence-backed call
   (DIA-NN cmdline + no alkylation), but it contradicts the PRIDE `modifications` field, so worth a
   hard second look.
